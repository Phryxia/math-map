# Functor

# 개요

Functor 는 [범주](category.md) 사이의 대응으로, 대상과 사상을 함께 옮기면서 항등사상과 합성을 보존한다. 핵심은 "함께" 라는 말에 있다. 대상만 어디로 가는지 정하는 것은 대응이라 부를 수 없고, 사상까지 옮기면서 구조를 지켜야 한 범주에서 알아낸 사실을 다른 범주로 나를 수 있다.

Functor 를 통해 옮겨지는 것은 대상과 사상만이 아니다. 가환 그림이 가환 그림으로, 동형이 동형으로 옮겨진다. 그래서 다루기 어려운 범주의 질문을 다루기 쉬운 범주로 밀어 놓고 답하는 전략이 가능해진다. 위상공간의 구멍을 군의 문제로 바꾸는 일이 그 대표적인 예이고, [선형사상](linear-maps.md)에서 익힌 "구조를 보존하는 사상" 의 감각이 그대로 한 단계 위로 올라간 것이 functor 다.

# 직관

## 구조를 옮기는 번역

벡터 공간에 그 바탕집합을 대응시키는 망각 functor 는 벡터 연산을 잊는다. 반대로 집합에 자유 벡터 공간을 대응시키는 functor 는 없던 구조를 최소한으로 붙인다. 두 경우 모두 "대상을 바꾸면 사상도 같이 따라간다" 는 점이 같다. 번역이 단어만 바꾸고 문법을 무시하면 문장이 깨지듯, 대상만 옮기고 사상을 옮기지 않으면 아무 정보도 나르지 못한다.

## 불변량을 만드는 기계

공간 $X$ 에 기본군 $\pi_1(X)$ 를 대응시키는 것은 functor 다. 연속사상 $f : X \to Y$ 가 군 준동형 $\pi_1(f)$ 로 옮겨지고, 합성과 항등이 보존된다. 여기서 곧바로 다음 논법이 나온다. 두 공간이 위상동형이면 그 기본군은 동형이다. 대우를 취하면 기본군이 다를 때 두 공간이 다르다고 말할 수 있다. Functor 가 동형을 보존한다는 한 줄이 불변량 논법 전체를 지탱한다.

# 정의

## Covariant functor

범주 $C$ , $D$ 에 대해 functor $F : C \to D$ 는 $C$ 의 각 대상 $A$ 에 $D$ 의 대상 $F(A)$ 를, 각 사상 $f : A \to B$ 에 사상 $F(f) : F(A) \to F(B)$ 를 대응시키되 다음을 만족하는 것이다.

$$
F(g\circ f)=F(g)\circ F(f),\qquad F(\mathrm{id}_A)=\mathrm{id}_{F(A)}
$$

## Contravariant functor

사상의 방향을 뒤집는 대응도 흔하다. $F(f) : F(B) \to F(A)$ 가 되고 합성 조건이 다음으로 바뀐다.

$$
F(g\circ f)=F(f)\circ F(g)
$$

반변 functor 는 반대 범주에서의 공변 functor $C^{\mathrm{op}} \to D$ 와 같은 것이다. 벡터 공간에 쌍대공간을 대응시키는 $V \mapsto V^*$ , 집합에 멱집합을 대응시키되 사상을 역상으로 보내는 대응이 대표적이다. 같은 멱집합이라도 직접상으로 보내면 공변, 역상으로 보내면 반변이 되어 서로 다른 functor가 된다.

## Hom functor

대상 $c$ 를 고정하고 $\mathrm{Hom}_C(c, -)$ 를 생각하면 대상 $d$ 를 집합 $\mathrm{Hom}(c, d)$ 로, 사상 $f : d \to d'$ 를 "뒤에 $f$ 를 합성하기" 로 보내는 공변 functor 가 된다. 두 번째 변수를 고정한 $\mathrm{Hom}_C(-, d)$ 는 "앞에 합성하기" 로 반변 functor 가 된다. 이 두 functor 가 Yoneda lemma 의 주인공이다.

## 성격을 나타내는 말

| 이름 | 조건 |
|---|---|
| 충실(faithful) | 각 hom-집합에서 단사 |
| 충만(full) | 각 hom-집합에서 전사 |
| 본질적 전사 | $\mathcal D$ 의 모든 대상이 어떤 $F(c)$ 와 동형 |

세 조건을 모두 만족하면 $F$ 는 범주의 동치를 준다. 망각 functor 는 대개 충실하지만 충만하지 않다. 군 준동형은 함수이지만 모든 함수가 군 준동형은 아니기 때문이다.

# 성질

## 동형을 보존한다

$f$ 의 역을 $g$ 라 하면 다음이 성립한다.

$$
F(g)\circ F(f)=F(g\circ f)=F(\mathrm{id}_A)=\mathrm{id}_{F(A)}
$$

반대 순서도 마찬가지이므로 $F(f)$ 는 동형이다. 역은 성립하지 않는다. 모든 것을 대상 하나와 항등사상 하나뿐인 범주로 보내는 functor 를 생각하면 원래의 비가역 사상도 항등사상이 된다. 즉 functor 는 정보를 잃을 수 있고, 얼마나 잃는지를 재는 말이 위의 충실·충만이다.

가환 그림도 보존된다. 그림의 가환성은 합성이 같다는 등식이고 functor 는 합성을 보존하기 때문이다. 이것이 functor 를 "그림을 옮기는 도구" 로 쓸 수 있는 근거이며, 도형을 functor 로 정의하는 관점이 여기서 나온다.

## 합성과 functor 범주

functor 의 합성은 다시 functor 이고 항등 functor 가 있으므로, 작은 범주들과 functor 들은 그 자체로 범주를 이룬다. 한편 $\mathcal C$ 에서 $\mathcal D$ 로 가는 functor 들을 대상으로, 그 사이의 [자연변환](natural-transformations.md)을 사상으로 삼으면 functor 범주 $[\mathcal C,\mathcal D]$ 가 된다. 범주론이 한 층 위로 올라가는 지점이다.

## 예

- **망각과 자유.** 군, 환, 벡터 공간에서 바탕집합으로 가는 망각 functor 와, 집합에서 자유 대상으로 가는 functor. 두 방향이 짝을 이루는 현상이 adjunction 이다.
- **부분순서.** [부분순서](partial-orders.md) 집합을 사상이 최대 하나인 범주로 보면 functor 는 정확히 단조사상이다. $A \le B$ 를 $F(A) \le F(B)$ 로 보내야 사상이 옮겨지기 때문이다.
- **군을 한 대상 범주로.** 대상이 하나이고 사상이 군의 원소인 범주에서 집합의 범주로 가는 functor 는 군 작용과 같다.
- **거듭제곱 구성.** 집합에 리스트, 유한 부분집합, 확률분포를 대응시키는 구성은 모두 functor 이고, 여기에 구조를 더 얹으면 monad 가 된다.

## 법칙을 코드로 확인

리스트에 대한 `fmap` 이 functor 법칙을 만족하는지, 그리고 그럴듯해 보이지만 법칙을 깨는 대응은 어떻게 걸리는지 확인한다.

```python
fmap = lambda f, xs: [f(x) for x in xs]              # 후보 1
bad  = lambda f, xs: [f(x) for x in reversed(xs)]    # 후보 2: 옮기면서 뒤집는다

xs = [1, 2, 3]
f, g = lambda x: x + 1, lambda x: x * 10
gf = lambda x: g(f(x))
idf = lambda x: x

for F in (fmap, bad):
    comp = F(gf, xs) == F(g, F(f, xs))               # F(g∘f) = F(g)∘F(f)
    idty = F(idf, xs) == xs                          # F(id) = id
    print(comp, idty)
# True True     리스트 fmap 은 functor
# False False   뒤집기를 섞으면 두 법칙이 모두 깨진다
```

두 번째 대응이 실패하는 이유가 분명하다. 사상을 두 번 옮기면 두 번 뒤집혀 원래 순서로 돌아오지만 한 번에 옮기면 한 번만 뒤집히고, 항등사상조차 항등으로 가지 않는다. 대상 대응(리스트를 리스트로)이 같아도 사상 대응을 잘못 정하면 functor 가 아니게 된다는 점을 보여 준다.

# 활용

## 불변량과 분류

대수적 위상수학은 공간의 범주에서 대수 구조의 범주로 가는 functor 를 만들어 공간을 구별한다. 기본군, 호몰로지 군, 코호몰로지 환이 모두 functor 이고, 각각이 보존하는 정보의 양이 다르기 때문에 서로 다른 판별력을 가진다. 계산 가능한 쪽에서 답을 내고 원래 문제로 되돌리는 이 전략이 functor 의 가장 큰 쓸모다.

## 구성을 비교하는 언어

같은 대상 대응이라도 사상 대응이 다르면 다른 functor 이므로, "어떤 구성이 사상과 어떻게 어울리는가" 를 정확히 물을 수 있다. 어떤 구성이 극한을 보존하는지, 어떤 구성이 자연스러운지는 모두 functor 수준의 질문이고, 답은 자연변환과 adjunction 으로 이어진다.

## 프로그래밍

타입과 함수를 범주로 보면 제네릭 컨테이너는 functor 이고 `map` 이 사상 대응이다. functor 법칙은 "컨테이너를 그대로 두고 내용만 바꾼다" 는 약속이며, 이 약속 덕분에 `map(g, map(f, xs))` 를 `map(g∘f, xs)` 로 바꿔 쓰는 최적화가 항상 안전하다.[^1]

[^1]: The Stacks Project, Definition 4.2.8 (tag 001B). 대상·사상 대응과 합성·항등 보존 조건. https://stacks.math.columbia.edu/tag/001B
