# 이산 Fourier 변환

# 개요

길이 $N$ 의 수열을 다루는 방법은 두 가지다. 각 시점의 값을 그대로 보거나, 서로 다른 속도로 도는 회전 성분들의 계수로 보거나. 이산 Fourier 변환은 전자에서 후자로 가는 좌표 변환이다.

[선형사상](linear-maps.md)의 관점에서 보면 정체가 분명해진다. DFT 는 $\mathbb{C}^N$ 위의 가역 선형변환이고, 그 행렬의 열들이 정규직교 기저를 이룬다. 즉 기저를 바꾸는 것뿐이다.

그런데 이 특정한 기저에 특별한 성질이 있다. 순환 이동이라는 연산이 이 기저에서 대각행렬이 된다. 그 결과 합성곱이 곱셈으로 바뀌고, 순환 구조를 가진 선형 문제가 전부 단순해진다. FFT 가 이 변환을 $O(N\log N)$ 에 계산해 주면서 신호처리, 다항식 곱셈, 편미분방정식 수치해법의 표준 도구가 되었다.

# 직관

## 이동을 대각화하는 기저

수열을 한 칸 순환 이동시키는 연산 $S$ 를 생각하자. 표준 기저에서 $S$ 는 성분들을 섞는다. 그런데 $x[t] = \omega^{kt}$ 꼴의 수열에 $S$ 를 적용하면 전체에 상수 $\omega^{-k}$ 가 곱해질 뿐이다.

곧 이 수열들이 $S$ 의 고유벡터이고 DFT 기저가 바로 그 고유벡터들의 모임이다. 순환 이동과 교환하는 모든 선형변환, 곧 모든 순환 합성곱이 이 기저에서 동시에 대각화된다. 합성곱 정리는 이 사실의 다른 표현일 뿐이다.

## 직교성이 역변환을 만든다

서로 다른 주파수의 회전 성분을 한 주기에 걸쳐 더하면 상쇄된다. 정수 $r$ 에 대해

$$
\sum_{k=0}^{N-1}e^{2\pi ikr/N}=\begin{cases}N&N\mid r\\0&N\nmid r\end{cases}
$$

이며, 공비가 $1$ 인 경우와 아닌 경우로 나누어 유한 등비급수 공식을 적용하면 나온다. 역변환은 이 합 공식을 대입한 결과이고, 기저가 직교한다는 사실 자체다.

## 유한 배열은 주기적이다

DFT 는 길이 $N$ 의 배열을 무한히 반복되는 주기 신호로 취급한다. 마지막 원소 다음이 첫 원소다.

이 암묵적 가정이 실무의 함정을 만든다. 실제 신호를 유한 구간에서 잘라 변환하면 양 끝이 이어 붙으며 불연속이 생기고, 그 불연속이 모든 주파수에 에너지를 흩뿌린다. 창 함수를 곱해 양 끝을 부드럽게 만드는 것이 표준 대응이며, 표본화 주파수의 절반을 넘는 성분이 낮은 주파수로 되접히는 에일리어싱도 함께 고려해야 한다.

# 정의

## 변환

$N$ 을 배열 길이, $x$ 를 길이 $N$ 의 복소수 배열이라 하자. $i$ 는 허수 단위이고 실수 $\theta$ 에 대해

$$
e^{i\theta}=\cos\theta+i\sin\theta
$$

이다. 변환 방향의 지수 부호를 음수로 정하면

$$
X[k]=\sum_{t=0}^{N-1}x[t]\,e^{-2\pi ikt/N},\qquad k=0,\ldots,N-1
$$

이다. 부호와 정규화 상수의 배치는 문헌마다 다르므로 라이브러리를 쓸 때 규약을 확인해야 한다.

## 역변환

$$
x[t]=\frac1N\sum_{k=0}^{N-1}X[k]\,e^{2\pi ikt/N},\qquad t=0,\ldots,N-1
$$

지수 부호를 바꾸고 $N$ 으로 나눈다. 양쪽에 $1/\sqrt{N}$ 을 배치하면 변환이 유니터리가 되어 Parseval 등식이 상수 없이 깔끔해진다.

## 행렬로 보기

$\omega = e^{-2\pi i/N}$ 이라 하면 $F[k][t] = \omega^{kt}$ 인 $N \times N$ 행렬이고, $F^{-1} = F^*/N$ 이다. $F/\sqrt{N}$ 이 유니터리이므로 DFT 는 $\mathbb{C}^N$ 의 정규직교 기저 변환이다.

# 성질

## 기본 성질

- 선형이고 가역이다.
- $X[0]$ 은 입력값의 합이므로 $N$ 으로 나누면 평균이다.
- 실수 입력이면 $X[N-k]=\overline{X[k]}$ 다. 따라서 실수 신호의 정보는 절반에 다 들어 있고, 실수 전용 변환이 연산량을 절반으로 줄인다.
- **Parseval.** $\sum |x[t]|^2 = (1/N)\sum |X[k]|^2$ 로 에너지가 보존된다.
- **이동.** 입력을 $m$ 만큼 순환 이동하면 $X[k]$ 에 $\omega^{km}$ 이 곱해진다. 크기는 변하지 않는다.

$N=4$ 이고 $x=(1,0,-1,0)$ 이면 결과는 $(0,2,0,2)$ 다. 하나의 실수 진동이 양·음의 주파수에 대응하는 두 복소 성분으로 나타난다.

## 합성곱 정리

순환 합성곱을 $(x * y)[n] = \sum_m x[m]\thinspace y[(n-m) \bmod N]$ 이라 하면

$$
\mathrm{DFT}(x*y)[k]=X[k]\cdot Y[k]
$$

가 성립한다. $O(N^2)$ 짜리 합성곱이 변환 두 번, 성분별 곱 한 번, 역변환 한 번으로 $O(N \log N)$ 에 끝난다.

이것이 DFT 가 실제로 쓰이는 가장 큰 이유다. 다항식 곱셈, 큰 정수 곱셈, 이미지 필터링, 상관 계산이 모두 합성곱이며 같은 요령으로 가속된다.

```python
import cmath

def dft(x):
    N = len(x)
    return [sum(x[t] * cmath.exp(-2j * cmath.pi * k * t / N) for t in range(N))
            for k in range(N)]


def idft(X):
    N = len(X)
    return [sum(X[k] * cmath.exp(2j * cmath.pi * k * t / N) for k in range(N)) / N
            for t in range(N)]


x = [1, 0, -1, 0]
X = dft(x)
print([complex(round(z.real, 9), round(z.imag, 9)) for z in X])
print([round(z.real, 9) for z in idft(X)])        # 원래대로 복원

# 합성곱 정리: 다항식 곱셈
def cyclic_conv(a, b):
    N = len(a)
    return [sum(a[m] * b[(n - m) % N] for m in range(N)) for n in range(N)]

a = [1, 2, 0, 0]          # 1 + 2z
b = [3, 4, 0, 0]          # 3 + 4z
direct = cyclic_conv(a, b)
via_dft = idft([p * q for p, q in zip(dft(a), dft(b))])
print([round(v, 9) for v in direct])
print([round(z.real, 9) for z in via_dft])        # 3 + 10z + 8z^2
```

$(1+2z)(3+4z) = 3 + 10z + 8z^2$ 를 두 경로로 계산한 결과가 일치한다. 길이를 충분히 잡아 순환 겹침을 피한 것이 요령이며, 실무에서는 $0$ 을 덧붙여 길이를 늘린다.

## 빠른 계산

정의를 그대로 쓰면 $O(N^2)$ 이다. Cooley–Tukey FFT 는 짝수 인덱스와 홀수 인덱스로 나누어

$$
X[k]=E[k]+\omega^k O[k],\qquad X[k+N/2]=E[k]-\omega^k O[k]
$$

로 절반 크기의 문제 두 개로 환원한다. $T(N)=2T(N/2)+O(N)$ 이므로 $O(N\log N)$ 이다.

$N$ 이 $2$ 의 거듭제곱이 아니어도 소인수분해를 이용하거나 Bluestein 알고리즘으로 합성곱 문제로 바꾸어 처리한다. DFT 와 FFT 를 구분해야 한다. 전자는 변환의 정의이고 후자는 그 값을 계산하는 알고리즘 계열이다.

## 유한군 위의 변환

DFT 는 순환군 $\mathbb{Z}/N\mathbb{Z}$ 위의 Fourier 변환이다. 지수함수 $t \mapsto \omega^{kt}$ 들이 그 군의 지표이고, 직교성은 지표의 직교 관계다.

이 관점에서 일반 유한 아벨군으로 확장되고, 비가환군에서는 [군의 표현](group-representations.md)이 지수함수의 자리를 대신한다. $(\mathbb{Z}/2\mathbb{Z})^n$ 위의 변환이 Walsh–Hadamard 변환이며 부울 함수 해석에서 널리 쓰인다. 서로 달라 보이는 변환들이 "군 위의 조화해석" 이라는 하나의 틀에 들어간다.

## 유한체에서

복소수 대신 유한체의 $N$ 차 원시 단위근을 쓰면 같은 구조가 성립한다. 이것이 수론 변환이며 부동소수점 오차 없이 정확한 정수 합성곱을 준다. 큰 정수 곱셈 라이브러리와 격자 기반 암호의 다항식 연산이 이 변환을 쓴다. 같은 대수적 뼈대가 계수환만 바꿔 재사용되는 사례다.

# 활용

## 신호와 이미지

주기 성분의 검출, 잡음 제거, 대역 통과 필터링, 스펙트로그램 생성이 모두 DFT 기반이다. JPEG 은 관련 변환인 이산 코사인 변환을 쓰고, MP3 를 비롯한 오디오 코덱도 주파수 영역에서 지각적으로 덜 중요한 성분을 버리는 방식으로 압축한다. [엔트로피 부호화](source-coding.md)와 결합해 실제 압축률이 나온다.

## 곱셈의 가속

다항식 곱셈과 큰 정수 곱셈은 합성곱이므로 FFT 로 $O(N\log N)$ 에 처리된다. Schönhage–Strassen 과 그 후속 알고리즘이 이 원리를 쓰며, 수십만 자리 이상의 정수를 다루는 계산 대수 시스템의 기본 루틴이다.

## 선형 연산의 대각화

순환 구조를 가진 행렬은 DFT 기저에서 대각행렬이 된다. 이 사실이 순환 행렬의 역행렬 계산, 상수계수 편미분방정식의 스펙트럴 해법, 정상 확률과정의 스펙트럼 분해를 단순하게 만든다. 격자 위의 Poisson 방정식을 FFT 로 푸는 것이 대표적인 예이며, 문제의 대칭성을 기저 선택으로 활용하는 일반적인 전략의 구체적 실현이다.[^1]
