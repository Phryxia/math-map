# Budan–Fourier 정리

# 개요

**Budan–Fourier 정리(Budan–Fourier theorem)** 는 실계수 다항식이 구간 안에 갖는 근의 개수를 두 끝점에서의 도함수 값의 부호로 위에서 누르는 정리다. [Descartes 부호 법칙](descartes-rule-of-signs.md)은 양의 근 전체의 개수만 누른다. $x^3-3x+1$ 의 근이 $-2$ 와 $0$ 사이에 몇 개인지 알려면 다른 구간에서도 같은 일을 해야 한다. 이 정리는 끝점 $a$ 에서 $p,p',p'',\dots$ 의 값을 늘어놓은 열의 부호 변화를 세고, 두 끝점의 차를 근의 개수의 상한으로 준다.

# 직관

Descartes 부호 법칙은 계수의 부호를 본다. 계수 $a_k$ 는 $p^{(k)}(0)/k!$ 이므로 계수열의 부호는 $0$ 에서의 도함수 값 $p(0),p'(0),\dots,p^{(n)}(0)$ 의 부호와 같다. $x$ 가 매우 크면 모든 도함수가 최고차 계수와 부호가 같아서 부호 변화가 없다. 그래서 Descartes 부호 법칙은 $0$ 에서의 부호 변화의 수에서 $\infty$ 에서의 부호 변화의 수를 뺀 값이 $(0,\infty)$ 의 근의 개수의 상한이라는 말이다.

$0$ 과 $\infty$ 대신 아무 두 점 $a$, $b$ 를 쓴다. $p(x)=x^3-3x+1$ 의 도함수는 $3x^2-3$, $6x$, $6$ 이다.

$x=-2$ 에서 값은 $-1,9,-12,6$ 이고 부호가 세 번 바뀐다. $x=0$ 에서 값은 $1,-3,0,6$ 이고 $0$ 을 지우면 두 번 바뀐다. 차 $1$ 이 $(-2,0\rbrack$ 의 근의 개수의 상한이고, 실제로 근 $-1.879\ldots$ 하나가 있다.

# 정의

## 도함수열의 부호 변화

$p$ 가 $n$ 차 실계수 다항식일 때, 실수 $x$ 에서 수열 $p(x),p'(x),\dots,p^{(n)}(x)$ 의 $0$ 을 지운 뒤 이웃한 두 항의 부호가 다른 자리의 수를 $W(x)$ 로 쓴다.

[Taylor 정리](taylor-theorem.md)의 전개 $p(x+c)=\sum_k p^{(k)}(c)x^k/k!$ 에서 $W(c)$ 는 $p(x+c)$ 의 계수열의 부호 변화의 수와 같다. $x^3-3x+1$ 에서 $W(-2)=3$, $W(0)=2$, $W(2)=0$ 이다.

## Budan–Fourier 정리

$a\lt b$ 이고 $p(a)p(b)\ne 0$ 이면, 구간 $(a,b)$ 안의 근의 개수 $Z$ 를 중복도를 세어 센 값이 다음을 만족한다[^1].

$$
Z\le W(a)-W(b),\qquad W(a)-W(b)-Z\equiv 0\pmod 2
$$

$a=0$ 으로 두고 $b$ 를 크게 보내면 Descartes 부호 법칙이다. $x^3-3x+1$ 에서는 $(0,2)$ 의 상한이 $W(0)-W(2)=2$ 이고 근이 실제로 둘이다.

# 성질

## 증명의 요지

$W(x)$ 는 어느 $p^{(k)}$ 가 $0$ 이 되는 점에서만 바뀐다. $p$ 의 중복도 $m$ 인 근 $c$ 를 왼쪽에서 오른쪽으로 지나는 경우를 본다. $c$ 바로 앞에서는 $p,p',\dots,p^{(m)}$ 의 부호가 번갈아 바뀌어 부호 변화가 $m$ 번이고, 바로 뒤에서는 모두 $p^{(m)}(c)$ 와 부호가 같아 부호 변화가 없다. 그래서 $W$ 가 $m$ 만큼 준다.

$p$ 는 $0$ 이 아니고 어떤 $p^{(k)}$, $k\ge 1$ 만 $0$ 이 되는 점에서는 같은 방법으로 보면 $W$ 가 그대로이거나 짝수만큼 준다. 두 경우를 더하면 $W(a)-W(b)$ 는 근의 개수에 음이 아닌 짝수를 더한 값이다.

## 상한이 실제로 줄어드는 경우

$x^2+1$ 은 실근이 없다. 도함수열은 $x^2+1,2x,2$ 이고, $x=-1$ 에서 $2,-2,2$ 로 $W(-1)=2$, $x=1$ 에서 $2,2,2$ 로 $W(1)=0$ 이다. 상한 $2$ 와 근의 개수 $0$ 의 차 $2$ 는 켤레 복소 근 $\pm i$ 한 쌍에서 온다. 정확한 개수가 필요하면 [Sturm 정리](sturm-theorem.md)를 쓴다.

# 활용

- 근의 분리. Sturm 정리는 나머지 계산이 필요하고, Budan–Fourier 정리는 도함수의 값만 있으면 된다. 상한이 $0$ 이면 그 구간에 근이 없고, $1$ 이면 정확히 하나다. 상한이 $0$ 이나 $1$ 인 구간만 남을 때까지 구간을 잘게 나누면 근이 하나씩 분리된다.
- Descartes 부호 법칙의 위치 이동. $p(x+c)$ 의 계수를 계산해 부호 변화를 세면 $W(c)$ 가 나오므로, Descartes 부호 법칙을 $c$ 보다 큰 근에 쓰는 것과 같다.

[^1]: S. Basu, R. Pollack, M.-F. Roy, Algorithms in Real Algebraic Geometry, 2nd ed., Springer, 2006, 2장.
