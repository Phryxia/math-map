# Vincent–Collins–Akritas 알고리즘

# 개요

**Vincent–Collins–Akritas 알고리즘(Vincent–Collins–Akritas algorithm, Descartes method)** 은 [Descartes 부호 법칙](descartes-rule-of-signs.md)을 구간마다 써서, 실수 계수 다항식의 실근을 하나씩 가둔 구간들을 구하는 방법이다. $p(x)=x^3-7x+7$ 의 양의 근은 $1.3569$ 와 $1.6920$ 으로 서로 가깝다. 계수열 $7,-7,0,1$ 의 부호 변화가 둘이므로 양의 근이 둘이거나 없다는 것만 알 뿐, 어느 구간에 있는지는 모른다. 이 알고리즘은 구간을 반씩 나누며 구간마다 부호 변화를 다시 세어, $(1,1.5)$ 와 $(1.5,2)$ 에 근이 하나씩 있다고 답한다.

# 직관

Descartes 부호 법칙은 $(0,\infty)$ 의 근만 센다. 구간 $(a,b)$ 의 근을 세려면 $(a,b)$ 를 $(0,\infty)$ 로 펴는 변수 변환을 쓴다. $x\mapsto(ax+b)/(x+1)$ 은 $x=0$ 을 $b$ 로, $x\to\infty$ 를 $a$ 로 보내고 그 사이를 일대일로 잇는다. 이 변환을 $p$ 에 넣고 분모를 없애면 새 다항식의 양의 근이 $p$ 의 $(a,b)$ 안의 근과 일대일로 대응한다.

$(0,8)$ 에서 시작한다. $8$ 은 [Cauchy 근 한계](cauchy-root-bound.md) $1+7$ 이다.

변환한 다항식의 계수 $463,-91,-35,7$ 의 부호 변화는 둘이다. 반으로 나눠 $(4,8)$ 의 계수 $463,649,293,43$ 은 부호 변화가 없어 근이 없다. $(0,4)$ 는 부호 변화가 둘이므로 다시 나눈다.

$(0,2)$ 는 둘, $(2,4)$ 는 없음, $(0,1)$ 은 없음, $(1,2)$ 는 둘이다. $(1,2)$ 를 나누면 $(1,1.5)$ 의 계수 $-0.125,-0.25,1,1$ 과 $(1.5,2)$ 의 계수 $1,0.5,-0.5,-0.125$ 는 부호 변화가 하나씩이다. 부호 변화가 하나이면 Descartes 부호 법칙으로 근이 정확히 하나다.

# 정의

## 구간의 Descartes 검사

$n$ 차 다항식 $p$ 와 구간 $(a,b)$ 에 대해 다음 다항식을 만든다.

$$
p_{(a,b)}(x)=(x+1)^n\thinspace p\left(\frac{ax+b}{x+1}\right)
$$

**Descartes 검사** 는 $p_{(a,b)}$ 의 계수열의 부호 변화의 수 $V(p_{(a,b)})$ 다. Descartes 부호 법칙에서 $Z$ 와 $V$ 의 관계가 그대로 옮겨져, $(a,b)$ 안의 근의 개수(중복도를 센다)는 $V(p_{(a,b)})$ 이하이고 차는 짝수다. 그래서 검사값이 $0$ 이면 근이 없고 $1$ 이면 근이 정확히 하나다.

직관 절의 예에서 $(1,1.5)$ 의 검사값은 $1$, $(1,2)$ 의 검사값은 $2$ 다.

## 이분 알고리즘

**Vincent–Collins–Akritas 알고리즘** 은 근이 모두 들어 있는 구간에서 시작해, 검사값이 $0$ 이면 버리고 $1$ 이면 결과에 넣고 $2$ 이상이면 가운데에서 둘로 나누어 두 반쪽을 다시 검사하는 반복이다. 가운데 점이 근이면 그 점을 따로 결과에 넣는다.

```javascript
// p 의 계수 c[0..n] (낮은 차수부터). (a, b) 안의 실근을 하나씩 가둔 구간의 목록을 만든다
function isolate(c, a, b, out) {
  const v = descartesTest(c, a, b); // (x+1)^n p((a x + b)/(x+1)) 의 부호 변화의 수
  if (v === 0) return;
  if (v === 1) { out.push([a, b]); return; }
  const m = (a + b) / 2;
  if (evaluate(c, m) === 0) out.push([m, m]);
  isolate(c, a, m, out);
  isolate(c, m, b, out);
}
```

음의 근은 $p(-x)$ 에 같은 알고리즘을 쓴다.

# 성질

## 원 하나와 원 둘 정리

정리. 지름이 $\lbrack a,b\rbrack$ 인 열린 원판 안에 $p$ 의 복소수 근이 없으면 $V(p_{(a,b)})=0$ 이다. $\lbrack a,b\rbrack$ 를 한 변으로 하는 두 정삼각형의 외접원 안쪽을 합친 영역에 $p$ 의 근이 단순근 하나뿐이면 $V(p_{(a,b)})=1$ 이다.[^1]

증명의 요지. 변환 $x\mapsto(ax+b)/(x+1)$ 은 허수축을 지름이 $\lbrack a,b\rbrack$ 인 원으로, 오른쪽 반평면을 그 원판으로 보낸다. 그래서 원판 밖의 근은 $p_{(a,b)}$ 의 실수부가 $0$ 이하인 근이 된다. 그런 근의 일차 인수 $x-\rho$ 와 켤레 근 쌍의 이차 인수 $x^2-2\mathrm{Re}\thinspace\rho\thinspace x+\lvert\rho\rvert^2$ 은 계수가 모두 $0$ 이상이므로, 곱한 $p_{(a,b)}$ 의 계수열에도 부호 변화가 없다. 원 둘 정리는 이 다항식에 양의 근 하나의 일차 인수를 곱해도 부호 변화가 하나만 생긴다는 데서 나온다.

## 종료

정리. $p$ 에 중근이 없으면 알고리즘은 유한 번 나눈 뒤 끝난다.

증명의 요지. 구간의 길이가 서로 다른 근 사이의 최소 거리보다 충분히 작아지면, 그 구간의 원판에는 근이 없거나 원 둘의 영역에 근이 하나만 있다. 원 하나와 원 둘 정리로 검사값이 $0$ 이나 $1$ 이 되어 더 나누지 않는다. 직관 절의 예에서 두 근의 거리는 $0.335$ 이고, 길이 $0.5$ 의 구간에서 두 근이 갈렸다.

중근이 있으면 그 근을 담은 구간의 검사값이 언제나 $2$ 이상이라 끝나지 않는다. 그래서 먼저 $p$ 를 $\gcd(p,p')$ 로 나누어 중근을 없앤다.

## Sturm 정리와의 비교

[Sturm 정리](sturm-theorem.md)는 Sturm 열을 한 번 만들어 두면 어느 구간의 근의 개수든 정확히 센다. Descartes 검사는 상한만 주지만, 검사에 쓰는 다항식이 $p$ 의 계수 변환뿐이고 나눗셈의 나머지 열을 만들지 않는다.

# 활용

- 컴퓨터 대수 시스템의 실근 분리. 정수 계수 다항식의 계수 변환은 정수 연산으로 정확히 할 수 있으므로, 결과 구간이 반올림 오차 없이 근을 하나씩 담는다는 것이 증명된다.
- 근의 정밀화의 시작. 근을 하나씩 가둔 구간을 얻으면 그 안에서 이분법이나 [Brent 법](brent-method.md)으로 근을 원하는 정밀도까지 구한다. 직관 절의 두 구간에서 이분법은 $1.35690$ 과 $1.69202$ 를 준다.
- 실대수 기하. 여러 다항식의 실근을 순서대로 늘어놓는 계산, 원통 대수 분해(cylindrical algebraic decomposition)의 한 단계가 일변수 실근 분리다.

[^1]: W. Krandick, K. Mehlhorn, "New bounds for the Descartes method", Journal of Symbolic Computation 41 (2006), 49–66.
