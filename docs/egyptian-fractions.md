# 이집트 분수

# 개요

**이집트 분수(Egyptian fraction)** 는 분자가 $1$ 인 서로 다른 분수들의 합으로 쓴 분수다. 빵 $4$ 개를 $5$ 명이 나누면 한 사람 몫은 $4/5$ 이고, 이것을 $1/2+1/4+1/20$ 으로 쓰면 빵마다 절반, 사분의 일, 이십분의 일로 자르는 방법이 된다.

양의 유리수는 모두 이렇게 쓸 수 있다. 남은 양보다 크지 않은 가장 큰 단위분수를 거듭 빼면 분자가 줄어들어 유한 번에 끝난다.

# 직관

$4/5$ 에서 뺄 수 있는 가장 큰 단위분수는 $1/2$ 이다. $1/1$ 은 $4/5$ 보다 크다. 빼고 남은 것은 $4/5-1/2=3/10$ 이다.

$3/10$ 에서 뺄 수 있는 가장 큰 단위분수는 $1/4$ 이다. $1/3=10/30$ 은 $3/10=9/30$ 보다 크다. 남은 것은 $3/10-1/4=1/20$ 이고 이미 단위분수다. 분자가 $4,3,1$ 로 줄었다.

# 정의

유리수 $x\gt 0$ 의 **이집트 분수 표현** 은 서로 다른 양의 정수 $n_1\lt n_2\lt\dots\lt n_k$ 에 대한 다음 등식이다.

$$
x=\frac{1}{n_1}+\frac{1}{n_2}+\cdots+\frac{1}{n_k}
$$

$1/n$ 꼴의 분수를 단위분수(unit fraction)라 한다. 직관 절의 예는 $4/5=1/2+1/4+1/20$ 이다.

**탐욕 알고리즘(greedy algorithm, Fibonacci–Sylvester 알고리즘)** 은 $x\le 1$ 에서 $1/n\le x$ 인 가장 작은 $n$ 을 골라 $1/n$ 을 빼는 일을 남은 양이 $0$ 이 될 때까지 되풀이하는 절차다. $x=a/b$ 이면 $n=\lceil b/a\rceil$ 이다.

```javascript
function egyptianGreedy(a, b) {
  // a/b, 0 < a <= b
  const denominators = [];
  while (a > 0) {
    const n = Math.ceil(b / a);
    denominators.push(n);
    [a, b] = [a * n - b, b * n]; // a/b - 1/n
    const g = gcd(a, b); // 유클리드 알고리즘
    a /= g;
    b /= g;
  }
  return denominators;
}
```

# 성질

## 탐욕 알고리즘의 종료

$0\lt a/b\le 1$ 에서 탐욕 알고리즘은 많아야 $a$ 단계에 끝나고, 나오는 분모는 서로 다르다.[^1]

증명의 요지. $n=\lceil b/a\rceil$ 이면 $n-1\lt b/a$ 이므로 $a(n-1)\lt b$ 이다. 남은 양은 $(an-b)/(bn)$ 이고 분자 $an-b$ 는 $a$ 보다 작다. 분자가 단계마다 줄어 [유클리드 알고리즘](euclidean-algorithm.md)처럼 유한 번에 $0$ 이 된다. 남은 양은 $1/(n-1)-1/n=1/(n(n-1))$ 보다 작아 $1/n$ 보다 작으므로 다음 분모는 $n$ 보다 크다.

$1$ 보다 큰 유리수는 단위분수를 $1/1$ 부터 차례로 더한 합이 한없이 커지므로 이 급수의 앞부분을 먼저 빼고 남은 $1$ 이하의 양에 탐욕 알고리즘을 쓴다.

## 표현의 개수와 분모의 크기

다음 등식으로 가장 큰 분모를 거듭 쪼개면 표현이 무한히 많다.

$$
\frac1n=\frac{1}{n+1}+\frac{1}{n(n+1)}
$$

탐욕 알고리즘은 항의 개수와 분모의 크기를 작게 만들지 않는다. $5/121$ 에서 탐욕 알고리즘은 분모 $25$, $757$, $763309$, $873960180913$ 과 $25$ 자리 수를 내지만, 같은 수가 $1/33+1/121+1/363$ 으로도 쓰인다.

## Sylvester 수열

$1$ 에서 탐욕적으로 단위분수를 빼되 마지막 항을 남기지 않고 계속하면 분모가 $2,3,7,43,1807,\dots$ 이다. 이 **Sylvester 수열(Sylvester's sequence)** 은 $s_1=2$, $s_{k+1}=s_k^2-s_k+1$ 로 정해지고, 다음이 성립한다.

$$
\frac{1}{s_1}+\cdots+\frac{1}{s_k}=1-\frac{1}{s_{k+1}-1}
$$

$k=4$ 이면 $1/2$, $1/3$, $1/7$, $1/43$ 의 합이 $1-1/1806$ 이다. 귀납 단계는 $s=s_k$ 로 둔 다음 계산이다.

$$
\frac{1}{s-1}-\frac1s=\frac{1}{s(s-1)}=\frac{1}{s_{k+1}-1}
$$

## Erdős–Straus 추측

**Erdős–Straus 추측(Erdős–Straus conjecture)** 은 $n\ge 2$ 마다 $4/n=1/x+1/y+1/z$ 를 만족하는 양의 정수 $x,y,z$ 가 있다는 추측이다. $4/5=1/2+1/4+1/20$ 이 $n=5$ 의 예다.

# 활용

- 고대 이집트의 Rhind 파피루스(Rhind papyrus)는 $2/n$ 을 단위분수의 합으로 쓴 표를 싣고 있다. $2/5=1/3+1/15$, $2/7=1/4+1/28$ 이 그 표의 첫 항목이다.
- Sylvester 수열은 탐욕 알고리즘의 분모가 단계마다 거의 제곱으로 커지는 예다. 단위분수 합으로 $1$ 에 가장 가까이 가되 넘지 않는 $k$ 항 합이 Sylvester 수열의 앞 $k$ 항이다.[^2]

[^1]: R. K. Guy, *Unsolved Problems in Number Theory*, 3rd ed., Springer, 2004, D11.
[^2]: D. R. Curtiss, "On Kellogg's Diophantine problem", *American Mathematical Monthly* **29** (1922), 380–387.
