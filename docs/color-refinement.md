# Color refinement

Color refinement는 각 정점의 현재 분류와 이웃들의 분류별 개수를 반복 비교하여 정점 구분을 세분화한다.

## 정의

유한 그래프의 정점 집합을 V, 정점 v의 이웃 집합을 N(v)라 하자. 0 이상의 정수 t는 반복 횟수이고 c_t(v)는 t번째 반복에서 v에 붙인 색이다. 색은 분류를 나타내는 기호다.

각 정점의 새 색은 자신의 기존 색과 이웃 색의 multiset으로 결정한다. multiset은 같은 색이 몇 번 나오는지도 보존한다.

$$
c_{t+1}(v)=\operatorname{ID}\left(c_t(v),\{\!\{c_t(u):u\in N(v)\}\!\}\right)
$$

ID는 서로 다른 입력 쌍에 서로 다른 새 색을 배정한다. 비교하는 두 그래프에는 같은 ID 규칙을 적용해야 한다. 실제 구현에서는 두 그래프의 분리 합집합 위에서 함께 색을 갱신하면 된다.

이 정점 단위 절차는 1-dimensional Weisfeiler–Leman refinement, 줄여서 1-WL이라고도 한다.

## 성질

이전 색을 새 입력에 포함하므로 이미 나뉜 색 부류는 다시 합쳐지지 않는다. 정점 수가 유한하면 결국 분할이 더 세분화되지 않는 안정 상태에 도달한다. 색 번호 자체가 같아지는 것을 종료 조건으로 삼을 필요는 없다.

동형사상은 각 단계의 색을 보존한다. 처음 라벨이 대응하고 이전 단계의 색이 대응하면, 이웃의 색별 개수도 대응하기 때문이다. 따라서 두 그래프의 색별 정점 수가 어느 단계에서 다르면 비동형이다.

반대 방향은 성립하지 않는다. 여섯 정점 순환과 분리된 삼각형 두 개에 모두 같은 초기 색을 주자. 모든 정점은 같은 색의 이웃 두 개를 가지므로 언제나 같은 새 색을 받는다. 두 그래프는 비동형이지만 이 절차로 구별되지 않는다.

여기서의 색은 인접 정점에 다른 색을 주는 그래프 색칠과 목적이 다르다. 이웃끼리 같은 색이어도 문제가 없다.

## 활용

그래프 동형 탐색의 후보 축소, 구조적 특징 계산, 이웃 집계 방식의 표현력 분석에 사용한다. 구별에 실패했다는 결과는 동형 증명서가 아니다.

## 기타 참고 문헌

- [Berkholz·Bonsma·Grohe, Tight Lower and Upper Bounds for the Complexity of Canonical Colour Refinement](https://arxiv.org/abs/1509.08251): 안정 분할과 정준적 refinement의 알고리즘.
- 위 동형 보존 논증은 반복 횟수에 대한 귀납이다. 여섯 정점 예시는 전 과정에서 색이 같게 남는 반례다.
