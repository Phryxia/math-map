# Gauss 소거법

# 개요

**Gauss 소거법(Gaussian elimination)** 은 연립일차방정식에서 한 식의 상수배를 다른 식에서 빼는 일을 정해진 순서로 되풀이해 미지수를 하나씩 없애는 방법이다. 미지수가 둘이면 한 식을 $y$ 에 대해 풀어 다른 식에 넣으면 되지만, 미지수가 셋이고 식이 셋이면 어느 식을 어느 미지수에 대해 풀지부터 정해야 하고 분수가 쌓인다. Gauss 소거법은 첫째 미지수를 첫째 식으로 아래 식들에서 지우고, 남은 식들에서 둘째 미지수를 지우는 일을 계수의 표만 보고 기계적으로 한다.

# 직관

다음 연립방정식을 푼다.

$$
x+y+z=6,\qquad 2x+y-z=1,\qquad x-y+2z=5
$$

첫째 식을 $x=6-y-z$ 로 풀어 둘째 식에 넣으면 $2(6-y-z)+y-z=1$, 곧 $-y-3z=-11$ 이다. 이 결과는 둘째 식에서 첫째 식의 $2$ 배를 뺀 것과 같다. 셋째 식에 넣은 결과 $-2y+z=-1$ 도 셋째 식에서 첫째 식을 뺀 것과 같다. 대입은 식의 상수배를 빼는 일이었다.

그러면 대입할 식을 고를 필요 없이, 위의 식으로 아래 식의 앞 미지수를 지우는 일만 반복한다. $-2y+z=-1$ 에서 $-y-3z=-11$ 의 $2$ 배를 빼면 $7z=21$ 이다. 식이 계단 모양이 되었으니 아래에서부터 $z=3$, $y=11-3z=2$, $x=6-y-z=1$ 로 푼다. 이 과정에서 미지수 이름은 쓰이지 않았고 계수와 우변만 바뀌었으므로 계산을 수의 표 위에서 할 수 있다.

# 정의

## 첨가행렬과 기본 행 연산

$m$ 개 식과 $n$ 개 미지수의 연립일차방정식 $Ax=b$ 에서 $A$ 의 오른쪽에 열 $b$ 를 붙인 $m\times(n+1)$ [행렬](matrices.md) $(A\mid b)$ 를 **첨가행렬(augmented matrix)** 이라 한다. 다음 세 연산을 **기본 행 연산(elementary row operation)** 이라 한다.

- 두 행을 바꾼다.
- 한 행에 $0$ 이 아닌 수를 곱한다.
- 한 행에 다른 행의 상수배를 더한다.

직관 절에서 둘째 식에서 첫째 식의 $2$ 배를 뺀 것은 첨가행렬의 둘째 행에 첫째 행의 $-2$ 배를 더한 셋째 연산이다.

## 행 사다리꼴

행렬의 각 행에서 처음으로 $0$ 이 아닌 성분을 그 행의 **피벗(pivot)** 이라 한다. 영행이 모두 아래에 있고, 아래 행의 피벗이 위 행의 피벗보다 오른쪽에 있으면 **행 사다리꼴(row echelon form)** 이라 한다. 여기에 피벗이 모두 $1$ 이고 피벗이 있는 열의 다른 성분이 모두 $0$ 이라는 조건을 더하면 **기약 행 사다리꼴(reduced row echelon form)** 이라 한다.

## 소거와 후진 대입

Gauss 소거법은 기본 행 연산으로 첨가행렬을 행 사다리꼴로 바꾸는 절차다. 왼쪽 열부터 피벗을 정하고, 피벗 아래 성분을 그 행의 상수배를 빼서 $0$ 으로 만든다. 피벗 자리가 $0$ 이면 아래의 $0$ 이 아닌 행과 바꾼다. 행 사다리꼴에서 아래 식부터 미지수를 구해 위 식에 넣는 것을 **후진 대입(back substitution)** 이라 한다.

```javascript
// A: m×n 계수, b: 길이 m 우변. 행 사다리꼴로 바꾸고 피벗 열을 돌려준다.
function eliminate(A, b) {
  const m = A.length, n = A[0].length;
  const pivots = [];
  let r = 0;
  for (let c = 0; c < n && r < m; c++) {
    const p = findRow(A, r, c);            // r 행 이하에서 c 열이 0 이 아닌 행
    if (p === -1) continue;                // 이 열에는 피벗이 없다
    swapRows(A, b, r, p);
    for (let i = r + 1; i < m; i++) {
      const f = A[i][c] / A[r][c];
      for (let j = c; j < n; j++) A[i][j] -= f * A[r][j];
      b[i] -= f * b[r];
    }
    pivots.push(c);
    r++;
  }
  return pivots;
}
```

직관 절의 예는 다음처럼 바뀐다.

$$
\left(\begin{array}{ccc|c}1&1&1&6\cr 2&1&-1&1\cr 1&-1&2&5\end{array}\right)\to\left(\begin{array}{ccc|c}1&1&1&6\cr 0&-1&-3&-11\cr 0&0&7&21\end{array}\right)
$$

오른쪽 행렬은 피벗이 $1,-1,7$ 인 행 사다리꼴이다. 셋째 행을 $7$ 로 나누고 위로 지워 나가면 기약 행 사다리꼴 $\left(\begin{array}{ccc|c}1&0&0&1\cr 0&1&0&2\cr 0&0&1&3\end{array}\right)$ 이 나오고, 마지막 열이 해 $(x,y,z)=(1,2,3)$ 이다.

# 성질

## 해집합의 보존

**정리.** 기본 행 연산은 연립방정식의 해집합을 바꾸지 않는다.

증명의 요지. 각 연산의 역이 같은 종류의 기본 행 연산이다. 행 $i$ 에 행 $j$ 의 $c$ 배를 더한 것은 $-c$ 배를 더해 되찾는다. 원래 식을 만족하는 $x$ 는 새 식을 만족하고, 역연산으로 그 반대도 성립한다.

## 해의 존재와 자유 변수

행 사다리꼴 $(U\mid d)$ 에서 피벗의 개수를 $r$ 이라 하자.

- $(0,\dots,0\mid c)$, $c\ne0$ 꼴의 행이 있으면 $0=c$ 라는 식이므로 해가 없다.
- 그런 행이 없으면 해가 있다. 피벗이 없는 열의 미지수 $n-r$ 개를 **자유 변수(free variable)** 로 두고 아무 값이나 주면, 후진 대입으로 나머지가 하나씩 정해진다.

해가 있으면 해집합은 해 하나 $x_0$ 에 $Ax=0$ 의 해 전체를 더한 $x_0+\ker A$ 이고, $\ker A$ 의 차원은 $n-r$ 이다. $r=n$ 이면 해는 많아야 하나다.

## 계수

피벗의 개수 $r$ 은 어떤 행 사다리꼴로 바꾸어도 같고, $A$ 의 열들이 생성하는 공간의 차원과 같다. 이 수를 $A$ 의 **계수(rank)** 라 한다. [선형사상](linear-maps.md)의 차원 정리 $\dim\ker A+\mathrm{rank}\thinspace A=n$ 은 위의 자유 변수 개수 $n-r$ 과 같은 내용이다. 기본 행 연산은 행들이 생성하는 공간을 바꾸지 않으므로 행의 계수와 열의 계수가 같다.

## 역행렬의 계산

정사각행렬 $A$ 에 단위행렬을 붙인 $(A\mid I)$ 를 기약 행 사다리꼴로 바꾼다. 왼쪽이 $I$ 가 되면 오른쪽이 $A^{-1}$ 이고, 왼쪽에 영행이 생기면 $A$ 는 가역이 아니다. 기본 행 연산 하나는 가역행렬 하나를 왼쪽에 곱하는 것이므로, 연산들의 곱 $E$ 가 $EA=I$ 를 주면 같은 $E$ 가 $I$ 를 $E=A^{-1}$ 로 바꾼다.

## 연산량

$n\times n$ 계에서 $k$ 번째 피벗 아래를 지우는 데 곱셈이 약 $(n-k)^2$ 번 들어 모두 약 $n^3/3$ 번이다. 후진 대입은 $n^2/2$ 번 정도다. 피벗 자리의 값이 $0$ 에 가까우면 반올림 오차가 커지므로 수치 계산에서는 절댓값이 큰 성분을 피벗으로 고르며, 이것은 [행렬 분해](matrix-factorizations.md)의 부분 피벗팅이다.

# 활용

- [행렬 분해](matrix-factorizations.md). 소거에서 쓴 곱셈 계수를 아래삼각행렬에 모으면 $A=LU$ 가 나오고, 우변이 바뀔 때마다 소거를 다시 하지 않는다.
- [행렬식](determinants.md). 행 교환 없이 행 사다리꼴 $U$ 로 바꾸면 $\det A$ 는 $U$ 의 피벗의 곱이고, 행을 한 번 바꿀 때마다 부호가 바뀐다.
- [체](fields.md). 소거에는 덧셈, 뺄셈, 곱셈과 피벗으로 나누는 연산만 쓰이므로 [유한체](finite-fields.md) 위의 연립방정식도 같은 절차로 풀린다.
- [격자 기반 후양자 암호](post-quantum-cryptography.md)의 LWE(learning with errors) 문제는 $As=b$ 의 우변에 작은 잡음을 더한 것이다. 잡음이 소거 단계마다 불어나므로 이 방법으로는 $s$ 가 구해지지 않는다.
- [삼중대각계](tridiagonal-systems.md)에서는 피벗 아래 성분이 하나뿐이어서 소거가 $O(n)$ 번의 연산으로 끝난다.
