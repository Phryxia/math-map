# 완전 다중격자

# 개요

**완전 다중격자(full multigrid)** 는 미분방정식을 가장 성긴 격자에서 먼저 풀고, 그 해를 한 단계 촘촘한 격자로 옮겨 시작값으로 쓰는 일을 가장 촘촘한 격자까지 되풀이하는 풀이 절차다. 간격 $h$ 의 격자에서 시작값을 $0$ 으로 두고 [다중격자](multigrid.md) 사이클을 돌리면, 오차가 이산화 오차(discretization error) $O(h^p)$ 까지 줄 때까지 돌리는 횟수가 미지수 개수와 함께 늘어난다. 완전 다중격자에서는 옮겨 온 시작값의 오차가 이미 그 격자의 이산화 오차 수준이므로 격자마다 사이클을 상수 번만 돌리고, 전체 연산량이 미지수 개수에 비례한다.

# 직관

간격 $h$ 의 격자에서 이산화한 해 $u_h$ 를 구한다. 미분방정식의 참해 $u$ 와의 차이는 이산화 차수 $p$ 에서 $\Vert u-u_h\Vert=O(h^p)$ 이므로, $u_h$ 를 그보다 훨씬 정확하게 구해도 참해와의 거리는 줄지 않는다. 목표는 $O(h^p)$ 까지다.

$-u''=\pi^2\sin(\pi x)$, $u(0)=u(1)=0$ 의 참해는 $u=\sin(\pi x)$ 다. 구간을 간격 $1/2$, $1/4$, $1/8$ 로 나눠 차분으로 바꾼 계의 해는 $x=1/2$ 에서 약 $1.234$, $1.053$, $1.013$ 이다. 참해 $1$ 과의 차이 $0.234$, $0.053$, $0.013$ 이 간격이 절반이 될 때마다 약 $4$ 분의 $1$ 이 되므로 $p=2$ 다.

간격 $2h$ 의 격자에서 같은 문제를 이미 풀어 두었다고 하자. 두 이산화 해는 각각 참해와 $O(h^p)$, $O((2h)^p)$ 떨어져 있으므로 $\Vert u_h-u_{2h}\Vert=O(h^p)$ 다. $u_{2h}$ 를 간격 $h$ 로 보간한 것을 초기 근사로 쓰면 초기 오차가 처음부터 $O(h^p)$ 이고, 사이클 한 번이면 목표를 넘어선다. 성긴 격자의 해는 같은 방법을 한 단계 더 성긴 격자에 써서 얻는다. 위의 예에서는 점 하나인 간격 $1/2$ 의 격자에서 $1.234$ 를 직접 구하고, 그것을 간격 $1/4$ 의 세 점으로 보간해 시작한다.

# 정의

## 절차

격자를 $l=L$(가장 성긴 것)부터 $l=0$(가장 촘촘한 것)까지 둔다. **완전 다중격자(full multigrid, FMG)** 는 가장 성긴 격자에서 직접 풀고, 그 해를 한 단계 촘촘한 격자로 보간해 시작값으로 삼아 V 사이클을 $\nu\_0$ 번 돌리는 일을 가장 촘촘한 격자까지 되풀이하는 절차다. `interpolate` 는 해 자체를 보간하는 사상이고, 사이클 안에서 보정을 보간하는 `prolong` 과 다르다.

```javascript
function fmg(level) {
  if (level === coarsest) return solveDirect(A[level], b[level])

  const xc = fmg(level + 1)
  let x = interpolate(level, xc)              // 해 자체의 보간

  for (let i = 0; i < nu0; i++) {
    x = vcycle(level, b[level], x)            // 상수 번의 사이클
  }
  return x
}
```

$\nu_0$ 은 격자 수와 무관한 상수이고 보통 $1$ 이나 $2$ 다. 직관 절의 예에서 $\nu_0=1$ 이면, 점 하나에서 직접 풀고, 점 셋으로 보간해 V 사이클을 한 번 돌리고, 점 일곱으로 보간해 V 사이클을 한 번 더 돌린다.

## 보간의 차수

매끄러운 함수를 보간했을 때 오차가 $O(h^q)$ 이면 그 보간의 **차수(order)** 가 $q$ 라 한다. 선형 보간의 차수는 $2$, 삼차 보간의 차수는 $4$ 다. 직관 절의 예에서 $\sin(\pi x)$ 를 $x=0$ 과 $x=1/4$ 의 값으로 선형 보간하면 $x=1/8$ 에서 $0.354$ 이고, 참값 $0.383$ 과 $0.029$ 차이가 난다. 같은 격자의 이산화 오차와 같은 규모다.

# 성질

## 보간 차수의 조건

`interpolate` 의 보간 오차는 이산화 오차보다 작아야 한다. 이산화 차수가 $p$ 이면 보간 차수는 $p$ 보다 높게 잡는다. 이차 이산화에서 선형 보간을 쓰면 보간 오차가 $O(h^2)$ 로 이산화 오차와 같은 크기여서 한 단계마다 상수 배로 쌓이므로, 삼차 이상의 보간을 쓴다.

## 연산량

**정리.** 각 단계에서 사이클을 상수 번 걸고 사이클 하나가 그 단계 미지수에 비례하면, 완전 다중격자 한 번의 연산량은 가장 촘촘한 격자의 미지수 $n$ 에 비례한다.

증명의 요지. 차원 $d$ 에서 단계 $l$ 의 미지수는 $2^{-ld}n$ 이다. 각 단계의 비용이 $c\thinspace\nu_0\thinspace2^{-ld}n$ 이므로 전체는

$$c\thinspace\nu_0\thinspace n\thinspace(1+2^{-d}+2^{-2d}+\dots)=\frac{c\thinspace\nu_0\thinspace n}{1-2^{-d}}$$

로 묶인다. ∎

반복 사이클은 같은 정확도에 $O(n\log n)$ 이 든다. 두 방법의 차이는 초기 근사 하나에서 온다.

## 이산화 오차의 달성

**정리.** 사이클의 감소 인자(reduction factor)가 $h$ 와 무관하게 $\rho\lt1$ 로 묶이고 `interpolate` 의 차수가 이산화 차수보다 높으면, 완전 다중격자가 내놓는 $x_h$ 는 모든 단계에서 $\Vert u_h-x_h\Vert\le C h^p$ 를 만족한다. 상수 $C$ 는 격자 수에 의존하지 않는다.[^1]

증명의 요지. 단계마다 귀납한다. 성긴 단계의 오차가 $Ch^p$ 이하라 두면, 보간 뒤의 오차는 그 값에 보간 오차와 두 이산화 해의 차이를 더한 것이고 둘 다 $O(h^p)$ 다. 사이클 $\nu_0$ 번이 이를 $\rho^{\nu_0}$ 배로 줄이므로, $\rho^{\nu_0}$ 이 보간과 이산화에서 더해지는 양을 상쇄할 만큼 작으면 같은 $C$ 로 다음 단계에 넘어간다. ∎

$\nu_0$ 을 정하는 조건이 이 상쇄다. 감소 인자가 나쁜 문제에서는 $\nu_0$ 을 키워야 하고, 연산량의 상수도 그만큼 커진다.

# 활용

- 타원 방정식의 해법. Poisson 방정식(Poisson equation)을 유한차분(finite difference)이나 [유한요소법](finite-element-method.md)으로 이산화한 계를 미지수 개수에 비례하는 연산으로 이산화 오차까지 푼다. 반복 사이클과 달리 정지 판정(stopping criterion)을 쓰지 않는다.
- 비선형 문제의 초기값. [Newton 법](newton-method.md)의 초기 근사를 성긴 격자에서 올려 주면 수렴 영역 안에서 시작하게 된다. [완전 근사 저장](full-approximation-scheme.md) 방식과 묶어 쓴다.
- 격자 적응의 기준. 두 단계의 해를 견주어 얻는 $\Vert x_h-x\_{2h}\Vert$ 가 이산화 오차의 추정값이 되고, 이 값으로 국소 격자 세분(local mesh refinement)을 판정한다. 한 격자의 해만으로 같은 판정을 하는 양이 [후처리 오차 추정자](a-posteriori-error-estimator.md)다.

[^1]: W. Hackbusch, *Multi-Grid Methods and Applications* (1985), 5장. 완전 다중격자의 정의, 연산량 정리, 보간 차수 조건과 이산화 오차 달성의 귀납 증명.
