# 준볼록 함수

# 개요

준볼록 함수는 수준집합이 모두 볼록인 함수다. [볼록](convexity.md) 함수보다 넓은 모임이고, 함숫값 사이의 부등식 대신 수준집합의 볼록성만 남긴다. 최소화는 수준집합이 비었는지 판정하는 볼록 문제의 이분 탐색으로 푼다.

# 직관

볼록 함수는 두 점을 이은 현이 그래프 위에 놓이는 함수다. $f(x)=\sqrt{\vert x\vert}$ 에 이 조건을 확인한다. $x=1$ 과 $x=4$ 를 이은 현의 중점 높이는 $(1+2)/2=1.5$ 이고, 중점에서의 함숫값은 $\sqrt{2.5}=1.581\ldots$ 이다. 현이 그래프 아래로 내려가므로 이 함수는 볼록이 아니다.

그런데 이 함수의 최소화는 어렵지 않다. $f(x)\le c$ 인 점을 모으면 구간 $\lbrack -c^2,c^2\rbrack$ 이고, 이 구간이 비지 않는 가장 작은 $c$ 가 최솟값이다. 현이 아래로 내려가도 수준집합은 구간으로 남아서, $c$ 를 줄여 가며 수준집합이 비는지만 보면 최솟값에 다가간다. 수준집합이 모두 볼록인 함수를 준볼록 함수라 한다.

# 정의

## 준볼록

볼록집합 $C$ 에서 정의된 $f\colon C\to\mathbb R$ 가 **준볼록**이라는 것은 모든 $c\in\mathbb R$ 에 대해 수준집합

$$
S_c=\lbrace x\in C: f(x)\le c\rbrace
$$

이 볼록인 것이다. 동치인 조건은 모든 $x,y\in C$ 와 $0\le\lambda\le 1$ 에 대해

$$
f(\lambda x+(1-\lambda)y)\le\max\lbrace f(x),f(y)\rbrace
$$

이다. $-f$ 가 준볼록이면 $f$ 를 **준오목**이라 한다.

## 엄격 준볼록

$x\neq y$ 와 $0\lt \lambda\lt 1$ 에서 위 부등식이 등호 없이 성립하면 $f$ 를 **엄격 준볼록**이라 한다.

# 성질

## 볼록성과의 관계

**정리.** 볼록 함수는 준볼록이고, 역은 성립하지 않는다.

$f$ 가 볼록이면 $x,y\in S_c$ 에서 $f(\lambda x+(1-\lambda)y)\le\lambda f(x)+(1-\lambda)f(y)\le c$ 이므로 $S_c$ 가 볼록이다. 역의 반례는 $f(x)=\sqrt{\vert x\vert}$ 다. 수준집합이 $\lbrack -c^2,c^2\rbrack$ 으로 모두 구간이지만 직관 절의 계산이 볼록성을 깨뜨린다. ∎

## 1차 조건

**정리.** $C$ 가 열린 볼록집합이고 $f$ 가 미분가능이면, $f$ 가 준볼록인 것은 모든 $x,y\in C$ 에 대해 $f(y)\le f(x)$ 가 $\nabla f(x)^{T}(y-x)\le 0$ 을 함의하는 것과 동치다[^1].

함의가 성립한다고 하자. $f(y)\le f(x)$ 인 두 점에서 선분 위의 값이 $f(x)$ 를 넘는 점이 있으면 그 점에서 선분 방향의 미분이 부호를 바꾸어야 하고, 함의가 그것을 막는다. 거꾸로 $f$ 가 준볼록이면 $f(y)\le f(x)$ 에서 선분 위 값이 $f(x)$ 이하이므로 $x$ 에서 $y$ 방향의 방향도함수가 양수가 되지 못한다. ∎

볼록 함수의 1차 조건은 $f(y)\ge f(x)+\nabla f(x)^{T}(y-x)$ 로 함숫값의 하한을 주지만, 준볼록의 1차 조건은 더 낮은 점의 방향만 제한한다.

## 국소 최솟값

**정리.** 준볼록 함수의 국소 최솟값은 전역 최솟값이 아닐 수 있다. 엄격 준볼록 함수에서는 국소 최솟값이 전역 최솟값이다.

반례는 $f(0)=0$ 이고 $x\neq 0$ 에서 $f(x)=1$ 인 함수다. 수준집합은 $\lbrace 0\rbrace$ 또는 $\mathbb R$ 이므로 준볼록이고, $x=5$ 는 근방에서 상수 $1$ 이라 국소 최솟값이지만 전역 최솟값은 $0$ 이다. 엄격 준볼록일 때 $f(x_0)$ 가 국소 최솟값이고 $f(y)\lt f(x_0)$ 이면 선분 위 점에서 $f$ 가 $f(x_0)$ 보다 작아져 국소 최소성과 어긋난다. ∎

## 이분 탐색

최솟값이 구간 $\lbrack l,u\rbrack$ 에 있다고 알면, $c$ 마다 $S_c$ 가 비었는지 판정하는 볼록 문제를 풀어 구간을 반씩 줄인다. 폭 $\epsilon$ 까지 줄이는 데 $\lceil\log_2((u-l)/\epsilon)\rceil$ 회의 판정이 든다[^1].

```javascript
function quasiconvexMinimize(isFeasible, l, u, eps) {
  while (u - l > eps) {
    const c = (l + u) / 2
    if (isFeasible(c)) u = c   // S_c 가 비지 않음
    else l = c
  }
  return u
}
```

`isFeasible(c)` 는 볼록집합 $S_c$ 에서 점을 하나 찾는 실행가능성 문제다. 준볼록 문제 하나가 볼록 문제 여러 개로 바뀐다.

# 활용

- **선형 분수 계획법.** $e^{T}x+g\gt 0$ 인 영역에서 $f(x)=(c^{T}x+d)/(e^{T}x+g)$ 는 준볼록이고, 수준집합 $S_t$ 가 부등식 $c^{T}x+d\le t(e^{T}x+g)$ 로 쓰이므로 각 판정이 [선형계획법](linear-programming.md)의 실행가능성 문제다.
- **조건수 최소화.** 행렬의 최대 고윳값과 최소 고윳값의 비를 설계 변수로 줄이는 문제가 준볼록이고, 수준집합이 반정부호 조건으로 쓰인다.
- **효용 이론.** 경제학의 선호 관계가 볼록일 때 그것을 나타내는 효용함수는 준오목이고, 준오목성이 무차별 곡선 위쪽 집합의 볼록성과 같은 조건이다.

[^1]: S. Boyd, L. Vandenberghe, *Convex Optimization*, Cambridge University Press, 2004, 3.4 절과 4.2.5 절.
