# 불완전 LU 분해

# 개요

희소 행렬을 Gauss 소거로 분해하면 원래 $0$ 이던 자리에 값이 생긴다. 이 채움 때문에 삼각인자가 원 행렬보다 훨씬 빽빽해지고 저장 공간이 모자란다.

**불완전 $LU$ 분해**는 비영 자리를 미리 정해 두고 그 밖에 생기는 값을 버린다. 결과는 $A$ 의 분해가 아니지만 $M=LU$ 를 [전처리](preconditioning.md) 행렬로 쓰기에는 충분하다.

# 직관

한 변에 $N$ 개씩 격자점을 놓은 $2$ 차원 5점 차분 행렬을 본다. 크기는 $n=N^2$ 이고 행마다 비영이 다섯 개이므로 저장량이 $5n$ 이다.

이 행렬에 Gauss 소거를 하면 어떻게 되는지 센다. 비영은 대각에서 떨어진 거리가 최대 $N$ 인 띠 안에만 있고, 소거는 띠 밖으로 값을 내보내지 않지만 띠 안은 거의 다 채운다. 삼각인자의 저장량이 $O(nN)=O(n^{3/2})$ 이고, $N=1000$ 이면 원 행렬의 $200$ 배다. 격자를 촘촘히 할수록 비율이 커지므로 분해를 그대로 쓸 수 없다.

소거는 그대로 하되 원래 $0$ 이던 자리에 값이 생기면 그 값을 버린다. 저장량은 $5n$ 으로 고정되고, 대신 $LU$ 가 $A$ 와 같지 않아 $A=LU-R$ 에서 잔차 $R$ 이 남는다.

$R$ 이 남아도 손해가 아니다. 전처리 행렬에 요구되는 것은 $A$ 와 같아지는 것이 아니라 $M^{-1}A$ 의 고윳값이 $1$ 근처로 모이는 것이고, $M^{-1}v$ 를 삼각계 두 번 풀이로 빨리 계산할 수 있으면 된다. 버린 값이 작으면 두 조건이 함께 성립한다.

# 정의

## 무늬와 분해

행렬 $A$ 와 지표 집합 $S\subseteq\lbrace 1,\dots,n\rbrace^2$ 에 대해 **불완전 $LU$ 분해**(incomplete LU factorization, ILU)는 아래삼각 $L$ 과 위삼각 $U$ 로

$$
A=LU-R,\qquad L\_{ij}=U\_{ij}=0\thickspace((i,j)\notin S),\qquad R\_{ij}=0\thickspace((i,j)\in S)
$$

를 만족하는 것이다. $S$ 밖에서는 인자가 $0$ 이고 $S$ 안에서는 곱이 $A$ 와 일치한다.

절차는 Gauss 소거와 같고 $(i,j)\notin S$ 에 값이 생길 때마다 버린다.

```javascript
// A 는 n x n 행렬, S 는 (i,j) 를 받아 참거짓을 주는 무늬
function ilu(A, S, n) {
  const M = A.map((row) => row.slice())
  for (let k = 0; k < n; k++) {
    for (let i = k + 1; i < n; i++) {
      if (!S(i, k)) continue
      M[i][k] = M[i][k] / M[k][k]
      for (let j = k + 1; j < n; j++) {
        if (!S(i, j)) continue
        M[i][j] = M[i][j] - M[i][k] * M[k][j]
      }
    }
  }
  return M // 아래삼각부가 L 의 비대각, 위삼각부가 U
}
```

## 무늬를 고르는 방법

$S$ 를 $A$ 의 비영 자리로 잡은 것이 $\mathrm{ILU}(0)$ 이다.

소거가 만드는 채움에 준위를 매겨 넓히면 $\mathrm{ILU}(k)$ 가 된다. $A$ 의 비영 자리에 준위 $0$ 을 주고, 준위 $p$ 와 $q$ 인 자리의 곱으로 생긴 채움에 준위 $p+q+1$ 을 준다. 준위가 $k$ 이하인 자리만 남긴다.

무늬 대신 크기로 거르는 방법이 $\mathrm{ILUT}$(ILU with threshold) 다. 소거 도중 나온 값이 그 행 노름의 $\tau$ 배보다 작으면 버리고, 남은 것 가운데 큰 것부터 행마다 $p$ 개만 지킨다.

## 불완전 Cholesky 분해

$A$ 가 대칭 양정부호이면 같은 절차를 Cholesky 분해에 적용해 $A=LL^{\mathsf T}-R$ 을 얻는다. 이것이 **불완전 Cholesky 분해**이고 저장량이 $\mathrm{ILU}$ 의 절반이다.

# 성질

## 존재

비대각 성분이 모두 $0$ 이하이고 역행렬의 성분이 모두 $0$ 이상인 행렬을 **M-행렬**이라 한다.

**정리.** $A$ 가 M-행렬이면 임의의 무늬 $S$ 에 대해 $\mathrm{ILU}$ 가 존재하고 $L$ 과 $U$ 가 모두 가역이다.[^1]

소거 단계마다 남은 부분행렬이 다시 M-행렬임을 보인다. 값을 버리는 연산은 비대각 성분을 $0$ 쪽으로 올리므로 M-행렬의 부호 조건을 깨지 않고, 대각 축은 양수로 남는다. ∎

대칭 양정부호만으로는 존재가 보장되지 않는다. 축이 음수가 되어 절차가 끊기는 예가 있고, 이때는 대각에 $\alpha$ 를 더한 $A+\alpha I$ 를 분해한다.

## 수정 불완전 분해

버린 값을 그 행의 대각에 더하면 $R$ 의 행합이 $0$ 이 되고

$$
(LU)\thinspace\mathbf 1=A\thinspace\mathbf 1
$$

이 성립한다. 이것이 **수정 불완전 $LU$ 분해**(modified ILU, MILU)다. 상수에 가까운 벡터가 오차에서 정확히 재현되므로 타원형 문제에서 조건수 상한이 $O(h^{-2})$ 에서 $O(h^{-1})$ 로 내려간다.[^2]

## 정렬 의존성

같은 행렬이라도 미지수의 번호를 바꾸면 채움의 자리가 달라지고 분해의 품질이 달라진다. 5점 차분 행렬에서 빨강-검정 정렬은 병렬 계산에 유리하지만 자연 정렬보다 수렴이 느리다.

전처리 품질과 병렬성이 정렬에서 맞서므로 문제마다 정렬을 따로 고른다.

# 활용

- **전처리된 공액기울기법.** 대칭 양정부호 희소계에서 불완전 Cholesky 분해를 $M$ 으로 쓴다. 반복마다 드는 추가 비용은 삼각계 두 번 풀이이고 $A$ 와 같은 차수의 연산이다.
- **비대칭 계의 반복 풀이.** 이류-확산 방정식처럼 대칭성이 깨진 계에서 $\mathrm{ILUT}$ 를 [Krylov 부분공간 방법](krylov-subspace-methods.md)의 전처리로 쓴다.
- **다단계 전처리의 성긴 단계.** [다중격자](multigrid.md)의 가장 성긴 격자에서 직접 풀이 대신 불완전 분해를 쓰면 성긴 계가 커도 비용이 선형으로 유지된다.
- **선형계 반복 풀이 라이브러리의 기본값.** 문제의 구조를 모르는 상태에서 쓸 전처리로 $\mathrm{ILU}(0)$ 이나 $\mathrm{ILUT}$ 가 선택된다. 무늬와 임계값 두 매개변수만 정하면 되고 행렬의 성긴 구조만 있으면 적용된다.

[^1]: J. Meijerink, H. van der Vorst, "An iterative solution method for linear systems of which the coefficient matrix is a symmetric M-matrix", *Math. Comp.* **31** (1977).
[^2]: I. Gustafsson, "A class of first order factorization methods", *BIT* **18** (1978). 수정 분해의 조건수 개선이 여기서 나왔다. 무늬 준위와 $\mathrm{ILUT}$ 를 포함한 서술은 Y. Saad, *Iterative Methods for Sparse Linear Systems*, 2판 (2003), 10장.
