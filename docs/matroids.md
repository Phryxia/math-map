# Matroid

# 개요

"서로 독립이다" 라는 말이 두 곳에서 따로 쓰인다. [벡터 공간](vector-spaces.md)에서는 어느 벡터도 나머지의 일차결합이 아니라는 뜻이고, [그래프](graphs.md)에서는 간선들이 순환을 만들지 않는다는 뜻이다. 그런데 두 개념이 같은 정리를 만족한다. 극대인 독립집합의 크기가 모두 같고, 작은 독립집합은 큰 것에서 원소를 빌려 키울 수 있다.

Matroid 는 이 공통점만 추려 낸 구조다. 기반이 되는 대상을 지우고 "어떤 부분집합이 독립인가" 라는 정보만 남긴다. 그러면 기저, 차원, 계수 같은 선형대수의 개념이 그대로 살아나고, 무엇보다 탐욕 알고리즘이 최적해를 주는 조건이 정확히 이 구조라는 정리가 나온다.

탐욕법이 언제 통하는지에 대한 답이라는 점이 이 개념의 실용적 가치다. [최소 신장트리](minimum-spanning-tree.md)에서 Kruskal 알고리즘이 최적인 이유가 그래프가 matroid 를 이루기 때문이고, 통하지 않는 문제는 대개 이 구조가 없다.

# 직관

## 독립성만 남긴다

벡터 목록에서 실제 좌표를 지우고 "어느 부분집합이 일차독립인가" 만 기록한다고 하자. 놀랍게도 이 정보만으로 계수, 기저, 차원을 정의할 수 있고 관련 정리들이 그대로 성립한다. 좌표는 계산에 필요했을 뿐 구조의 본질이 아니었던 것이다.

같은 기록을 그래프의 간선에 대해 만들면 순환 없는 부분집합들이 나오고, 이 역시 동일한 공리를 만족한다. 서로 무관해 보이는 두 대상이 같은 추상 구조의 실현이며, 이 추상화가 자동으로 정리들을 공유하게 해 준다.

## 교환 공리가 핵심이다

세 공리 중 앞의 둘은 사소하다. 공집합이 독립이고 독립집합의 부분집합도 독립이라는 것은 어떤 합리적인 독립성 개념이든 만족한다. 그런 족을 독립성 체계라 부른다.

진짜 내용은 교환 공리다. 크기가 다른 두 독립집합이 있으면 작은 쪽이 큰 쪽에서 원소 하나를 빌려 커질 수 있다. 이것이 "막다른 골목이 없다" 는 보장이고, 탐욕법이 잘못된 선택으로 갇히지 않는 이유다.

공리가 깨지는 예를 보면 이해가 빠르다. 경로 그래프의 세 정점 $v_1 - v_2 - v_3$ 에서 서로 인접하지 않은 정점들을 독립이라 하자. $\lbrace v_2\rbrace$ 와 $\lbrace v_1, v_3\rbrace$ 이 모두 독립인데, $\lbrace v_2\rbrace$ 에 $v_1$ 도 $v_3$ 도 더할 수 없다. 교환 공리가 깨지고, 실제로 탐욕법이 실패한다.

# 정의

## 독립성 공리

$E$ 를 유한 집합, $I$ 를 $E$ 의 부분집합들의 모임이라 하자. 다음 셋을 만족하면 $(E, I)$ 를 matroid 라 하고 $I$ 의 원소를 독립집합이라 한다.

- $\emptyset \in I$
- $A \in I$ 이고 $B \subseteq A$ 이면 $B \in I$
- 교환 공리:

$$
A,B\in I,\ |A|<|B|\ \Rightarrow\ \exists e\in B\setminus A:\ A\cup\lbrace e\rbrace\in I
$$

독립이 아닌 집합을 종속집합, 극소 종속집합을 순환이라 한다.

## 기저와 계수

극대 독립집합을 기저라 한다. 부분집합 $S \subseteq E$ 의 계수 $r(S)$ 는 $S$ 안에 들어 있는 독립집합의 최대 크기다. $r(E)$ 를 matroid 의 계수라 한다.

## 표준적인 예

| 이름 | $E$ | 독립집합 |
|---|---|---|
| 선형 matroid | 벡터 목록의 인덱스 | 일차독립인 부분집합 |
| 그래프 matroid | 간선 집합 | 순환 없는 부분집합 |
| 균등 matroid | 임의의 유한집합 | 크기가 $k$ 이하인 부분집합 |
| 분할 matroid | 여러 부류로 나뉜 집합 | 각 부류에서 정해진 개수 이하 |
| 횡단 matroid | 이분 그래프의 한쪽 | 매칭으로 덮이는 부분집합 |

연결 그래프에서 그래프 matroid 의 기저가 신장트리다.

# 성질

## 모든 기저의 크기가 같다

크기가 다른 두 기저가 있다면 교환 공리로 작은 쪽에 원소를 더해 독립성을 유지할 수 있으므로 극대성에 모순이다. 선형대수에서 "기저의 크기가 차원으로 잘 정의된다" 는 정리가 여기서는 공리에서 한 줄로 나온다.

## 계수 함수

계수 함수는 다음을 만족하며, 거꾸로 이 성질들이 matroid 를 정의하기도 한다.

$$
r(\emptyset)=0,\qquad r(S)\le r(S\cup\lbrace e\rbrace)\le r(S)+1
$$

$$
r(S\cup T)+r(S\cap T)\le r(S)+r(T)
$$

마지막 줄이 열등모듈성이다. "원소를 하나 더할 때의 이득이 이미 가진 것이 많을수록 작다" 는 수확체감 성질이며, 이 성질을 가진 함수의 최적화는 일반적으로 다항시간에 풀린다. matroid 가 다루기 쉬운 근본적인 이유가 여기 있고, 열등모듈 최적화라는 더 넓은 분야로 이어진다.

## 탐욕 정리

각 원소에 가중치 $w(e) \ge 0$ 을 주고 독립집합 중 가중치 합이 최대인 것을 찾는 문제를 보자. 무거운 원소부터 훑으며 독립성을 유지하면 넣는 탐욕 알고리즘이 항상 최적해를 준다.

역도 성립한다. 독립성 체계에서 모든 가중치에 대해 탐욕법이 최적이면 그 체계는 matroid 다. 즉 matroid 는 "탐욕법이 통하는 구조" 의 정확한 특징이다.

위의 경로 그래프 예에서 가운데 가중치를 $3$ 으로, 양 끝을 각각 $2$ 로 주면 탐욕법은 가운데만 골라 $3$ 을 얻지만 최적해는 $4$ 다. 교환 공리가 깨진 대가가 정확히 이 만큼 드러난다.

```python
def greedy_max(ground, indep, weight):
    """무거운 순서로 훑으며 독립성을 유지하면 채택한다."""
    chosen = []
    for e in sorted(ground, key=weight, reverse=True):
        if indep(chosen + [e]):
            chosen.append(e)
    return chosen, sum(weight(e) for e in chosen)


def brute_max(ground, indep, weight):
    from itertools import combinations
    best = ([], 0)
    for k in range(len(ground) + 1):
        for c in combinations(ground, k):
            if indep(list(c)) and sum(map(weight, c)) > best[1]:
                best = (list(c), sum(map(weight, c)))
    return best


# 균등 matroid: 크기 2 이하면 독립
U = ["a", "b", "c", "d"]
w1 = {"a": 5, "b": 4, "c": 3, "d": 1}
print(greedy_max(U, lambda S: len(S) <= 2, w1.get))
print(brute_max(U, lambda S: len(S) <= 2, w1.get))     # 일치

# matroid 가 아닌 경우: 경로 v1 - v2 - v3 의 독립집합
V = ["v1", "v2", "v3"]
adj = {("v1", "v2"), ("v2", "v1"), ("v2", "v3"), ("v3", "v2")}
ok = lambda S: all((x, y) not in adj for x in S for y in S)
w2 = {"v1": 2, "v2": 3, "v3": 2}
print(greedy_max(V, ok, w2.get))                        # (['v2'], 3)
print(brute_max(V, ok, w2.get))                         # (['v1','v3'], 4)
```

## 쌍대와 마이너

기저의 여집합들을 기저로 삼으면 다시 matroid 가 되고 이를 쌍대 matroid 라 한다. 그래프 matroid 의 쌍대는 평면 그래프에서 쌍대 그래프의 matroid 와 일치하며, 이 대응이 평면성의 조합적 특징을 준다.

원소를 지우거나 축약해 얻는 마이너도 matroid 다. 어떤 matroid 가 벡터로 실현되는지, 그래프로 실현되는지가 금지된 마이너의 목록으로 특징지어진다는 것이 이 이론의 주요 결과다.

## 교차는 훨씬 어렵다

두 matroid에서 동시에 독립인 집합 중 최대를 찾는 matroid 교차 문제는 다항시간에 풀린다. 이분 매칭과 분지 문제가 그 특수한 경우다. 그러나 세 개가 되면 NP-난해다. 셋 이상에서는 탐욕적 구조가 남지 않는다는 뜻이며, 조합 최적화에서 다루기 쉬움과 어려움의 경계가 이 지점에 놓인다.

# 활용

## 알고리즘 설계의 판정 기준

새 문제에서 탐욕법을 쓰고 싶을 때 "제약이 matroid 를 이루는가" 를 먼저 확인한다. 이루면 최적성이 증명 없이 따라오고, 이루지 않으면 반례가 있을 가능성이 높아 다른 기법을 찾아야 한다. Kruskal 알고리즘, 작업 스케줄링에서 마감시간을 지키는 작업 집합 선택, 자원 배분의 여러 변형이 matroid 로 설명된다.

## 여러 분야의 공통 언어

선형대수의 계수, 그래프의 순환 구조, 조합론의 횡단 조건이 하나의 언어로 통합된다. 그래서 한쪽에서 증명한 정리를 다른 쪽으로 옮길 수 있다. Rado 의 정리는 Hall 의 결혼 정리를 matroid 로 일반화한 것이고, matroid 교차 정리는 König 의 정리와 최대유량 최소절단 정리를 함께 포함한다.

## 열등모듈 최적화

matroid 의 계수 함수가 열등모듈이라는 관찰에서 출발해, 열등모듈 함수의 최소화와 최대화를 다루는 분야가 자랐다. 센서 배치, 요약문 선택, 영향력 최대화 같은 문제가 이 틀에서 근사비 보장을 얻는다. matroid 제약 아래 열등모듈 함수를 최대화하면 $1 - 1/e$ 근사가 가능하다는 결과가 그 대표적인 예다.[^1]

[^1]: Michel X. Goemans, *Lecture notes on matroid optimization*. 독립성 공리, 그래프와 선형 matroid 예시, 탐욕 정리. https://math.mit.edu/~goemans/18433S09/matroid-notes.pdf
