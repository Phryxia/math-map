# B-스플라인

# 개요

**B-스플라인(B-spline)** 은 낮은 차수의 다항식 조각을 매끄럽게 이어 붙인 곡선을 제어점의 가중합으로 적는 방법이다. 제어점 다섯 개로 [Bézier 곡선](bezier-curves.md)을 그리면 곡선은 $4$ 차 다항식 하나이고, 첫 제어점을 옮기면 끝점을 뺀 곡선 전체가 움직인다. 긴 곡선을 그리면서 한 부분만 고치려면 조각마다 따로 그리고 이음매를 맞춰야 한다. B-스플라인은 각 제어점의 무게를 짧은 구간에서만 $0$ 이 아니게 잡아, 이음매가 저절로 매끄럽고 제어점 하나가 곡선의 일부만 움직이게 한다.

# 직관

제어점 $P_0=(0,0)$, $P_1=(1,2)$, $P_2=(3,2)$, $P_3=(4,0)$ 의 꺾은선을 놓는다. 변마다 가운데 점을 찍으면 $M_0=(0.5,1)$, $M_1=(2,2)$, $M_2=(3.5,1)$ 이다. 이제 $M_0,P_1,M_1$ 을 제어점으로 하는 $2$ 차 Bézier 곡선과 $M_1,P_2,M_2$ 를 제어점으로 하는 $2$ 차 Bézier 곡선을 그린다.

두 곡선은 $M_1$ 에서 만난다. 앞 곡선의 끝 접선은 $2(M_1-P_1)=P_2-P_1$ 이고 뒤 곡선의 첫 접선은 $2(P_2-M_1)=P_2-P_1$ 이므로 이음매에서 접선이 같다. 가운데 점을 이음매로 쓰면 접선이 저절로 맞는다.

$P_0$ 을 옮기면 $M_0$ 만 바뀌므로 앞 곡선만 움직이고 뒤 곡선은 그대로다. 제어점을 더 늘려도 같은 방법으로 조각을 이어 가면 된다.

앞 곡선을 원래 제어점으로 적으면 $u\in\lbrack 0,1\rbrack$ 에서 다음이다.

$$
C(u)=\frac{(1-u)^2}{2}P_0+\frac{1+2u-2u^2}{2}P_1+\frac{u^2}{2}P_2
$$

무게 셋은 음이 아니고 더하면 $1$ 이다. 정의 절의 Cox–de Boor 점화식이 이 무게를 조각마다 만들어 준다.

# 정의

## 매듭과 기저 함수

감소하지 않는 수열 $t_0\le t_1\le\cdots\le t_m$ 을 **매듭 벡터(knot vector)** 라 하고 각 $t_i$ 를 매듭이라 한다. 차수 $p$ 의 **B-스플라인 기저 함수(B-spline basis function)** $N_{i,p}$ 는 다음 **Cox–de Boor 점화식(Cox–de Boor recursion)** 으로 정의한다. 분모가 $0$ 인 항은 $0$ 으로 둔다.

$$
N_{i,0}(t)=\begin{cases}1 & t_i\le t\lt t_{i+1}\cr 0 & \text{그 밖}\end{cases}
$$

$$
N_{i,p}(t)=\frac{t-t_i}{t_{i+p}-t_i}N_{i,p-1}(t)+\frac{t_{i+p+1}-t}{t_{i+p+1}-t_{i+1}}N_{i+1,p-1}(t)
$$

매듭이 $0,1,2,3$ 이면 $2$ 차 기저 함수 $N_{0,2}$ 는 세 조각으로 된다.

$$
N_{0,2}(t)=\begin{cases}t^2/2 & 0\le t\lt 1\cr (-2t^2+6t-3)/2 & 1\le t\lt 2\cr (3-t)^2/2 & 2\le t\lt 3\end{cases}
$$

$t=1$ 과 $t=2$ 에서 양쪽 값이 $1/2$ 이고 도함수가 각각 $1$ 과 $-1$ 로 같다. 매듭 간격이 모두 $1$ 이면 $N_{i,2}(t)=N_{0,2}(t-i)$ 이고, 직관 절의 세 무게는 $t=2+u$ 에서 $N_{0,2}$, $N_{1,2}$, $N_{2,2}$ 의 값이다.

## B-스플라인 곡선

제어점 $P_0,\dots,P_n$ 과 매듭 $t_0,\dots,t_{n+p+1}$ 이 정하는 차수 $p$ 의 B-스플라인 곡선은 다음이다.

$$
C(t)=\sum_{i=0}^{n}N_{i,p}(t)\thinspace P_i,\qquad t_p\le t\le t_{n+1}
$$

직관 절의 곡선은 $p=2$, $n=3$, 매듭 $0,1,\dots,6$ 인 경우이고 정의역은 $2\le t\le 4$ 다.

```javascript
// 차수 p, 매듭 배열 knots 에서 N_{i,p}(t) 를 Cox–de Boor 점화식으로 계산한다
function basis(i, p, t, knots) {
  if (p === 0) return knots[i] <= t && t < knots[i + 1] ? 1 : 0;
  const a = knots[i + p] - knots[i];
  const b = knots[i + p + 1] - knots[i + 1];
  const left = a === 0 ? 0 : ((t - knots[i]) / a) * basis(i, p - 1, t, knots);
  const right = b === 0 ? 0 : ((knots[i + p + 1] - t) / b) * basis(i + 1, p - 1, t, knots);
  return left + right;
}
```

# 성질

## 국소 지지와 단위 분할

$N_{i,p}$ 는 구간 $\lbrack t_i,t_{i+p+1})$ 밖에서 $0$ 이고 안에서 음이 아니다. $p$ 에 대한 귀납법으로, 점화식의 첫 항은 $t_i$ 와 $t_{i+p}$ 사이에서만, 둘째 항은 $t_{i+1}$ 과 $t_{i+p+1}$ 사이에서만 $0$ 이 아니므로 성립한다.

$t_p\le t\le t_{n+1}$ 에서 $\sum_i N_{i,p}(t)=1$ 이다. 점화식을 $i$ 에 대해 더하면 $N_{i,p-1}$ 의 계수 둘이 더해 $1$ 이 되므로 차수를 하나씩 내려 $p=0$ 의 합 $1$ 에 닿는다.

## 국소 제어와 볼록 껍질

구간 $\lbrack t_j,t_{j+1})$ 에서 $0$ 이 아닌 기저 함수는 $N_{j-p,p},\dots,N_{j,p}$ 의 $p+1$ 개뿐이다. 그래서 이 구간의 곡선 조각은 제어점 $P_{j-p},\dots,P_j$ 만으로 정해지고 그 점들의 볼록 껍질 안에 있다. 제어점 $P_i$ 를 옮기면 곡선은 $\lbrack t_i,t_{i+p+1})$ 에서만 바뀐다.

## 이음매의 매끄러움

매듭 $t_i$ 가 매듭 벡터에 $k$ 번 되풀이되면 기저 함수는 그 점에서 $p-k$ 번 연속미분 가능하다. 직관 절처럼 $p=2$ 이고 매듭이 겹치지 않으면 이음매에서 도함수까지 연속이다. 매듭을 $p$ 번 겹치면 곡선이 그 점에서 제어점을 지나고 꺾일 수 있다.

## 도함수

B-스플라인 곡선의 도함수는 차수가 $p-1$ 인 B-스플라인 곡선이다.

$$
C'(t)=\sum_{i=0}^{n-1}\frac{p\thinspace(P_{i+1}-P_i)}{t_{i+p+1}-t_{i+1}}\thinspace N_{i+1,p-1}(t)
$$

## Bézier 곡선과의 관계

매듭 벡터가 $0$ 을 $p+1$ 번, $1$ 을 $p+1$ 번 되풀이한 것이면 $N_{i,p}$ 는 Bernstein 기저 $\binom pi t^i(1-t)^{p-i}$ 이고 B-스플라인 곡선은 제어점이 같은 $p$ 차 Bézier 곡선이다. 매듭을 하나 더 넣어 제어점을 늘리는 **매듭 삽입(knot insertion)** 을 내부 매듭마다 다중도가 $p$ 가 될 때까지 되풀이하면, 곡선을 조각별 Bézier 곡선으로 나눈 제어점이 나온다.

## Curry–Schoenberg 정리

매듭 벡터 $t_0,\dots,t_{n+p+1}$ 이 주어지면, $\lbrack t_p,t_{n+1}\rbrack$ 에서 매듭 사이마다 차수 $p$ 이하의 다항식이고 각 매듭에서 위의 매끄러움 조건을 만족하는 함수 전체는 $n+1$ 차원 벡터 공간이고, $N_{0,p},\dots,N_{n,p}$ 가 그 기저다. 이것을 **Curry–Schoenberg 정리(Curry–Schoenberg theorem)** 라 한다[^1]. 이런 함수를 **스플라인(spline)** 이라 한다.

# 활용

- 3차 스플라인 보간. 같은 간격의 매듭에서 $3$ 차 기저 함수는 세 매듭에서 값 $1/6$, $2/3$, $1/6$ 을 갖고 나머지 매듭에서 $0$ 이다. 자료점을 지나도록 제어점을 정하는 연립방정식은 대각선이 $2/3$ 이고 이웃이 $1/6$ 인 [삼중대각 연립방정식](tridiagonal-systems.md)이다.
- 컴퓨터 보조 설계. 제어점마다 무게를 붙여 유리함수로 만든 NURBS(non-uniform rational B-spline)는 원과 타원을 정확히 나타내고, 설계 소프트웨어의 곡선과 곡면이 이 꼴로 저장된다.
- 평활 스플라인. 통계에서 자료에 맞추는 곡선을 B-스플라인 기저의 결합으로 두고 이계도함수의 제곱 적분을 벌점으로 더해 계수를 정한다.
- 등기하 해석(isogeometric analysis). 유한요소법의 기저 함수로 설계에 쓴 B-스플라인을 그대로 써서, 곡면을 다시 격자로 근사하지 않고 편미분방정식을 푼다.

[^1]: C. de Boor, *A Practical Guide to Splines*, revised ed., Springer, 2001.
