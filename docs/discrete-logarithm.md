# 이산로그와 Diffie–Hellman

# 개요

[합동 연산](modular-arithmetic.md)에서 거듭제곱은 빠르다. `g^x \bmod p` 는 반복 제곱으로 `O(\log x)` 번의 곱셈이면 된다. 그런데 그 역, 즉 `g^x \equiv h` 인 `x` 를 찾는 일은 어렵다고 믿어진다.

이 비대칭이 현대 암호의 한 축이다. 실수 위의 로그는 뉴턴법으로 금방 구해지지만, 유한 [군](groups.md) 위에서는 값들이 순서 없이 흩어져 있어 크기를 비교해 좁혀 갈 수 없다. 국소적 정보로 전역해를 향해 나아갈 방법이 없다는 것이 어려움의 본질이다.

Diffie 와 Hellman 은 1976 년에 이 비대칭으로 공개 채널에서 비밀키를 합의하는 방법을 제시했다. 두 사람이 각자 비밀 지수를 고르고 거듭제곱한 값만 주고받으면, 도청자는 지수를 모르므로 같은 값에 도달할 수 없다. 비밀을 미리 나누지 않고도 비밀을 만들 수 있다는 이 발상이 공개키 암호를 열었다.

# 직관

## 순서가 없으면 이분 탐색도 없다

실수에서 `2^x = 1000` 을 풀 때는 `x` 를 키우면 값이 커진다는 단조성을 쓴다. 시행착오가 빠르게 수렴한다.

`\bmod p` 에서는 `g^1, g^2, g^3, \dots` 가 `1` 과 `p-1` 사이를 무작위처럼 튄다. `g^x` 가 목표보다 크다는 사실이 `x` 에 대해 아무것도 말해 주지 않는다. 결국 다 해 보거나 다른 구조를 찾아야 한다.

## 중간에서 만나기

그래도 완전 탐색보다는 나은 방법이 있다. `x = im + j` 로 쪼개면 `g^x = h` 가 `g^j = h\,g^{-im}` 이 된다. 왼쪽을 `m` 개 만들어 표에 넣고 오른쪽을 하나씩 만들며 표를 찾으면, `m \approx \sqrt p` 에서 두 작업이 균형을 이룬다.

$$
O(p)\ \longrightarrow\ O(\sqrt p)
$$

제곱근으로 줄어들지만 여전히 지수 시간이다. 비트 길이 `n` 에 대해 `2^{n/2}` 이므로 `n` 을 두 배로 늘리면 안전성이 회복된다.

```mermaid

  A["완전 탐색 O(p)"] --> B["Baby-step giant-step<br/>O(√p) 시간, O(√p) 공간"]
  B --> C["Pollard rho<br/>O(√p) 시간, O(1) 공간"]
  C --> D["Pohlig-Hellman<br/>군 위수의 소인수로 분해"]
  D --> E["지표 계산법<br/>준지수 시간, 유한체에서만"]
```

## 왜 군의 위수가 소수여야 하는가

군의 위수 `N` 이 작은 소수들의 곱이면 문제가 쉬워진다. Pohlig–Hellman 이 각 소인수 `q` 마다 문제를 크기 `q` 의 부분문제로 쪼개고 중국인의 나머지 정리로 합치기 때문이다. 그러면 난이도가 `\sqrt N` 이 아니라 가장 큰 소인수의 제곱근으로 결정된다.

그래서 실무에서는 위수가 큰 소수이거나 큰 소인수를 가지는 군을 쓴다. `p` 가 소수여도 곱셈군의 위수는 `p-1` 로 짝수이므로, `p = 2q+1` 인 안전 소수를 고르거나 위수 `q` 인 부분군으로 제한한다.

# 정의

## 문제

순환군 `G = \langle g\rangle` 의 위수를 `N` 이라 하자. 이산로그 문제는 주어진 `h \in G` 에 대해 다음을 만족하는 `x \in \mathbb Z/N\mathbb Z` 를 찾는 것이다.

$$
g^x=h
$$

`G` 가 `(\mathbb Z/p\mathbb Z)^\times` 이면 `N = p-1` 이고, 타원곡선군이면 곱셈 표기가 덧셈 표기로 바뀌어 `xP = Q` 를 푸는 문제가 된다.

## 관련된 세 문제

| 문제 | 주어진 것 | 구할 것 |
|---|---|---|
| 이산로그 (DL) | `g, g^a` | `a` |
| 계산적 Diffie–Hellman (CDH) | `g, g^a, g^b` | `g^{ab}` |
| 판정적 Diffie–Hellman (DDH) | `g, g^a, g^b, z` | `z = g^{ab}` 인가 |

DL 을 풀면 CDH 를 풀고, CDH 를 풀면 DDH 를 푼다. 역방향은 일반적으로 알려져 있지 않으며, 이것이 별개의 가정으로 다뤄지는 이유다. 실제로 DDH 가 쉬우면서 CDH 는 어렵다고 믿어지는 군이 존재한다. 쌍선형 사상을 가진 타원곡선이 그런 예이고, 이 성질이 오히려 새로운 암호 구성의 재료가 되었다.

## Diffie–Hellman 키 교환

공개 파라미터 `(G, g, N)` 을 두고 진행한다.

1. 앨리스가 `a` 를 무작위로 고르고 `A = g^a` 를 보낸다.
2. 밥이 `b` 를 무작위로 고르고 `B = g^b` 를 보낸다.
3. 앨리스는 `B^a`, 밥은 `A^b` 를 계산한다.

$$
B^a=g^{ba}=g^{ab}=A^b
$$

도청자는 `g, g^a, g^b` 를 보지만 `g^{ab}` 를 얻으려면 CDH 를 풀어야 한다.

## 계산

```python
import math, random

p, g = 1000003, 2          # p 는 소수, g 는 원시근 후보

def bsgs(g, h, p):
    """Shanks 의 baby-step giant-step: g^x = h (mod p) 를 O(sqrt(p)) 에."""
    m = math.isqrt(p - 1) + 1
    table = {}
    e = 1
    for j in range(m):                       # baby step: g^j
        table.setdefault(e, j)
        e = e * g % p
    factor = pow(g, -m, p)                   # g^{-m}
    e = h
    for i in range(m):                       # giant step: h * g^{-im}
        if e in table:
            return i * m + table[e]
        e = e * factor % p
    return None

x_true = 726431
h = pow(g, x_true, p)
x = bsgs(g, h, p)
print("찾은 x:", x, " 검증:", pow(g, x, p) == h)

# Diffie-Hellman: 두 사람이 같은 비밀을 얻는다
rng = random.Random(7)
a, b = rng.randrange(2, p - 1), rng.randrange(2, p - 1)
A, B = pow(g, a, p), pow(g, b, p)            # 공개로 주고받는 값
print("공유 비밀 일치:", pow(B, a, p) == pow(A, b, p) == pow(g, a * b, p))
# 찾은 x: 726431  검증: True
# 공유 비밀 일치: True
```

백만 규모에서는 표가 천 개 남짓이라 즉시 끝난다. 안전한 크기는 `p` 가 2048 비트 이상이며, 그때 `\sqrt p` 는 `2^{1024}` 로 접근이 불가능하다.

# 성질

## 일반 군에서의 하한

군의 연산만 쓰고 원소의 표현을 들여다보지 않는 알고리즘을 일반 군 알고리즘이라 한다. Shoup 의 결과에 따르면 위수가 소수 `q` 인 군에서 이런 알고리즘은 `\Omega(\sqrt q)` 번의 연산을 필요로 한다.

따라서 baby-step giant-step 과 Pollard rho 는 이 모형에서 최적이다. 더 빠른 알고리즘이 있다면 반드시 군 원소의 구체적 표현을 이용해야 한다.

## 유한체에서는 준지수 시간

`(\mathbb Z/p\mathbb Z)^\times` 는 원소가 정수로 표현되므로 그 구조를 쓸 수 있다. 지표 계산법은 작은 소수들의 곱으로 쪼개지는 원소를 모아 선형방정식을 세운 뒤 로그를 한꺼번에 구한다. 시간이 다음 형태다.

$$
L_p[1/3,c]=\exp\Big((c+o(1))(\ln p)^{1/3}(\ln\ln p)^{2/3}\Big)
$$

정수 소인수분해와 같은 형태이며, 실제로 두 문제의 최선 알고리즘이 같은 뼈대를 공유한다. 그래서 RSA 와 유한체 Diffie–Hellman 의 권장 키 길이가 비슷하다.

작은 표수의 유한체에서는 더 나쁘다. 2013 년 이후 준다항식 시간 알고리즘이 나와 `\mathbb F_{2^n}` 기반 구성은 사실상 폐기되었다.

## 타원곡선에서는 그렇지 않다

타원곡선군에는 "작은 소수로 쪼개진다" 에 해당하는 개념이 없어 지표 계산법이 적용되지 않는다. 그래서 최선의 공격이 여전히 `O(\sqrt N)` 이다.

결과가 키 길이의 차이로 나타난다. 128 비트 보안을 위해 유한체는 3072 비트가 필요하지만 타원곡선은 256 비트면 된다. 대역폭과 계산량이 크게 줄어들어 현대 프로토콜이 타원곡선 쪽으로 옮겨 간 이유다.

다만 곡선을 잘못 고르면 무너진다. 이상 곡선이나 MOV 공격에 취약한 작은 매장 차수의 곡선이 그런 예이며, 표준 곡선을 쓰는 이유가 여기 있다.

## 중간자 공격

Diffie–Hellman 자체는 인증을 제공하지 않는다. 중간에 있는 공격자가 양쪽과 각각 키 교환을 하면 두 세션을 모두 읽으면서 중계할 수 있다.

그래서 실제 프로토콜은 서명이나 사전 공유 비밀로 교환 값을 인증한다. TLS 에서 서버 인증서로 `g^b` 에 서명하는 것이 그 절차다. 수학적 난제가 안전성을 보장하는 범위가 어디까지인지를 보여 주는 사례다.

## 순방향 비밀성

세션마다 새 `a, b` 를 뽑고 끝나면 버리는 방식을 임시 Diffie–Hellman 이라 한다. 장기 키가 나중에 유출되어도 지난 세션의 내용은 복호할 수 없다. 지난 세션의 비밀은 이미 없어진 `a, b` 에만 의존하기 때문이다.

RSA 키 전송 방식에는 이 성질이 없다. 서버의 개인키가 유출되면 기록해 둔 과거 트래픽이 전부 풀린다. TLS 1.3 이 키 전송 방식을 제거하고 임시 Diffie–Hellman 만 남긴 이유다.

## 양자 컴퓨터

Shor 알고리즘은 소인수분해뿐 아니라 이산로그도 다항시간에 푼다. 두 문제 모두 숨은 부분군 문제의 특수한 경우이고, 양자 Fourier 변환이 주기를 찾아낸다.

따라서 충분한 규모의 양자 컴퓨터가 나오면 Diffie–Hellman 과 타원곡선 암호가 함께 무너진다. 타원곡선으로 옮기는 것은 도움이 되지 않는다. 격자나 부호 기반의 후양자 암호로 전환이 진행 중인 배경이다.

# 활용

## 키 합의 프로토콜

TLS, SSH, Signal, WireGuard 가 모두 Diffie–Hellman 을 핵심 부품으로 쓴다. 대칭키 암호는 빠르지만 키를 미리 나눠야 하고, 그 키를 나누는 일을 공개 채널에서 해결하는 것이 이 프로토콜의 역할이다.

Signal 의 이중 래칫은 메시지마다 새 교환을 수행해 순방향 비밀성과 침해 후 복구를 동시에 얻는다.

## 서명과 다른 구성

ElGamal 암호와 DSA, ECDSA 서명이 같은 가정 위에 서 있다. 서명에서는 난수 재사용이 즉시 개인키 노출로 이어지는 것이 알려진 함정이며, 실제 사고가 여러 번 있었다. 결정론적 난수 생성을 규정한 RFC 6979 이 그 대응이다.

## 암호 밖의 쓰임

이산로그 계산 자체가 유한체와 대수군의 구조를 조사하는 계산 도구다. 곡선의 위수를 세거나 군의 구조를 결정하는 알고리즘의 부품으로 쓰인다. Pollard rho 와 kangaroo 방법은 일반적인 충돌 탐색 기법이기도 해서 해시 함수 분석에도 등장한다.
