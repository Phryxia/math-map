# 축약사상 고정점 정리

# 개요

방정식을 푼다는 것은 `f(x) = 0` 을 만족하는 `x` 를 찾는 일이다. 이것을 `x = T(x)` 꼴로 고쳐 쓰면 "적용해도 변하지 않는 점" 을 찾는 문제가 된다. 두 형태는 언제나 서로 바꿔 쓸 수 있다.

축약사상 고정점 정리는 `T` 가 거리를 일정 비율로 줄이기만 하면 그런 점이 정확히 하나 있고, 아무 데서나 시작해 반복하면 거기에 도달한다고 말한다. [완비성](completeness.md)이 극한의 존재를 주고 [연속성](continuity.md)이 그 극한이 실제로 고정점임을 준다.

이 정리의 가치는 결론의 강함보다 가정의 검증 가능성에 있다. "해가 존재하는가" 를 직접 다루는 대신 "각 단계가 오차를 일정 비율로 줄이는가" 만 확인하면 된다. 게다가 증명이 구성적이라 알고리즘과 오차 한계가 함께 나온다.

# 직관

## 줄어들면 모인다

`T` 를 적용할 때마다 두 점 사이의 거리가 `q < 1` 배로 줄어든다면, 한 점에서 출발한 반복열의 이웃 항 간격도 `q` 배씩 줄어든다. 간격이 등비급수를 이루므로 총 이동 거리가 유한하고, 수열은 한곳으로 수렴할 수밖에 없다.

유일성은 더 간단하다. 고정점이 둘이면 그 거리가 자기 자신의 `q` 배 이하여야 하는데 `q < 1` 이므로 거리가 `0` 이다.

## 가정 하나하나가 필요하다

세 가정 중 무엇을 빼도 결론이 무너진다.

| 빠진 가정 | 반례 |
|---|---|
| 완비성 | `(0,1)` 에서 `T(x) = x/2`. 고정점 `0` 이 공간 밖 |
| $q < 1$ (엄밀한 축약) | $\mathbb{R}$ 에서 $T(x) = x + 1/(1+e^x)$ . $\lvert T(x)-T(y) \rvert < \lvert x-y \rvert$ 이지만 고정점 없음 |
| $T(X) \subseteq X$ | 정의역을 벗어나면 반복 자체가 정의되지 않음 |

두 번째 줄이 특히 중요하다. "거리가 줄어든다" 로는 부족하고 "일정 비율 이하로 줄어든다" 여야 한다. 비율이 `1` 에 한없이 가까워지면 등비급수가 발산해 수렴 논증이 깨진다. 컴팩트 공간에서는 이 약한 조건으로도 결론이 성립하지만 일반적으로는 아니다.

## 오차를 미리 알 수 있다

정리가 실용적인 이유는 수렴만 말하지 않기 때문이다. 첫 걸음의 크기와 `q` 만 알면 `n` 번째 반복의 오차 상한이 계산된다. 알고리즘을 돌리기 전에 필요한 반복 횟수를 예측할 수 있고, 돌리는 중에는 이웃 항의 간격으로 현재 오차를 추정할 수 있다.

# 정의

## 축약사상

$X$ 를 비어 있지 않은 완비 거리 공간, $d$ 를 그 거리, $T : X \to X$ 를 함수라 하자. 어떤 $0 < q < 1$ 이 있어 모든 $x, y \in X$ 에 대해

$$
d(Tx,Ty)\le q\,d(x,y)
$$

이면 `T` 를 축약사상이라 하고 `q` 를 축약 계수라 한다. 고정점은 `T(p) = p` 인 점이다.

축약사상은 Lipschitz 상수가 `q < 1` 인 함수이므로 항상 연속이다. 연속성을 따로 가정할 필요가 없다.

# 성질

## 정리와 증명

**정리.** 위 조건에서 고정점은 정확히 하나 존재하며, 임의의 시작점 $x_0$ 에서 $x_{n+1} = T(x_n)$ 으로 반복하면 그 고정점으로 수렴한다.

이웃 항의 거리는 $d(x_{k+1}, x_k) \le q^k d(x_1, x_0)$ 이므로 $m > n \ge 0$ 에 대해 삼각부등식과 등비급수로

$$
d(x_m,x_n)\le\sum_{k=n}^{m-1}q^k d(x_1,x_0)\le\frac{q^n}{1-q}\,d(x_1,x_0)
$$

를 얻는다. 우변이 $0$ 으로 가므로 반복열은 Cauchy 이고, 완비성으로 극한 $p$ 가 존재한다. $T$ 가 연속이므로 $x_{n+1} = T(x_n)$ 의 양변에 극한을 취하면 $p = T(p)$ 다.

서로 다른 고정점 $p, r$ 이 있다면 $d(p,r) = d(Tp,Tr) \le q \cdot d(p,r)$ 이라 $d(p,r) = 0$ 이다.

## 오차 한계

위 부등식에서 $m \to \infty$ 를 보내면 선험적 한계를 얻는다.

$$
d(x_n,p)\le\frac{q^n}{1-q}\,d(x_1,x_0)
$$

같은 논법을 `n` 번째 항에서 다시 시작하면 후험적 한계가 나온다.

$$
d(x_n,p)\le\frac{q}{1-q}\,d(x_n,x_{n-1})
$$

전자는 시작 전에 필요한 반복 횟수를 계산할 때, 후자는 반복 중에 종료 조건을 판정할 때 쓴다. 실무에서 "이웃 항의 차이가 충분히 작으면 멈춘다" 는 관례가 정당화되는 근거가 후자이며, `q` 가 `1` 에 가까우면 `q/(1-q)` 가 커져 그 관례가 위험해진다는 것도 함께 알려 준다.

## 수렴 속도

$d(x_n, p) \le q^n d(x_0, p)$ 이므로 오차가 매 단계 상수 배로 줄어드는 선형 수렴이다. 유효 자릿수가 일정하게 늘어난다.

[Newton 법](newton-method.md)은 이보다 빠른 이차 수렴을 보인다. 해 근처에서 축약 계수가 `0` 으로 가기 때문이며, 그 대가로 시작점이 충분히 가까워야 한다는 조건이 붙는다. 전역 수렴을 보장하는 느린 방법과 국소 수렴만 보장하는 빠른 방법 사이의 거래가 수치해석 전반에 걸쳐 나타난다.

```python
def fixed_point(T, x0, q, tol=1e-12, max_iter=200):
    x = x0
    for n in range(1, max_iter + 1):
        nxt = T(x)
        gap = abs(nxt - x)
        if q / (1 - q) * gap < tol:          # 후험적 오차 한계
            return nxt, n
        x = nxt
    return x, max_iter


# T(x) = (x+2)/3, q = 1/3, 고정점 1
print(fixed_point(lambda x: (x + 2) / 3, 0.0, 1 / 3))

# cos 의 고정점 (Dottie 수). [0,1] 에서 |sin| <= sin(1) < 1
import math
print(fixed_point(math.cos, 0.5, math.sin(1.0)))

# 반복 몇 번 만에 오차가 얼마인가: 선험적 한계
q, d10 = 1 / 3, abs((0 + 2) / 3 - 0)
for n in (5, 10, 20):
    print(n, q ** n / (1 - q) * d10)
```

$(x+2)/3$ 은 $0$ 에서 시작해 $2/3, 8/9, 26/27$ 을 거쳐 $1$ 로 간다. $\cos$ 은 $[0,1]$ 을 자기 안으로 보내고 그 위에서 $\lvert \cos' \rvert = \lvert \sin \rvert \le \sin(1) \approx 0.841 < 1$ 이므로 축약사상이며, 계수가 $1$ 에 가까워 수렴이 느리다.

## 변형

- **반복 축약.** `T` 자체는 축약이 아니어도 어떤 `T^m` 이 축약이면 같은 결론이 성립한다. 적분방정식에서 자주 쓰이는 형태다.
- **국소 판정.** 닫힌 공 $\bar{B}(x_0, r)$ 을 자기 안으로 보내는 축약이면 그 공 안에 고정점이 있다. $d(x_0, Tx_0) \le (1-q)r$ 을 확인하면 된다.
- **매개변수 의존.** `T` 가 매개변수에 연속적으로 의존하면 고정점도 그렇다. 음함수 정리의 증명이 이 사실을 쓴다.

# 활용

## 미분방정식의 해

초기값 문제 $y' = f(t,y)$ , $y(t_0) = y_0$ 를 적분해

$$
y(t)=y_0+\int_{t_0}^t f(s,y(s))\,ds
$$

로 바꾸면, 우변이 연속함수 공간 위의 사상이 된다. `f` 가 `y` 에 대해 Lipschitz 이면 구간을 충분히 짧게 잡아 이 사상을 축약으로 만들 수 있고, `C[a,b]` 가 sup 거리에서 완비이므로 정리가 적용된다.

이것이 Picard–Lindelöf 정리이며 [상미분방정식](ordinary-differential-equations.md)의 해의 존재와 유일성을 준다. 함수공간 위에서 고정점을 찾는다는 발상이 핵심이고, 같은 기법이 적분방정식과 편미분방정식의 약해 이론으로 확장된다.

## 수치 알고리즘

비선형 방정식의 반복해법, 선형계의 Jacobi 와 Gauss–Seidel 반복, 강화학습의 가치 반복이 모두 축약사상의 반복이다. 가치 반복에서 Bellman 작용소가 할인율 $\gamma < 1$ 을 계수로 하는 축약이며, 그 사실 하나가 최적 가치함수의 존재와 유일성, 그리고 수렴 속도를 동시에 준다.

## 정의의 정당화

프랙탈을 축약사상들의 모임에 대한 불변집합으로 정의하는 반복함수계, 재귀적으로 정의된 함수나 자료형이 실제로 존재함을 보이는 논증, 게임이론의 균형 존재 증명이 모두 어떤 완비 공간에서 고정점을 찾는 형태다. "이렇게 정의된 대상이 정말 있는가" 라는 질문을 "이 사상이 축약인가" 로 바꿔 놓는 것이 이 정리의 일반적 쓰임이다.[^1]

[^1]: Jiří Lebl, *Basic Analysis*, Fixed point theorem and Picard's theorem again. 축약사상 고정점 정리의 증명과 미분방정식 응용. https://www.jirka.org/ra/html/sec_metpicard.html
