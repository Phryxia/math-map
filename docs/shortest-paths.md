# 최단경로와 Bellman 방정식

# 개요

가중 유향그래프에서 출발점 `s` 로부터 각 정점까지의 최단거리 `d(v)` 를 구하는 문제는, 경로를 하나하나 세는 대신 **거리 함수가 만족해야 하는 방정식**을 푸는 문제로 바꿀 수 있다.

$$
d(s)=0,\qquad d(v)=\min_{(u,v)\in E}\bigl(d(u)+w(u,v)\bigr)
$$

이것이 **Bellman 방정식**이다. 좌우 양쪽에 미지의 `d` 가 있으므로 정의가 아니라 고정점 방정식이고, [동적 계획법](dynamic-programming.md)이 하는 일은 이 방정식을 푸는 것이다. 그래프가 DAG 면 위상순서대로 한 번 훑어 풀리지만, 사이클이 있으면 그럴 수 없다. 대신 **반복**한다. 모든 거리를 $\infty$ 로 두고 방정식의 우변을 좌변에 대입하기를 되풀이하면 값이 단조 감소하고, 음수 사이클이 없으면 `|V|-1` 단계 안에 멈춘다. Bellman–Ford 알고리즘이다.

이 반복은 [영역 이론](domain-theory.md)의 고정점 반복과 같은 구조다. 값이 작아지는 방향을 "정보가 늘어나는 방향" 으로 읽으면, $\infty$ 가 $\bot$ 이고 각 반복이 `F` 한 번의 적용이며 안정화가 고정점 도달이다. 차이는 사슬이 유한 단계에 멈춘다는 것이고, 멈추지 않는 경우가 정확히 **음수 사이클**이다. 알고리즘의 종료 조건과 이론의 수렴 조건이 같은 것을 가리킨다.

# 직관

## 간선 하나를 더 쓸 기회를 준다

`d_k(v)` 를 "간선을 `k` 개 이하 쓰는 경로의 최단길이" 라 하자. 그러면

$$
d_0(v)=\begin{cases}0,&v=s\\ \infty,&\text{그 외}\end{cases},
\qquad
d_{k}(v)=\min\Bigl(d_{k-1}(v),\ \min_{(u,v)\in E}\bigl(d_{k-1}(u)+w(u,v)\bigr)\Bigr)
$$

이다. `k` 를 하나 늘리는 것은 모든 간선에 "지금보다 짧게 만들 수 있으면 그렇게 하라" 고 한 번씩 기회를 주는 것이다. 이 완화(relaxation)를 `|V|-1` 번 하면 끝난다. 음수 사이클이 없으면 최단경로는 정점을 반복하지 않으므로 간선을 `|V|-1` 개보다 많이 쓸 이유가 없기 때문이다.

```mermaid
flowchart LR
  D0["d_0 : s 만 0,<br/>나머지 무한대"] --> D1["d_1"] --> D2["d_2"] --> DK["..."] --> DN["d_{n-1} = 최단거리"]
  DN -->|"한 번 더 줄어들면"| NEG["음수 사이클"]
```

## 왜 `|V|-1` 번이면 충분한가

최단경로가 존재한다면 단순경로로 고를 수 있고, 단순경로의 간선 수는 최대 `|V|-1` 이다. `d_k` 가 간선 `k` 개 이하의 경로를 모두 고려하므로 `k=|V|-1` 에서 답이 확정된다.

그러므로 `|V|` 번째 반복에서 값이 또 줄어들면 간선을 `|V|` 개 쓰는 더 짧은 걸음이 있다는 뜻이고, 그런 걸음은 정점을 반복하므로 사이클을 품는다. 그 사이클의 가중치 합은 음수여야 한다. **종료 판정이 곧 음수 사이클 검출**인 이유다.

## 고정점으로 읽기

$D=(\mathbb R\cup\{\pm\infty\})^{V}$ 위에 "값이 작을수록 정보가 많다" 는 순서를 주고

$$
F(d)(v)=\begin{cases}0,&v=s\\ \min_{(u,v)\in E}\bigl(d(u)+w(u,v)\bigr),&\text{그 외}\end{cases}
$$

로 두면, 값 반복은 $F^k(\bot)$ 의 사슬이다. $\bot$ 은 `s` 에서만 `0` 이고 나머지가 $\infty$ 인 배열이다. `F` 는 단조이고(값이 작아지면 $\min$ 도 작아진다) 연속이므로 [Kleene 반복](domain-theory.md)이 그대로 적용된다.

음수 사이클이 있으면 사슬이 아래로 끝없이 내려간다. 극한은 그 사이클에서 도달 가능한 정점에서 $-\infty$ 이고, 이것도 고정점이긴 하다. "답이 없다" 가 아니라 "답이 $-\infty$ 다" 로 이론이 닫히는 것이 고정점 관점의 이점이다.

한편 방정식의 해는 유일하지 않다. `s` 에서 도달할 수 없는 정점에는 아무 값이나 넣어도 부등식이 깨지지 않는 경우가 있다. 참된 거리 함수를 뽑아내는 조건은 다음과 같다.

$$
d(s)\le0,\quad d(v)\le d(u)+w(u,v)\ \ \forall(u,v)\in E
$$

를 만족하는 것 중 **점별로 가장 큰 것**이 최단거리다. 이 서술은 그대로 선형계획의 형태이고, 그 쌍대가 흐름 문제가 된다.

# 정의

## 문제

유향그래프 `G=(V,E)` 와 가중치 $w\colon E\to\mathbb R$, 출발점 $s\in V$ 가 주어진다. 경로의 길이를 간선 가중치의 합으로 정의하고

$$
d(v)=\inf\{\,\text{길이}(P)\ :\ P\ \text{는}\ s\to v\ \text{경로}\,\}
$$

로 둔다. 도달할 수 없으면 $\infty$, 음수 사이클을 거쳐 갈 수 있으면 $-\infty$ 다.

## Bellman–Ford

```
d[s] = 0, 나머지는 무한대
|V| - 1 번 반복:
    모든 간선 (u,v) 에 대해  d[v] = min(d[v], d[u] + w(u,v))
한 번 더 반복해서 값이 줄어드는 간선이 있으면 음수 사이클
```

시간복잡도는 `O(|V||E|)` 이다. 반복 중 아무 값도 바뀌지 않으면 그 자리에서 멈춰도 된다.

## 다른 경우의 알고리즘

| 조건 | 알고리즘 | 시간 |
|---|---|---|
| 가중치 비음수 | Dijkstra | $O(|E|\log|V|)$ |
| DAG | 위상순서로 한 번 훑기 | `O(|V|+|E|)` |
| 음수 간선 허용 | Bellman–Ford | `O(|V||E|)` |
| 모든 쌍 | Floyd–Warshall | `O(|V|^3)` |
| 모든 쌍, 희소 | Johnson (재가중 후 Dijkstra) | $O(|V||E|\log|V|)$ |

Dijkstra 가 더 빠른 이유는 탐욕적 순서를 쓸 수 있기 때문이다. 가중치가 비음수면 확정된 거리 중 가장 작은 것은 더 줄어들 수 없으므로, 각 정점을 한 번만 처리하면 된다. 음수 간선이 있으면 이 논거가 무너지고 반복으로 돌아가야 한다.

## Johnson 의 재가중

음수 간선이 있어도 Dijkstra 를 쓰고 싶으면 잠재함수 $h\colon V\to\mathbb R$ 로 가중치를 바꾼다.

$$
w'(u,v)=w(u,v)+h(u)-h(v)
$$

경로의 길이는 양 끝의 `h` 차이만큼만 달라지므로 최단경로의 **집합**이 보존된다. `h` 를 Bellman–Ford 로 구한 거리 함수로 잡으면 삼각부등식 $h(v)\le h(u)+w(u,v)$ 에서 $w'\ge0$ 이 나온다. 한 번의 Bellman–Ford 로 이후의 모든 Dijkstra 실행을 가능하게 만드는 것이다.

# 성질

- **최적 부분구조.** $s\to v$ 최단경로의 앞부분은 그 자체로 최단경로다. 음수 사이클이 없을 때만 성립하고, Bellman 방정식이 세워지는 근거다.
- **해의 비유일성.** 부등식 $d(v)\le d(u)+w(u,v)$ 를 만족하는 함수(잠재함수)는 많고, 최단거리는 그중 점별 최대다. 이 여유가 Johnson 재가중을 가능하게 한다.
- **음수 사이클 검출.** `|V|` 번째 반복에서 값이 줄어드는 간선을 따라 선행자 포인터를 역추적하면 사이클 자체를 복원할 수 있다. 차익거래 탐지가 이 형태로 환원된다.
- **선형계획과의 관계.** 최단경로는 $\max\sum_v d(v)$ 를 제약 $d(v)-d(u)\le w(u,v)$ 아래 푸는 문제이고, 그 쌍대가 단위 유량을 보내는 최소비용 흐름이다. 차이 제약 조건계의 실행 가능성 판정도 같은 문제다.
- **DAG 라는 특수화.** 사이클이 없으면 반복이 필요 없고 위상순서 한 번으로 끝난다. 반복이 필요한 이유가 정확히 사이클에 있다는 것을 보여 준다.

# 활용

## 값 반복이 방정식을 푸는 것을 확인한다

각 반복을 전부 기록하지 않고, 한 번의 훑기가 아무것도 바꾸지 못하면 멈추는 형태로 구현한다. 멈춘 지점에서 Bellman 방정식이 모든 정점에서 성립하는지 직접 검사한다.

```python
INF = float('inf')

def bellman_ford(n, edges, s):
    """값 반복. 반환은 (거리, 음수 사이클 여부, 안정화까지 걸린 반복 횟수)."""
    d = [INF] * n; d[s] = 0
    for k in range(1, n + 1):
        nd = d[:]
        for u, v, w in edges:
            if d[u] + w < nd[v]:
                nd[v] = d[u] + w
        if nd == d:                       # 고정점에 도달
            return d, False, k - 1
        d = nd
    return d, True, n                     # n 번째에도 줄어들면 음수 사이클

# 음수 간선이 있지만 음수 사이클은 없는 그래프
E = [(0, 1, 4), (0, 2, 5), (1, 2, -3), (2, 3, 4), (1, 3, 2), (3, 4, -1), (2, 4, 6)]
d, neg, k = bellman_ford(5, E, 0)
print("거리 =", d, " 음수 사이클 =", neg, " 반복 =", k)
assert d == [0, 4, 1, 5, 4] and not neg

for v in range(1, 5):                     # Bellman 방정식을 정점마다 직접 검사
    incoming = [d[u] + w for (u, vv, w) in E if vv == v]
    assert d[v] == min(incoming), (v, d[v], incoming)
print("모든 정점에서 d(v) = min over incoming (d(u) + w) 가 성립한다")

# 잠재함수로 재가중하면 가중치가 모두 비음수가 된다 (Johnson)
assert all(w + d[u] - d[v] >= 0 for (u, v, w) in E)
print("재가중 후 가중치 :", [w + d[u] - d[v] for (u, v, w) in E])

# 음수 사이클이 있는 그래프
E2 = [(0, 1, 1), (1, 2, -1), (2, 1, -1), (1, 3, 5)]
_, neg2, _ = bellman_ford(4, E2, 0)
assert neg2
print("음수 사이클 검출 =", neg2)

# 거리 = [0, 4, 1, 5, 4]  음수 사이클 = False  반복 = 4
# 모든 정점에서 d(v) = min over incoming (d(u) + w) 가 성립한다
# 재가중 후 가중치 : [0, 4, 0, 0, 1, 0, 3]
# 음수 사이클 검출 = True
```

반복이 `4` 회에서 멈춘 것은 `|V|-1=4` 와 맞는다. 최악의 경우가 실현된 예이고, 간선을 살피는 순서를 바꾸면 더 빨리 끝날 수도 있다. 순서에 의존하는 것은 도달 속도뿐이고 고정점 자체는 같다.

재가중 결과가 전부 비음수인 것이 Johnson 의 관찰이다. `d` 가 삼각부등식 $d(v)\le d(u)+w(u,v)$ 를 만족하므로 $w+d(u)-d(v)\ge0$ 이 자동으로 따라온다. 값이 `0` 인 간선이 최단경로에 실제로 쓰이는 간선이고, 그래서 재가중 후에도 최단경로 집합이 보존된다.

음수 사이클 쪽에서는 반복이 `n` 번째에도 멈추지 않는다. 고정점 관점에서는 사슬이 아래로 계속 내려가는 것이고, 유한 단계에 멈추지 않는다는 사실 자체가 검출 신호가 된다.

## 어디에 쓰이는가

- **경로 찾기.** 지도와 네트워크 라우팅의 기본. 거리 벡터 라우팅 프로토콜이 Bellman–Ford 의 분산 판본이다.
- **차익거래 탐지.** 환율의 로그를 부호 바꿔 가중치로 쓰면, 음수 사이클이 곧 무위험 차익거래다.
- **차이 제약 조건계.** $x_j-x_i\le c_{ij}$ 꼴의 부등식계는 최단경로 문제와 같고, 해의 존재가 음수 사이클의 부재와 동치다. 일정 계획 문제가 이 형태로 풀린다.
- **강화학습의 값 반복.** Bellman 방정식의 확률적 판본에서 같은 반복이 돌아간다. 할인율이 수축사상을 만들어 수렴을 보장하는 것이, 여기서 음수 사이클이 없어 사슬이 멈추는 것과 같은 자리에 있다.
