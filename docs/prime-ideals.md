# 소 아이디얼과 극대 아이디얼

# 개요

[아이디얼로 나누면](ideals-quotient-rings.md) 새 환이 나온다. 그런데 나온 환이 어떤 모양인지는 아이디얼이 결정한다. $\mathbb{Z}/6\mathbb{Z}$ 는 영인자가 있어 지저분하고 $\mathbb{Z}/7\mathbb{Z}$ 는 체라 깔끔하다.

소 아이디얼과 극대 아이디얼은 이 차이를 아이디얼 쪽에서 읽는 조건이다. 소 아이디얼로 나누면 정역이 나오고 극대 아이디얼로 나누면 체가 나온다. 정수에서는 둘 다 소수에 해당하지만 일반적인 환에서는 갈라지며, 그 간극이 환의 기하적 크기를 잰다.

이름이 소수를 연상시키는 것은 우연이 아니다. Euclid 보조정리 `p | ab ⟹ p | a 또는 p | b` 를 아이디얼의 언어로 그대로 옮긴 것이 소 아이디얼의 정의다. 소수의 "나누기" 성질을 원소가 아니라 아이디얼의 층위로 올린 셈이며, 유일분해가 깨지는 환에서도 이 층위에서는 질서가 남는다.

# 직관

## 소수의 어느 성질을 살릴 것인가

정수에서 소수는 두 가지로 특징지어졌다. 더 쪼갤 수 없다는 것(기약)과 곱을 나누면 인수를 나눈다는 것(소). 아이디얼로 올릴 때 살아남는 것은 후자다.

전자를 올리면 극대 아이디얼이 된다. "더 큰 진아이디얼이 없다" 가 "더 쪼갤 수 없다" 에 해당하기 때문이다. 정수에서는 두 조건이 같지만 일반적으로 극대가 소보다 강하다.

## 기하로 읽기

다항식환에서 아이디얼은 도형에 대응한다. 이 사전에서 두 조건이 기하적 의미를 얻는다.

| 아이디얼 | 몫환 | 기하 |
|---|---|---|
| 극대 | 체 | 점 |
| 소 | 정역 | 기약 도형(더 작은 두 조각의 합집합이 아님) |
| 일반 | 임의의 환 | 임의의 도형 |

$k[x,y]$ 에서 $(x)$ 는 $y$ 축이라는 직선이고 기약이므로 소이지만, 직선 안에 점이 들어가므로 극대가 아니다. $(x,y)$ 는 원점이라 극대다. $(xy)$ 는 두 축의 합집합이라 기약이 아니고 실제로 소가 아니다. $x \cdot y \in (xy)$ 인데 $x, y \notin (xy)$ 이기 때문이다.

소 아이디얼이 극대보다 얼마나 많은지가 공간의 차원이다. 점만 있으면 `0` 차원이고, 점과 곡선이 있으면 `1` 차원이다. 이 직관을 정확히 한 것이 Krull 차원이다.

# 정의

## 소와 극대

항등원을 가진 가환환 $R$ 의 진아이디얼 $P$ 가 모든 $a, b \in R$ 에 대해

$$
ab\in P\quad\Longrightarrow\quad a\in P\ \text{또는}\ b\in P
$$

를 만족하면 소 아이디얼이다.

진아이디얼 $M$ 을 진부분집합으로 포함하는 진아이디얼이 없으면, 곧 $M \subseteq J \subseteq R$ 인 아이디얼 $J$ 가 $M$ 또는 $R$ 뿐이면 $M$ 을 극대 아이디얼이라 한다.

두 정의 모두 진아이디얼일 것, 곧 `R` 자신이 아닐 것을 요구한다. `R` 을 허용하면 영환이 정역이나 체가 되어 버린다.

## 스펙트럼

`R` 의 소 아이디얼 전체를 `Spec R` 이라 하고, 극대 아이디얼 전체를 `mSpec R` 이라 한다. `Spec R` 에 Zariski 위상을 주면 위상공간이 되며, 이것이 대수기하에서 환을 공간으로 보는 출발점이다.

# 성질

## 몫환에 의한 판정

$$
P\ \text{소}\iff R/P\ \text{정역},\qquad
M\ \text{극대}\iff R/M\ \text{체}
$$

첫 번째는 몫환에서 $[a][b] = [0]$ 이 $ab \in P$ 와 같다는 데서 바로 나온다. 두 번째는 대응 정리를 쓴다. $R/M$ 의 아이디얼이 $M$ 을 포함하는 $R$ 의 아이디얼과 대응하므로, $M$ 이 극대인 것과 $R/M$ 의 아이디얼이 $(0)$ 과 전체뿐인 것이 같고, 가환환이 그런 것과 체인 것이 동치다.

## 극대는 소다

모든 체는 정역이므로 모든 극대 아이디얼은 소 아이디얼이다. 역은 일반적으로 거짓이다.

$\mathbb{Z}$ 에서 $(0)$ 은 소이지만 극대가 아니다. $\mathbb{Z}/(0) = \mathbb{Z}$ 가 정역이지만 체가 아니기 때문이다. $k[x,y]$ 에서는

$$
k[x,y]/(x)\cong k[y],\qquad k[x,y]/(x,y)\cong k
$$

이므로 `(x)` 는 소이고 극대가 아니며 `(x,y)` 는 극대다.

$\mathbb{Z}$ 에서는 $(0)$ 을 빼면 소와 극대가 일치한다. 이것이 $\mathbb{Z}$ 의 Krull 차원이 $1$ 이라는 뜻이고, $k[x,y]$ 에서는 $(0) \subsetneq (x) \subsetneq (x,y)$ 라는 길이 $2$ 의 사슬이 있어 차원이 $2$ 다.

```python
from itertools import product

def ideal_zn(n, gen):
    from math import gcd
    g = gcd(n, gen % n)
    return {k * g % n for k in range(n // g)} if g else {0}

def is_prime_ideal(n, gen):
    I = ideal_zn(n, gen)
    if I == set(range(n)):
        return False                      # 진아이디얼이 아님
    return all(not (a * b % n in I and a % n not in I and b % n not in I)
               for a, b in product(range(n), repeat=2))

def is_maximal_ideal(n, gen):
    I = ideal_zn(n, gen)
    if I == set(range(n)):
        return False
    bigger = [ideal_zn(n, g) for g in range(n)]
    return not any(I < J < set(range(n)) for J in bigger)


n = 12
seen = set()
for g in range(n):
    I = frozenset(ideal_zn(n, g))
    if I in seen:
        continue                          # (9) = (3), (10) = (2) 처럼 같은 아이디얼
    seen.add(I)
    p, m = is_prime_ideal(n, g), is_maximal_ideal(n, g)
    if p or m:
        print(f"({g}) = {sorted(I)}  소={p} 극대={m}")
```

$\mathbb{Z}/12\mathbb{Z}$ 에서 소이면서 극대인 아이디얼은 $(2)$ 와 $(3)$ 뿐이다. $12$ 의 소인수와 정확히 대응하며, 대응 정리에 의해 이들이 $\mathbb{Z}$ 의 $(2), (3)$ 에서 내려온 것임을 알 수 있다.

## 존재 정리

$1 \ne 0$ 인 모든 가환환에는 극대 아이디얼이 존재한다. 진아이디얼들의 포함 관계에 Zorn 보조정리를 적용하면 되고, 사슬의 합집합이 여전히 진아이디얼인 것은 $1$ 을 포함하지 않기 때문이다. 따라서 이 정리는 [선택공리](axiom-of-choice.md)에 의존한다.

따름정리로 가역이 아닌 원소는 반드시 어떤 극대 아이디얼에 들어간다. 극대 아이디얼이 정확히 하나뿐인 환을 국소환이라 하며, [국소화](localization-rings.md)는 소 아이디얼 하나를 골라 그 바깥의 원소를 모두 가역으로 만들어 국소환을 얻는 조작이다. 기하로는 한 점 주변만 남기고 잘라 내는 것에 해당한다.

## 소 아이디얼의 유용한 성질

- `R` 이 정역인 것과 `(0)` 이 소인 것은 동치다.
- 소 아이디얼의 역상은 소 아이디얼이다. $\varphi : R \to S$ 와 소 $Q \subseteq S$ 에 대해 $\varphi^{-1}(Q)$ 가 소다. 극대 아이디얼에는 이 성질이 없다.
- 아이디얼 $I$ 의 근기 $\sqrt{I}$ 는 $I$ 를 포함하는 모든 소 아이디얼의 교집합이다. 이 사실이 Hilbert 영점정리의 대수적 핵심이다.
- 곱셈에 닫힌 집합 `S` 와 서로소인 아이디얼 중 극대인 것은 소다. 소 아이디얼을 실제로 만들어 낼 때 쓰는 표준 보조정리다.

역상 성질이 함자성을 준다. 환 준동형 $R \to S$ 가 연속사상 $\mathrm{Spec}\, S \to \mathrm{Spec}\, R$ 을 유도하므로, 환의 범주와 공간의 범주가 화살표 방향을 뒤집어 대응한다.

# 활용

## 몫을 단순화하기

복잡한 환을 다룰 때 소 아이디얼로 나누면 영인자가 사라져 취소가 가능해지고, 극대 아이디얼로 나누면 체가 되어 선형대수와 다항식 이론을 그대로 쓸 수 있다. 정수의 문제를 `mod p` 로 옮겨 푸는 고전적 기법이 후자이며, 여러 소수에 대한 정보를 모아 원래 문제로 되돌리는 것이 국소-전역 원리다.

## 대수와 기하의 사전

`k` 가 대수적으로 닫힌 체이면 `k[x_1,…,x_n]` 의 극대 아이디얼은 점 `(a_1,…,a_n)` 에 대응하는 `(x_1-a_1, …, x_n-a_n)` 이 전부다. 이것이 약한 형태의 Hilbert 영점정리이고, 다항식의 공통 영점과 아이디얼을 잇는 다리다.

일반 환에서는 극대 아이디얼만으로 부족해 소 아이디얼 전체를 점으로 삼는다. $\mathrm{Spec}\, R$ 이 그 결과이며, 정역의 $(0)$ 처럼 닫히지 않은 점이 등장한다. 이 확장 덕분에 $\mathbb{Z}$ 같은 환도 기하적 대상으로 다룰 수 있게 되고, 정수론과 대수기하가 같은 언어를 쓰게 된다.

## 차원과 구조

소 아이디얼의 사슬 $P_0 \subsetneq P_1 \subsetneq \cdots \subsetneq P_d$ 의 최대 길이가 Krull 차원이다. 체는 $0$ , $\mathbb{Z}$ 와 $k[x]$ 는 $1$ , $k[x_1,\ldots,x_n]$ 은 $n$ 이다. 차원이 대수적 조건만으로 정의된다는 점이 중요하다. 좌표나 위상을 쓰지 않고도 "이 환이 기술하는 공간이 몇 차원인가" 를 말할 수 있으며, 이것이 가환대수가 기하의 기초 언어로 쓰이는 이유다.[^1]
