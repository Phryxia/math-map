# 나무 오토마타

# 개요

**나무 오토마타(tree automaton)** 는 문자열 대신 순위 있는 나무를 입력으로 받는 유한 상태 기계다. 잎에서 뿌리로 상태를 올려 보내는 상향 판본이 표준이고, 이것이 인식하는 나무 언어족은 합집합, 교집합, 여집합, 사영에 닫혀 있다. 네 닫힘 연산이 단항 2차 논리식의 논리곱, 부정, 양화에 각각 대응하므로 논리식을 오토마타로 기계적으로 번역할 수 있고, 그 번역이 [Courcelle 정리](courcelle-theorem.md)의 증명이다.

# 직관

이항 나무의 잎에 $0$ 과 $1$ 이 붙고 내부 노드에 AND 와 OR 가 붙은 구문나무가 있다. 뿌리의 값을 구하려면 각 노드에 그 노드가 뿌리인 부분나무의 값을 적고 잎에서 뿌리로 올라가면 된다. 한 노드에서 쓰는 정보는 그 노드의 라벨과 두 자식에 적힌 값 두 개뿐이고, 적히는 값은 $0$ 과 $1$ 둘 중 하나다.

이 계산에서 남겨야 할 것은 두 가지다. 노드에 적히는 값이 유한 집합에서 나온다는 것과, 노드의 값이 그 노드의 라벨과 자식들의 값만으로 정해진다는 것이다. 값의 집합을 $\lbrace 0,1\rbrace$ 에서 다른 유한 집합으로 바꾸고 정해지는 규칙을 바꾸면 Boolean 식과 무관한 판정도 한 번 올려 보내는 것으로 끝난다. 잎의 $1$ 이 짝수 개인지 보려면 값을 개수의 짝홀로 두고 내부 노드에서 두 자식의 값을 더하면 된다.

문자열의 [유한 오토마타](finite-automata.md)와 다른 점은 전이가 받는 상태의 개수다. 문자열에서는 전이가 상태 하나와 문자 하나를 받아 상태 하나를 내지만, 나무에서는 자식이 $k$ 개인 노드의 전이가 상태 $k$ 개와 라벨 하나를 받아 상태 하나를 낸다.

# 정의

## 순위 알파벳과 항

**순위 알파벳**은 유한 집합 $\Sigma$ 와 각 기호에 자식 수를 주는 함수로 이루어지고, 자식 수가 $k$ 인 기호의 집합을 $\Sigma_k$ 로 쓴다. $\Sigma$ 위의 **나무**는 $f\in\Sigma_k$ 와 나무 $t_1,\dots,t_k$ 로부터 $f(t_1,\dots,t_k)$ 를 만드는 규칙으로 재귀적으로 정해진다. $k=0$ 인 기호가 잎이다.

## 상향 나무 오토마타

**상향 나무 오토마타**는 $\mathcal A=(Q,\Sigma,\Delta,F)$ 다. $Q$ 는 유한 상태집합, $F\subseteq Q$ 는 수용 상태집합이고, 전이관계 $\Delta$ 는 각 $f\in\Sigma_k$ 와 각 $(q_1,\dots,q_k)\in Q^k$ 에 상태의 부분집합 $\Delta(f,q_1,\dots,q_k)\subseteq Q$ 를 준다.

나무 $t$ 의 노드마다 상태를 주는 사상 $\rho$ 가 모든 노드에서 $\rho(v)\in\Delta\bigl(f,\rho(v_1),\dots,\rho(v_k)\bigr)$ 를 만족하면 $\rho$ 를 **실행**이라 한다. 여기서 $f$ 는 $v$ 의 라벨이고 $v_1,\dots,v_k$ 는 $v$ 의 자식이다. 뿌리의 상태가 $F$ 에 드는 실행이 있으면 $\mathcal A$ 가 $t$ 를 수용한다. 모든 $\Delta(f,q_1,\dots,q_k)$ 가 원소 하나이면 **결정적**이라 한다. 수용되는 나무 전체를 $\mathcal A$ 가 인식하는 언어라 하고, 어떤 상향 나무 오토마타가 인식하는 나무 집합을 **정규 나무 언어**라 한다.

```javascript
function runBottomUp(automaton, tree) {
  // 자식의 상태집합을 먼저 구하고 전이로 올린다
  const childStates = tree.children.map(c => runBottomUp(automaton, c))
  return automaton.step(tree.label, childStates)   // 상태집합을 낸다
}
```

## 하향 판본

**하향 나무 오토마타**는 뿌리에 초기 상태를 두고 각 노드에서 그 상태와 라벨을 보아 자식들에게 보낼 상태의 조를 고른다. 비결정적 하향 오토마타는 비결정적 상향 오토마타와 같은 언어족을 인식한다.

# 성질

## 결정화

**정리.** 상태 $n$ 개의 비결정적 상향 나무 오토마타가 인식하는 언어를 상태 $2^n$ 개의 결정적 상향 나무 오토마타가 인식한다.

부분집합 구성이다. 각 노드에 그 부분나무에서 도달 가능한 원래 상태의 집합을 붙이고, 새 전이를 $\Delta'(f,S_1,\dots,S_k)=\bigcup\Delta(f,q_1,\dots,q_k)$ 로 둔다. 합집합은 $q_i\in S_i$ 인 모든 조에 대해 취한다. 새 수용 상태집합은 $F$ 와 만나는 부분집합 전체다. ∎

## 닫힘성

**정리.** 정규 나무 언어는 합집합, 교집합, 여집합, 그리고 라벨의 한 성분을 지우는 사영에 닫혀 있다.

합집합과 교집합은 두 오토마타의 상태를 짝지은 곱 구성으로 얻는다. 여집합은 결정화한 뒤 수용 상태집합을 여집합으로 바꾸면 되고, 결정적이라 실행이 하나뿐이므로 수용이 뒤집힌다. 사영은 지운 성분의 값을 추측하는 전이를 두어 얻고, 그 추측이 비결정성을 만든다. ∎

사영 뒤에 여집합을 쓰려면 다시 결정화해야 하므로, 두 연산을 번갈아 $m$ 번 쓰면 상태 수가 $m$ 단 지수 탑으로 커진다.

## 공백성 판정

**정리.** 상향 나무 오토마타가 인식하는 언어가 비어 있는지는 전이의 개수에 선형인 시간에 판정된다.

잎 기호의 전이에서 나오는 상태를 모아 놓고, 이미 모인 상태들로 전이의 왼쪽이 채워지면 그 오른쪽 상태를 더하는 포화를 더 늘 것이 없을 때까지 한다. 모인 집합이 $F$ 와 만나지 않으면 언어가 비어 있다. ∎

## 결정적 하향 판본의 약함

**정리.** $\Sigma_2=\lbrace f\rbrace$ 와 $\Sigma_0=\lbrace a,b\rbrace$ 위의 언어 $\lbrace f(a,b),f(b,a)\rbrace$ 는 어떤 결정적 하향 나무 오토마타도 인식하지 못한다.

뿌리의 상태와 라벨 $f$ 가 두 자식에게 보낼 상태를 하나로 정하므로, 왼쪽 자식이 $a$ 와 $b$ 를 모두 받아들이고 오른쪽 자식도 그래야 한다. 그러면 $f(a,a)$ 도 수용된다. ∎

## 단항 2차 논리와의 대응

**정리.** 순위 나무 위의 MSO(monadic second-order) 논리로 정의되는 나무 집합은 정규 나무 언어이고, 역도 성립한다[^1].

한 방향은 닫힘성 정리를 논리식의 구조에 따라 적용하는 것이다. 원자식마다 오토마타를 하나 두고, 논리곱에 곱 구성을, 부정에 여집합 구성을, 집합 양화에 사영 구성을 대응시킨다. 반대 방향은 오토마타의 실행을 상태마다의 집합변수로 적고 전이 규칙을 1차 논리식으로 쓴다. ∎

# 활용

- [Courcelle 정리](courcelle-theorem.md)의 증명이 나무 분해를 항으로 보고 MSO 논리식을 나무 오토마타로 번역한다. 번역의 상수가 논리식의 양화 깊이에 지수 탑으로 커지는 것은 사영과 여집합을 번갈아 쓰기 때문이다.
- 문서 스키마 검증에서 허용되는 문서를 정규 나무 언어로 적고, 주어진 문서가 그 언어에 드는지를 오토마타 한 번 돌리기로 판정한다.
- 항 재작성에서 재작성 규칙의 왼쪽과 맞는 부분항을 찾는 일이 상향 오토마타의 실행이고, 여러 규칙을 한 오토마타로 합쳐 한 번에 훑는다.
- 무한 나무로 옮긴 판본에서 수용 조건을 Rabin 조건으로 두면 오토마타의 공백성이 결정 가능하고, 거기서 두 후속자 이론의 결정 가능성이 나온다[^2].

[^1]: James W. Thatcher, Jesse B. Wright, "Generalized finite automata theory with an application to a decision problem of second-order logic", Mathematical Systems Theory 2 (1968), 57–81.

[^2]: Michael O. Rabin, "Decidability of second-order theories and automata on infinite trees", Transactions of the American Mathematical Society 141 (1969), 1–35.
