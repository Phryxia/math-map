# 직관주의 논리

# 개요

"이 방정식에 해가 존재한다" 는 증명이 두 종류다. 해를 실제로 만들어 보이는 것과, 해가 없다고 가정해 모순을 이끄는 것이다. 고전 논리는 둘을 같은 것으로 취급하지만 실용적 가치는 전혀 다르다. 후자는 존재를 알려 주면서 무엇인지는 알려 주지 않는다.

직관주의 논리는 이 구별을 논리 자체에 새겨 넣는다. 명제의 증명을 그 명제를 확인하는 구성으로 해석하고, 배중률과 이중부정 제거를 일반 규칙으로 채택하지 않는다. [수학적 직관주의](mathematical-intuitionism.md)의 철학적 입장을 형식 체계로 옮긴 것이며, [명제와 증명](proofs.md)의 추론 규칙에서 두 가지를 덜어 낸 결과다.

덜어 낸 결과가 뜻밖의 이득을 낳았다. 증명이 프로그램이 되고 명제가 타입이 되는 [Curry–Howard 대응](curry-howard.md)이 성립하며, 이것이 현대 증명 보조 도구의 논리적 기반이다.

# 직관

## BHK 해석

각 연결사의 의미를 "무엇을 제시해야 증명이 되는가" 로 정한다.

| 명제 | 증명이란 |
|---|---|
| `A ∧ B` | `A` 의 증명과 `B` 의 증명 둘 다 |
| `A ∨ B` | 어느 쪽인지와 그쪽의 증명 |
| `A → B` | `A` 의 증명을 `B` 의 증명으로 바꾸는 구성 |
| `∃x. P(x)` | 구체적인 `a` 와 `P(a)` 의 증명 |
| `∀x. P(x)` | 임의의 `a` 에 `P(a)` 의 증명을 주는 구성 |
| `¬A` | `A` 의 증명을 모순으로 바꾸는 구성 |

`A ∨ B` 의 줄이 결정적이다. 어느 쪽인지 말하지 못하면 증명이 아니다. 그래서 `A ∨ ¬A` 를 일반적으로 주장할 수 없다. 임의의 명제에 대해 어느 쪽인지 알려 주는 방법이 없기 때문이다.

프로그래밍의 눈으로 보면 각 줄이 타입이다. 곱타입, 합타입, 함수타입, 의존곱과 의존합이 차례로 대응한다. 증명이 곧 그 타입의 값이다.

## 부정하는 것이 아니라 주장하지 않는 것

흔한 오해가 있다. 직관주의는 배중률이 거짓이라고 말하지 않는다. `¬(A ∨ ¬A)` 는 직관주의적으로도 증명되지 않으며, 오히려 그 이중부정은 증명된다.

또한 판정 절차가 있는 명제에는 배중률이 성립한다. "이 자연수가 짝수인가" 는 나눠 보면 알 수 있으므로 `A ∨ ¬A` 를 구성할 수 있다. 배중률이 실패하는 것은 확인 절차가 없는 명제에 대해서이며, 무한을 다룰 때 주로 나타난다.

# 정의

## 부정

명제 `A` 와 모순을 나타내는 `⊥` 를 정한다. 부정은 별도의 진릿값 연산이 아니라 함의로 정의한다.

$$
\neg A:=A\to\bot
$$

`⊥` 에서는 무엇이든 따라 나온다는 폭발 규칙은 유지한다. 이것을 버리면 최소논리가 되며 별개의 체계다.

## 채택하지 않는 규칙

직관주의 자연연역은 각 연결사의 도입·제거 규칙을 쓰되, 다음을 모든 `A` 에 대한 일반 규칙으로 채택하지 않는다.

$$
A\lor\neg A,\qquad \neg\neg A\to A
$$

두 규칙은 서로 동치이고, Peirce 법칙 `((A→B)→A)→A` 와 귀류법도 마찬가지다. 이 중 하나를 더하면 고전 논리가 복원된다.

# 성질

## 한쪽 방향만 성립한다

`A → ¬¬A` 는 증명된다. `A` 를 가정하고 `¬A` 도 가정하면 정의에 따라 모순이 나오기 때문이다. 역방향은 일반적으로 증명되지 않는다.

배중률 자체를 쓰지 않고도 그 이중부정은 증명된다.

$$
\neg\neg(A\lor\neg A)
$$

`A ∨ ¬A` 가 모순을 낳는다고 가정하자. `A` 를 가정하면 왼쪽 선택으로 모순이므로 `¬A` 를 얻고, 이 `¬A` 를 오른쪽 선택으로 쓰면 다시 모순이다.

## 고전 논리와의 관계

직관주의적으로 증명한 명제는 고전 논리에서도 증명된다. 규칙이 부분집합이기 때문이다. 역은 성립하지 않으므로 증명 가능한 식이 진짜로 적다.

그런데 이중부정 번역을 쓰면 두 체계가 정확히 연결된다. Glivenko 정리에 따르면 명제논리에서

$$
\vdash_{\text{cl}}A\quad\Longleftrightarrow\quad\vdash_{\text{int}}\neg\neg A
$$

이다. 고전 논리는 직관주의 논리에 정보를 더한 것이 아니라, 같은 내용을 이중부정 아래에서 말하는 것이다. 술어논리에서는 Gödel–Gentzen 번역이 같은 역할을 한다.

따라서 직관주의 논리가 모순을 허용하는 약한 체계라는 인상은 틀렸다. 오히려 구별을 더 많이 하는 체계다.

## 존재성질과 선언성질

닫힌 명제에 대해 다음이 성립한다.

- `⊢ A ∨ B` 이면 `⊢ A` 이거나 `⊢ B` 다.
- `⊢ ∃x. P(x)` 이면 어떤 구체적 `t` 에 대해 `⊢ P(t)` 다.

고전 논리에는 없는 성질이다. `⊢ A ∨ ¬A` 이지만 `A` 도 `¬A` 도 증명되지 않는 경우가 있기 때문이다.

이 성질이 직관주의 논리를 계산과 잇는 다리다. 존재 증명에서 실제 대상을 기계적으로 추출할 수 있고, 그 추출 과정이 곧 프로그램 실행이다. 증명 정규화가 프로그램의 평가에 대응한다는 Curry–Howard 의 내용이 이것이다.

```python
# 증명을 프로그램으로 읽는다. 명제 = 타입, 증명 = 값.
# A -> B 의 증명은 함수, A and B 는 튜플, A or B 는 태그된 값.

Bot = None                                   # 증명이 없는 타입

def and_intro(a, b):      return (a, b)
def and_elim1(p):         return p[0]
def or_intro_left(a):     return ("left", a)
def or_intro_right(b):    return ("right", b)
def not_(A_to_bot):       return A_to_bot    # not A = A -> bot

# A -> not not A: a 를 받아 "na 를 받아 na(a) 를 내는 함수" 를 돌려준다
def dni(a):
    return lambda na: na(a)

# not not (A or not A) 의 증명. k 는 (A or not A) -> bot.
def dn_lem(k):
    # not A 를 구성한다: a 를 받으면 left(a) 로 k 를 불러 모순을 낸다
    na = lambda a: k(or_intro_left(a))
    return k(or_intro_right(na))             # 다시 모순


# 확인: 구체적인 A 를 "증명 한 개짜리 타입" 으로 흉내 낸다
proof_of_A = "pf"
print(dni(proof_of_A)(lambda a: f"모순: {a}"))

trace = []
def k(x):
    """A or not A 를 모순으로 보내는 임의의 구성. 여기서는 right 를 받으면
    그 안의 not A 를 A 의 증명에 적용해 본다."""
    trace.append(x[0])
    if x[0] == "right":
        return x[1](proof_of_A)              # not A 를 쓰면 k 가 다시 불린다
    return "bot"

dn_lem(k)
print(trace)                                 # ['right', 'left']

# 반면 not not A -> A 를 구성하는 함수는 작성할 수 없다.
# nna 는 (A -> bot) -> bot 이고, bot 에서 A 를 꺼낼 방법이 없다.
```

`k` 가 두 번 불리는 흔적이 증명의 구조를 드러낸다. `dn_lem` 은 먼저 오른쪽 선택으로 `¬A` 를 건네고, 그 `¬A` 가 쓰이면 왼쪽 선택을 통해 다시 모순으로 돌아온다. 반면 `¬¬A → A` 는 반환할 값을 만들 방법이 없어 작성 자체가 불가능하다.

## 무엇이 살아남는가

고전 논리의 정리 중 어떤 것이 직관주의적으로도 성립하는지는 경우마다 다르다.

| 식 | 직관주의 |
|---|---|
| `¬(A ∧ B) ← ¬A ∨ ¬B` | 성립 |
| `¬(A ∧ B) → ¬A ∨ ¬B` | 실패 |
| `¬(A ∨ B) ↔ ¬A ∧ ¬B` | 성립 |
| `(A → B) ← ¬A ∨ B` | 성립 |
| `(A → B) → ¬A ∨ B` | 실패 |

실패하는 쪽은 모두 "어느 경우인지 알려 주지 않는" 결론을 요구한다. 실패를 확인하는 표준 도구가 [Kripke 의미론](kripke-semantics.md)이며, 두 상태짜리 모형 하나로 대부분의 반례가 나온다.

# 활용

## 증명에서 프로그램 추출

존재 증명이 구성적이면 그로부터 실제 알고리즘을 뽑아낼 수 있다. Coq, Agda, Lean 같은 증명 보조 도구가 직관주의 논리를 기반으로 삼는 이유이며, 검증된 컴파일러와 검증된 자료구조가 이 방식으로 만들어진다. 정렬 알고리즘의 정확성 증명에서 정렬 프로그램 자체가 나오는 식이다.

## 의존성의 추적

고전 정리를 쓸 때 어느 단계가 배중률이나 선택공리에 의존하는지 추적할 수 있다. 역수학에서 정리들을 필요한 공리의 세기로 분류하는 작업, 구성적 해석학에서 어떤 결과가 살아남는지 가려내는 작업이 여기에 해당한다. 중간값 정리가 구성적으로 성립하지 않는다는 사실은 실제로 근을 찾는 알고리즘의 한계와 직결된다.

## 논리의 계열

배중률을 빼되 다른 것을 더하거나 빼면 여러 체계가 나온다. 선형논리는 가정을 몇 번 쓸 수 있는지까지 추적해 자원을 모형화하고, 양상 논리의 여러 체계는 필연성의 해석을 달리한다. 무엇을 추론 규칙으로 인정하느냐가 그 논리로 무엇을 표현할 수 있는지를 정한다는 관점이, 프로그래밍 언어의 타입 시스템 설계에 그대로 쓰인다.[^1]

[^1]: Stanford Encyclopedia of Philosophy, *Intuitionistic Logic*, §1–2. 형식 체계, BHK 해석과 고전논리와의 관계. https://plato.stanford.edu/entries/logic-intuitionistic/
