# 선형 치우침 Attention

# 개요

**선형 치우침 Attention(attention with linear biases, ALiBi)** 은 위치 벡터를 쓰지 않고, 질의와 키 사이의 거리에 비례하는 값을 Attention 점수에서 빼서 순서를 넣는 방법이다. 짧은 문장으로 학습한 언어 모형에 학습 때보다 긴 문장을 넣으면, 처음 보는 자리의 위치 벡터 때문에 예측이 크게 나빠진다. 선형 치우침 Attention 에서는 거리만 점수에 들어가므로, 학습 때 보지 못한 긴 문장에도 같은 규칙이 그대로 적용된다.

# 직관

[Attention 메커니즘](attention-mechanism.md) 문서의 예에서 "달린다" 자리의 질의는 "개가, 공을, 물고" 에 점수 $2,0,1$ 을 주었고 무게는 $0.665,0.090,0.245$ 였다. "달린다" 를 자리 $3$ 이라 하면 세 낱말은 각각 $3,2,1$ 칸 앞에 있다.

[위치 부호화](positional-encoding.md)를 더하는 대신 점수에서 거리의 $m$ 배를 뺀다. $m=1/2$ 이면 빼는 값이 $1.5,1,0.5$ 이고 점수는 $0.5,-1,0.5$ 가 된다.

$$\frac{(e^{0.5},e^{-1},e^{0.5})}{e^{0.5}+e^{-1}+e^{0.5}}\approx(0.450,\thinspace 0.100,\thinspace 0.450)$$

"개가" 의 무게가 $0.665$ 에서 $0.450$ 으로 내려가고 가까운 "물고" 가 올라갔다. $m=1/8$ 이면 무게는 $(0.615,\thinspace 0.094,\thinspace 0.291)$ 로 처음 값에 가깝다. 기울기 $m$ 이 클수록 가까운 낱말을, 작을수록 먼 낱말도 본다. 머리마다 다른 기울기를 주어 점수에서 거리를 빼는 방법을 선형 치우침 Attention 이라 한다.

# 정의

여러 머리 Attention 의 머리가 $H$ 개일 때, 머리 $h=1,\dots,H$ 의 기울기를 $m_h=2^{-8h/H}$ 로 둔다. 인과 가림을 쓴 자기 Attention 에서 머리 $h$ 의 점수를 다음과 같이 바꾸고, 입력에 위치 벡터를 더하지 않는 것을 **선형 치우침 Attention** 이라 한다[^1].

$$\mathbf q_i\cdot\mathbf k_j-m_h\thinspace(i-j)\qquad(j\le i)$$

원 논문은 축척 $1/\sqrt{d_k}$ 를 내적에 그대로 곱한다. $H=8$ 이면 기울기는 $1/2,1/4,\dots,1/256$ 이다. 직관 절은 기울기 $1/2$ 과 $1/8$ 인 두 머리를 축척 없이 계산한 것이다.

# 성질

## 거리만의 함수

치우침 $-m_h(i-j)$ 는 두 자리의 차에만 달려 있다. 그래서 문장 전체를 몇 칸 옮겨도 점수가 바뀌지 않고, 위치 부호화 문서의 회전 위치 부호화와 같은 상대성을 가진다. 위치에 따라 정해지는 매개변수가 없으므로 어느 길이의 입력에서도 정의된다.

## 무게의 기하 감소

질의와 키의 내적이 모두 같으면 머리 $h$ 의 무게는 거리 $t$ 에 대해 $e^{-m_ht}$ 에 비례한다. 거리 $1/m_h$ 에서 무게가 $1/e$ 배로 줄어들므로, $H=8$ 의 머리들은 약 $2$ 칸에서 $256$ 칸까지의 거리를 나누어 본다.

## 학습 길이 밖의 예측

Press, Smith, Lewis 는 길이 $1024$ 의 입력으로 학습한 선형 치우침 Attention 모형이 길이 $2048$ 의 입력에서, 길이 $2048$ 로 학습한 사인 위치 부호화 모형과 같은 정도의 혼잡도(perplexity)를 보였고, 학습은 약 $11$% 빨랐다고 보고했다[^1].

# 활용

- 긴 문서의 언어 모형. 짧은 입력으로 학습하고 긴 입력에서 쓰므로 학습 비용을 줄인다[^1].
- 공개 대규모 언어 모형의 위치 처리. 위치 벡터 없이 점수에 거리 치우침만 더하는 구조가 여러 모형에 쓰인다.

[^1]: O. Press, N. A. Smith, M. Lewis, "Train short, test long: Attention with linear biases enables input length extrapolation", *International Conference on Learning Representations* (2022).
