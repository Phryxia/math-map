# 다중격자

# 개요

격자 위의 방정식을 반복법으로 풀면 오차의 고주파 성분만 빨리 사라지고 저주파 성분이 남는다. 저주파 성분은 격자를 성기게 만들면 고주파가 되므로, 성긴 격자에서 같은 반복을 하면 사라진다.

격자를 여러 단계로 쌓고 단계마다 자기 주파수대를 맡기면 반복 횟수가 격자 간격과 무관해진다. 한 번의 사이클 비용이 미지수 개수에 비례하므로 전체 비용도 그렇다.

# 직관

격자 간격 $h$ 인 정사각 격자에서 Poisson 방정식을 5점 차분으로 이산화한 계 $Ax=b$ 를 Gauss–Seidel 반복으로 푼다. 처음 몇 번은 오차가 크게 줄다가 곧 거의 줄지 않는다.

오차를 격자 위의 Fourier 모드로 나누면 이유가 보인다. 파수 $k$ 인 모드에 Gauss–Seidel 을 한 번 적용하면 그 모드의 크기가 $k$ 에 따라 다른 비율로 줄어든다. 격자에서 가장 빠르게 진동하는 모드는 한 번에 절반 아래로 줄지만, 한 파장이 격자 전체에 걸치는 모드는 $1-O(h^2)$ 배로만 줄어든다.

Gauss–Seidel 은 각 점의 값을 이웃 값들의 평균으로 고치는 계산이다. 느린 모드는 이웃끼리 값이 거의 같으므로 평균을 취해도 변하는 것이 없다.

이 모드를 간격 $2h$ 인 격자 위에서 보면 사정이 다르다. 파장은 그대로인데 격자 간격이 두 배가 되었으므로 한 파장 안에 들어가는 점의 수가 절반이고, 그만큼 빠르게 진동하는 모드가 된다. 성긴 격자에서 같은 반복을 하면 이 모드가 줄어든다. 게다가 성긴 격자의 미지수는 4분의 1뿐이다.

# 정의

## 완화

계 $Ax=b$ 와 현재 근사 $x$ 에 대해 damped Jacobi 나 Gauss–Seidel 을 $\nu$ 번 적용하는 것을 **완화**라 한다. 완화의 선형 연산자를 $S$ 라 쓰면 오차는 $e\mapsto S^{\nu}e$ 로 바뀐다.

## 격자 사이의 옮김

촘촘한 격자의 벡터를 성긴 격자로 보내는 선형사상 $R$ 을 **제한**, 반대 방향의 $P$ 를 **보간**이라 한다. 보통 $R=cP^{\top}$ 로 잡는다. 성긴 격자의 계수행렬은 Galerkin 곱으로 정한다.

$$
A_c=RAP
$$

## V 사이클

한 단계 내려가 보정을 받아 오는 절차를 재귀로 쓴다.

```javascript
function vcycle(level, b, x) {
  if (level === coarsest) return solveDirect(A[level], b)

  x = relax(A[level], b, x, nu1)              // 사전 완화
  const r = subtract(b, apply(A[level], x))   // 잔차
  const rc = restrict(level, r)               // 성긴 격자로

  const ec = vcycle(level + 1, rc, zeros(rc.length))

  x = add(x, prolong(level, ec))              // 보정을 되돌려 더한다
  return relax(A[level], b, x, nu2)           // 사후 완화
}
```

성긴 단계에서 재귀 호출을 두 번 하면 W 사이클이고, 가장 성긴 격자에서 시작해 한 단계씩 내려오며 보간한 값을 초기 근사로 쓰면 완전 다중격자다.

# 성질

## 비용

차원 $d$ 에서 격자 간격을 두 배로 늘리면 미지수가 $2^{-d}$ 배가 된다. 각 단계의 완화 비용이 그 단계 미지수에 비례하므로 한 사이클의 비용은 다음 등비급수로 묶인다.

$$
c\thinspace n\thinspace(1+2^{-d}+2^{-2d}+\dots)=\frac{c\thinspace n}{1-2^{-d}}
$$

한 사이클이 $O(n)$ 이고 사이클 수가 $n$ 과 무관하면 전체가 $O(n)$ 이다.

## 수렴

두 조건을 각각 완화 성질과 근사 성질이라 한다.[^1]

$$
\Vert AS^{\nu}\Vert\le\eta(\nu)h^{-2},\qquad \Vert A^{-1}-PA_c^{-1}R\Vert\le Ch^{2}
$$

**정리(Hackbusch).** 두 조건이 성립하고 $\eta(\nu)\to 0$ 이면, 충분히 큰 $\nu$ 에서 두 단계 방법의 오차 감소 인자가 $C\eta(\nu)\lt 1$ 로 묶이고 이 값은 $h$ 에 의존하지 않는다.

증명의 요지는 두 노름을 곱하는 것이다. 두 단계 반복의 오차 연산자는 $(A^{-1}-PA_c^{-1}R)AS^{\nu}$ 이고, 앞 인자를 근사 성질로 뒤 인자를 완화 성질로 묶으면 $h^{2}\cdot h^{-2}=1$ 이 되어 $h$ 가 사라진다. V 사이클은 성긴 단계를 정확히 풀지 않고 재귀로 근사하므로 여기에 한 단계 더 귀납이 필요하다. ∎

수렴률이 $h$ 와 무관하다는 것이 이 방법의 성질이다. [공액기울기법](krylov-subspace-methods.md)의 반복 횟수는 조건수의 제곱근에 비례해 $h^{-1}$ 규모로 늘어난다.

## 대수적 다중격자

격자가 명시적으로 없으면 행렬 성분만으로 단계를 만든다. $\vert a_{ij}\vert$ 가 같은 행의 다른 성분에 비해 크면 변수 $i$ 와 $j$ 가 강하게 결합되었다고 보고, 강한 결합 관계에서 극대독립집합 비슷한 것을 골라 성긴 변수 집합으로 삼는다. 보간은 성긴 변수의 값으로 촘촘한 변수를 표현하되 계수를 행의 성분에서 읽는다.[^2]

# 활용

- **전처리.** V 사이클 한 번을 $M^{-1}v$ 계산으로 쓰면 [전처리](preconditioning.md)된 공액기울기법이 된다. 수렴률이 $h$ 와 무관하므로 스펙트럼 등가 상수도 그렇다.
- **편미분방정식.** 확산 항이 지배하는 이산화 계에서 표준 해법이다. 이류 항이 섞이면 완화가 고주파를 지우지 못해 흐름 방향을 따르는 순서로 완화하거나 반방향 성긴 격자를 쓴다.
- **[그래프 Laplacian](graph-laplacian.md).** 대수적 다중격자를 [그래프](graphs.md)의 Laplacian 계에 적용하면 성긴 단계가 정점을 뭉친 그래프가 된다.

[^1]: Wolfgang Hackbusch, *Multi-Grid Methods and Applications*, Springer Series in Computational Mathematics 4 (1985), 6–7장. 완화 성질과 근사 성질에서 두 단계 수렴을 얻고 V 사이클로 확장하는 논증이 이 장에 있다.
[^2]: John W. Ruge, Klaus Stüben, *Algebraic multigrid*, in Multigrid Methods, SIAM Frontiers in Applied Mathematics 3 (1987), 73–130.
