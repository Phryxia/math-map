# 오류정정부호

# 개요

통신 선로와 저장 장치는 비트를 가끔 뒤집는다. 오류정정부호는 메시지에 계산된 잉여 정보를 덧붙여, 몇 개의 비트가 망가져도 원래 메시지를 되찾도록 만드는 방법이다.

핵심 착상은 기하적이다. 가능한 모든 문자열이 놓인 공간에서 실제로 쓰는 문자열(부호어)을 서로 멀찍이 떨어뜨려 놓으면, 몇 글자가 바뀐 문자열이라도 여전히 원래 부호어가 가장 가깝다. 그래서 부호 설계는 "서로 먼 점들을 많이 배치하는 문제" 가 된다.

이 문제가 다루기 쉬워지는 것은 부호를 [유한체](finite-fields.md) 위의 [벡터 공간](vector-spaces.md)의 부분공간으로 잡을 때다. 부분공간이면 부호어의 개수가 차원으로 정해지고, 최소거리 계산이 최소 무게 계산으로 줄며, 부호화와 복호가 행렬 연산이 된다. 두 문서를 선수지식으로 두는 이유가 여기에 있다.

# 직관

## 반복은 비싸다

같은 비트를 세 번씩 보내면 한 비트 오류를 고칠 수 있다. 다수결로 읽으면 되기 때문이다. 대신 전송량이 세 배가 된다. 더 영리한 방법은 여러 비트를 한꺼번에 보고 패리티를 계산하는 것이다. Hamming 부호는 4 비트를 7 비트로 늘리는 것만으로 한 비트 오류를 고친다. 반복부호로 같은 능력을 얻으려면 12 비트가 필요하다.

## 공을 채우는 문제

부호어마다 반지름 `t` 인 공(거리 `t` 이내의 문자열 전체)을 생각하자. 이 공들이 서로 겹치지 않으면 `t` 개까지의 오류를 고칠 수 있다. 공간의 크기가 유한하므로 공의 개수와 크기에는 한계가 있고, 이것이 부호의 성능 한계를 준다. 좋은 부호를 찾는 일은 유한한 공간에 공을 빽빽하게 채우는 문제다.

# 정의

## Hamming 거리와 부호

`F_q` 를 원소가 `q` 개인 유한체라 하자. 두 벡터의 Hamming 거리는 다른 자리의 개수이고, 무게는 0 이 아닌 자리의 개수다.

$$
d(x,y)=\lvert\{i:x_i\neq y_i\}\rvert,\qquad w(x)=d(x,0)
$$

부호 `C ⊆ F_q^n` 의 최소거리는 서로 다른 두 부호어 사이 거리의 최솟값이다.

## 선형부호

`C` 가 `F_q^n` 의 `k` 차원 부분공간이면 선형부호라 하고 `[n, k, d]_q` 로 쓴다. `k/n` 을 부호율이라 한다. 선형이면 두 부호어의 차가 다시 부호어이므로 다음이 성립한다.

$$
d=\min_{c\in C,\ c\neq0}w(c)
$$

즉 모든 쌍을 볼 필요 없이 0 이 아닌 부호어의 무게만 보면 된다. 부호는 두 행렬로 기술된다. 생성행렬 `G` 는 메시지를 부호어로 보내고(`c = mG`), 패리티 검사행렬 `H` 는 부호어를 0 으로 보낸다(`Hc^T = 0`). 수신어 `y = c + e` 에 대해 `Hy^T = He^T` 를 신드롬이라 하며, 신드롬은 보낸 메시지가 아니라 오류만 반영한다.

## 정정 능력

최소거리가 `d` 이면 `t = ⌊(d−1)/2⌋` 개까지의 오류를 정정할 수 있고, `d−1` 개까지의 오류를 검출할 수 있다. 지워진 자리의 위치를 아는 소실(erasure) 이라면 `d−1` 개까지 복구할 수 있다. 위치를 모르는 오류가 위치를 아는 소실보다 두 배 비싼 셈이다.

# 성질

## 한계

- **Singleton 한계.** `d ≤ n − k + 1`. 등호를 달성하는 부호를 MDS 라 하고, 잉여 기호 하나가 소실 하나를 정확히 막는 가장 효율적인 상태다.
- **Hamming(구 채우기) 한계.** 반지름 `t` 인 공들이 겹치지 않으므로 다음이 성립한다.

$$
q^k\sum_{i=0}^{t}\binom{n}{i}(q-1)^i\le q^n
$$

등호를 달성하면 완전부호라 하고, 공간에 빈틈이 전혀 없다는 뜻이다. Hamming 부호와 Golay 부호가 그런 예이며 완전부호는 극히 드물다.

## Hamming 부호

패리티 검사행렬의 열을 `1` 부터 `2^r − 1` 까지의 이진 표현으로 채우면 `[2^r − 1,\ 2^r − 1 − r,\ 3]` 부호가 된다. 열이 모두 다르고 0 이 아니므로 어떤 두 열도 합이 0 이 아니어서 최소거리가 3 이다. 복호는 놀랍도록 단순하다. 신드롬을 이진수로 읽으면 그 값이 곧 오류가 난 자리의 번호다.

## Reed–Solomon 부호

메시지를 차수가 `k` 미만인 다항식으로 보고, 서로 다른 `n` 개의 점에서 평가한 값을 부호어로 삼는다.

$$
c=\big(f(x_1),\dots,f(x_n)\big),\qquad \deg f<k
$$

0 이 아닌 다항식의 근은 많아야 `k−1` 개이므로 서로 다른 두 부호어는 최대 `k−1` 자리에서만 일치한다. 따라서 `d ≥ n−k+1` 이고 Singleton 한계와 맞아 MDS 다. 복호는 보간이다. 살아남은 점이 `k` 개면 그 점들을 지나는 차수 `k` 미만 다항식이 유일하므로 원래 메시지가 복원된다. 위치를 모르는 오류까지 고치려면 Berlekamp–Massey 나 Euclid 알고리즘으로 오류 위치 다항식을 먼저 찾는다.

같은 원리가 Shamir 비밀분산이다. 비밀을 상수항에 숨기고 `n` 명에게 평가값을 나눠 주면 `k` 명이 모여야 복원되고, `k−1` 명은 아무 정보도 얻지 못한다. 부호이론과 암호가 같은 사실의 양면이라는 점이 잘 드러난다.

## 두 부호를 직접 구현

Hamming(7,4) 의 신드롬 복호와 Reed–Solomon 의 소실 복구를 확인한다.

```python
from itertools import product

# H 의 j 번째 열 = 숫자 j+1 의 이진 표현
Hm = [[int(b) for b in f"{j:03b}"] for j in range(1, 8)]
syndrome = lambda y: tuple(sum(y[j] * Hm[j][i] for j in range(7)) % 2 for i in range(3))

C = [v for v in product((0, 1), repeat=7) if syndrome(v) == (0, 0, 0)]
print(len(C), min(sum(a != b for a, b in zip(u, v))
                  for u in C for v in C if u != v))     # 16 3  → [7,4,3]

ok = True
for c in C:
    for i in range(7):                                  # 모든 1비트 오류를 시험한다
        y = list(c)
        y[i] ^= 1
        pos = int("".join(map(str, syndrome(y))), 2) - 1  # 신드롬이 오류 위치
        y[pos] ^= 1
        ok &= tuple(y) == c
print(ok)                                               # True

p = 97                                                  # GF(97) 위의 RS
def lagrange(pts, x0):
    tot = 0
    for i, (xi, yi) in enumerate(pts):
        num = den = 1
        for j, (xj, _) in enumerate(pts):
            if i != j:
                num, den = num * (x0 - xj) % p, den * (xi - xj) % p
        tot = (tot + yi * num * pow(den, p - 2, p)) % p  # Fermat 소정리로 역원
    return tot

msg = [(1, 12), (2, 45), (3, 7)]                        # k=3 개의 값이 메시지
cw = [(x, lagrange(msg, x)) for x in range(1, 7)]       # n=6 개 점으로 확장
print(cw)
# [(1, 12), (2, 45), (3, 7), (4, 92), (5, 9), (6, 49)]
left = [cw[1], cw[3], cw[5]]                            # 세 자리가 통째로 소실
print([lagrange(left, x) for x in (1, 2, 3)])           # [12, 45, 7]  완전 복구
```

Hamming 쪽에서 부호어가 16 개(`2^4`)이고 최소거리가 3 이라는 것이 `[7,4,3]` 이라는 이름 그대로다. Reed–Solomon 쪽에서는 여섯 자리 중 셋이 사라져도 남은 셋만으로 원래 값이 그대로 돌아온다. `n−k = 3` 이므로 Singleton 한계가 허용하는 최대치를 정확히 쓰고 있다.

# 활용

## 저장과 전송

QR 코드는 Reed–Solomon 을 써서 그림이 겹치거나 일부가 찢겨도 읽힌다. CD, DVD, 위성 통신, 휴대전화 통신, 플래시 메모리의 컨트롤러가 모두 오류정정부호 위에서 돌아간다. 분산 저장 시스템은 복제 대신 소실 부호를 써서 같은 내구성을 훨씬 적은 용량으로 얻는데, RAID 6 와 여러 객체 스토리지가 쓰는 방식이다.

## 부호율과 잡음의 교환

Shannon 의 채널 부호화 정리는 채널 용량보다 낮은 부호율이면 오류 확률을 원하는 만큼 0 에 가깝게 만드는 부호가 존재한다고 말한다. 존재만 보장할 뿐 구성을 주지 않는다는 점이 이 정리의 한계였고, 대수적 구성(Hamming, BCH, Reed–Solomon)과 반복 복호 기반 부호(LDPC, Turbo, Polar)가 그 간극을 메워 왔다. [무손실 부호화](source-coding.md)가 잉여를 제거하는 일이라면 오류정정부호는 잉여를 정확히 계산해 다시 넣는 일이고, 두 작업의 순서와 분업이 통신 시스템 설계의 기본 구도다.

## 다른 분야로의 파급

소실 부호와 비밀분산의 동일성은 암호 프로토콜에서 널리 쓰이고, 부호이론의 거리 한계는 조합론의 설계 이론, 격자 문제, 계산복잡도의 하드니스 증폭과 직접 연결된다. 부호를 다항식 평가로 보는 관점은 확률적 검증 가능 증명과 영지식 증명의 기본 장치이기도 하다.
