# Compactness

# 개요

[위상 공간](topology.md)의 부분집합이 **compact** 하다는 것은 모든 열린 덮개에서 유한 부분덮개를 뽑을 수 있다는 뜻이다.

유한집합에서는 최댓값이 반드시 존재하고, 각 점에서 성립하는 성질이 전체에서 균등하게 성립하며, 무한히 이어지는 과정이 제자리로 돌아온다. Compactness 는 공간이 유한하지 않아도 이 논증을 흉내 낼 수 있게 한다. 열린집합만으로 서술되는 조건이면서 최댓값 정리와 균등연속성을 떠받친다.

# 직관

## 유한성의 대용

각 점 $x$ 마다 그 점 근방에서 성립을 보장하는 열린집합 $U_x$ 가 있고 근방들의 합집합이 공간 전체를 덮는다고 하자. Compactness 로 유한 개를 골라내면 유한 개의 보장 중 가장 나쁜 것을 취해 전체에 쓸 수 있다.

가장 나쁜 것을 취하는 마지막 단계가 유한성을 요구한다. 무한 개의 $\delta$ 의 하한은 $0$ 일 수 있다. 연속함수가 컴팩트 집합에서 균등연속이 되는 증명이 이 모양이고, 컴팩트성을 쓰는 논증 대부분이 같은 골격이다.

## 컴팩트성이 깨지는 방식

$(0,1)$ 에서 $U_n = (1/n, 1)$ 은 전체를 덮지만 유한 개로는 덮지 못한다. 유한 개를 골라도 그중 가장 큰 $n$ 의 구간까지만 얻고 $0$ 근처를 놓친다. $\mathbb R$ 에서 $U_n = (-n, n)$ 도 무한대 쪽에서 같은 일을 한다.

$\mathbb R^n$ 에서 컴팩트하지 않은 이유는 구멍이 있거나 무한히 뻗어 있거나 둘뿐이고, 이것이 Heine–Borel 정리의 "닫혀 있고 유계" 다.

## 세 가지 동치 조건

거리 공간에서는 열린 덮개 조건, 점열 컴팩트, 완비이면서 전유계가 모두 같다. 존재를 끌어낼 때는 부분수열, 균등성을 얻을 때는 덮개, 구체적 공간을 판정할 때는 완비와 전유계를 쓴다. 거리 구조가 없는 일반 위상공간에서는 이 동치가 깨지므로 어느 정의를 쓰는지 명시해야 한다.

# 정의

## 열린 덮개와 compactness

$X$ 를 위상 공간이라 하고 $K \subseteq X$ 와 인덱스 집합 $I$ 를 두자. 각 $i$ 에 대해 $U_i$ 가 $X$ 의 열린집합이고

$$
K\subseteq\bigcup_{i\in I}U_i
$$

이면 $\lbrace U_i\rbrace$ 를 $K$ 의 **열린 덮개**라 한다. 모든 열린 덮개에 대해 유한 부분집합 $J \subseteq I$ 를 골라

$$
|J|<\infty,\qquad K\subseteq\bigcup_{i\in J}U_i
$$

로 만들 수 있으면 $K$ 는 **compact** 하다.

동치인 형태로 **유한 교집합 성질**이 있다. 닫힌집합들의 모임에서 유한 개를 뽑을 때마다 교집합이 비지 않으면 전체 교집합도 비지 않는다. 이 형태가 존재 증명에 쓰이며, 논리의 컴팩트성 정리와 같은 모양이라는 점이 이름의 유래다.

## 점열 컴팩트와 전유계

$K$ 의 모든 수열이 $K$ 의 점으로 수렴하는 부분수열을 가지면 **점열 컴팩트**다. $K$ 가 임의의 $\varepsilon > 0$ 에 대해 유한 개의 반지름 $\varepsilon$ 공으로 덮이면 **전유계**다. 전유계는 유계보다 강한 조건이며, 무한 이산 공간이 유계이면서 전유계가 아닌 예다.

# 성질

## 판정과 반례

- 유한집합은 컴팩트하다. 각 점을 덮는 열린집합을 하나씩 고르면 된다.
- **Heine–Borel.** $\mathbb R^n$ 의 부분집합이 컴팩트한 것과 닫혀 있고 유계인 것은 동치다.
- 일반 거리 공간에서는 닫혀 있고 유계라는 조건으로 충분하지 않다. 무한집합에 이산 거리를 주면 전체가 닫혀 있고 유계이지만 한 점짜리 열린집합들의 덮개에 유한 부분덮개가 없다.
- 거리 공간에서 컴팩트인 것과 완비이면서 전유계인 것은 동치다. 무한 이산 공간이 실패하는 이유는 전유계가 아니기 때문이다.
- 컴팩트 공간의 닫힌 부분집합은 컴팩트하다. Hausdorff 공간에서는 역으로 컴팩트 부분집합이 닫혀 있다.

```python
def needs_infinite_cover(intervals, target):
    """target 을 덮는 열린구간 목록에서 유한 부분덮개를 그리디로 찾아본다."""
    lo, hi = target
    cur = lo
    used = 0
    while cur < hi:
        best = None
        for (a, b) in intervals:
            if a < cur + 1e-15 < b or (a <= cur < b):
                if best is None or b > best:
                    best = b
        if best is None or best <= cur:
            return used, cur          # 여기서 막혔다
        cur, used = best, used + 1
    return used, None

cover = [(1 / n, 1.0) for n in range(2, 200)]
print(needs_infinite_cover(cover, (0.0, 1.0)))     # 0 을 덮는 구간이 없다
print(needs_infinite_cover(cover, (0.02, 1.0)))    # 유한 개로 끝난다
```

$(0,1)$ 전체를 목표로 하면 좌단에서 막히고 좌단을 조금만 안쪽으로 옮기면 유한 개로 끝난다. 컴팩트성이 깨지는 지점이 경계에 몰려 있다.

## 연속함수와의 관계

컴팩트 집합의 연속상은 컴팩트하다. 상의 덮개를 역상으로 끌어와 유한 부분덮개를 뽑고 다시 밀어내면 된다. 여기서 여러 정리가 따라 나온다.

- **최대·최소 정리.** 비어 있지 않은 컴팩트 공간 위의 실수값 연속함수는 최댓값과 최솟값을 갖는다. 상이 $\mathbb R$ 의 컴팩트 집합이라 닫혀 있고 유계이므로 상한을 달성한다.
- **균등연속.** 컴팩트 거리 공간 위의 연속함수는 균등연속이다.
- 컴팩트 공간에서 Hausdorff 공간으로 가는 연속 전단사는 위상동형이다. 역함수의 연속성을 따로 증명하지 않아도 된다.

## 곱과 Tychonoff

유한 개 컴팩트 공간의 곱은 컴팩트하다. 임의 개의 곱까지 확장한 것이 Tychonoff 정리이며 [선택공리](axiom-of-choice.md)와 동치다. 무한 곱에서도 컴팩트성이 유지된다는 사실이 함수공간과 논리의 컴팩트성 정리를 떠받친다.

## 수열 조건과의 차이

거리 공간에서는 컴팩트와 점열 컴팩트가 동치이지만 일반 위상공간에서는 아니다. $[0,1]^{[0,1]}$ 은 Tychonoff 정리로 컴팩트하지만 점열 컴팩트가 아니고, 첫 번째 비가산 서수의 구간은 점열 컴팩트이지만 컴팩트가 아니다.

# 활용

## 존재정리

최적화에서 최적해의 존재는 대개 허용 영역의 컴팩트성으로 답한다. [볼록성](convexity.md)이 국소해와 전역해를 잇고 컴팩트성이 존재를 보장하며, 둘 중 하나만으로는 부족하다. $(0,1)$ 위의 항등함수는 볼록하지만 최솟값을 갖지 않는다.

변분법의 직접법도 최소화열을 뽑아 부분수열의 극한을 취한다. 무한차원에서는 노름 컴팩트성이 너무 강하므로 약위상을 도입해 컴팩트성을 되살린다.

## 국소에서 전역으로

각 점 근방의 정보를 유한 개로 줄여 전체에 대한 결론을 내는 논증에 쓰인다. 균등연속, Lebesgue 수 보조정리, 다양체 위의 단위 분할 구성이 여기 속한다. 미분기하와 대수위상에서 컴팩트 다양체를 가정하는 것도 국소 좌표계를 유한 개로 줄이기 위해서다.

## 분류 문제의 전제

[곡면의 분류](classification-of-surfaces.md)는 컴팩트하고 경계가 없는 곡면에 대한 정리다. 컴팩트성이 없으면 무한히 많은 손잡이를 붙인 곡면 같은 대상이 들어와 유한한 불변량으로 분류할 수 없다. Euler 지표가 유한한 값으로 정의되고 삼각분할이 유한 개의 조각으로 끝나는 것이 컴팩트성의 결과다.[^1]
