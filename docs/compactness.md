# Compactness

# 개요

유한집합에서는 거의 모든 것이 쉽다. 최댓값은 반드시 존재하고, 각 점에서 성립하는 성질은 전체에서 균등하게 성립하며, 무한히 이어지는 과정은 결국 제자리로 돌아온다. 무한집합에서 이 편리함이 무너지는 것이 해석학의 어려움 대부분이다.

Compactness 는 이 편리함을 되찾는 조건이다. 공간이 유한한 것은 아니지만, 열린집합으로 덮을 때마다 유한 개만 남겨도 충분하다면 유한집합의 논증을 거의 그대로 흉내 낼 수 있다. [위상 공간](topology.md)의 열린집합만으로 서술되는 조건이면서, 최댓값 정리와 균등연속성처럼 해석학의 핵심 결과를 모두 떠받친다.

# 직관

## 유한성을 흉내 내는 장치

"각 점에서 성립한다" 를 "전체에서 균등하게 성립한다" 로 끌어올리는 논증을 생각해 보자. 각 점 $x$ 마다 그 점 근방에서 성립을 보장하는 열린집합 $U_x$ 가 있다. 근방들의 합집합은 공간 전체를 덮는다. 이제 compactness 로 유한 개를 골라내면, 유한 개의 보장 중 가장 나쁜 것을 취해 전체에 쓸 수 있다.

"가장 나쁜 것을 취한다" 는 이 마지막 단계가 유한성을 요구한다. 무한 개의 $\delta$ 의 하한은 $0$ 일 수 있기 때문이다. 연속함수가 컴팩트 집합에서 균등연속이 되는 증명이 정확히 이 모양이고, 컴팩트성을 쓰는 논증의 대부분이 같은 골격을 공유한다.

## 새어 나갈 곳이 없다

$(0,1)$ 에서 $U_n = (1/n, 1)$ 은 전체를 덮지만 유한 개로는 덮지 못한다. 유한 개를 골라 봐야 그중 가장 큰 $n$ 의 구간까지만 얻고 $0$ 근처를 놓친다. 수열 $1/n$ 이 공간 밖으로 빠져나가려 하는데 막을 것이 없는 상황이다.

$\mathbb R$ 에서 $U_n = (-n, n)$ 도 같은 일을 무한대 쪽에서 한다. 그래서 $\mathbb R^n$ 에서 컴팩트하지 않은 이유는 딱 두 가지, 구멍이 있거나 무한히 뻗어 있거나다. 이것이 Heine–Borel 정리가 말하는 "닫혀 있고 유계" 의 의미다.

## 세 가지 얼굴

거리 공간에서는 서로 다르게 생긴 조건 셋이 같아진다.

```mermaid

  B <--> C["완비 + 전유계"]
```

증명에서는 셋 중 가장 편한 것을 골라 쓴다. 존재를 끌어낼 때는 부분수열, 균등성을 얻을 때는 덮개, 구체적 공간을 판정할 때는 완비와 전유계를 쓰는 것이 보통이다. 거리 구조가 없는 일반 위상공간에서는 이 동치가 깨지므로 어느 정의를 쓰는지 명시해야 한다.

# 정의

## 열린 덮개와 compactness

$X$ 를 위상 공간이라 하고, $K \subseteq X$ 와 $I$ 를 인덱스 집합이라 하자. 각 $i$ 에 대해 $U_i$ 가 $X$ 의 열린집합이고

$$
K\subseteq\bigcup_{i\in I}U_i
$$

이면 $\{U_i\}$ 를 $K$ 의 열린 덮개라 한다. 모든 열린 덮개에 대해 유한 부분집합 $J \subseteq I$ 를 골라

$$
|J|<\infty,\qquad K\subseteq\bigcup_{i\in J}U_i
$$

로 만들 수 있으면 $K$ 는 compact 하다. 공간이 유한하다는 뜻이 아니라 덮개에서 유한 개를 뽑을 수 있다는 뜻이다.

동치인 형태로 유한 교집합 성질이 있다. 닫힌집합들의 모임에서 유한 개를 뽑을 때마다 교집합이 비지 않으면 전체 교집합도 비지 않는다. 이 형태가 존재 증명에 바로 쓰이며, 논리의 컴팩트성 정리와 같은 모양이라는 점이 이름의 유래다.

## 점열 컴팩트와 전유계

$K$ 의 모든 수열이 $K$ 의 점으로 수렴하는 부분수열을 가지면 점열 컴팩트라 한다. $K$ 가 임의의 $\varepsilon > 0$ 에 대해 유한 개의 반지름 $\varepsilon$ 공으로 덮이면 전유계라 한다. 전유계는 유계보다 강한 조건이며, 무한 이산 공간이 유계이면서 전유계가 아닌 표준 예다.

# 성질

## 판정과 반례

- 유한집합은 컴팩트하다. 각 점을 덮는 열린집합을 하나씩 고르면 된다.
- **Heine–Borel.** $\mathbb R^n$ 의 부분집합이 컴팩트한 것과 닫혀 있고 유계인 것은 동치다.
- 일반 거리 공간에서는 닫혀 있고 유계라는 조건으로 충분하지 않다. 무한집합에 이산 거리를 주면 전체가 닫혀 있고 유계이지만, 한 점짜리 열린집합들의 덮개에 유한 부분덮개가 없다.
- 거리 공간에서 컴팩트인 것과 완비이면서 전유계인 것은 동치다. 무한 이산 공간이 실패하는 이유가 전유계가 아니기 때문임을 이 기준이 설명한다.
- 컴팩트 공간의 닫힌 부분집합은 컴팩트하다. Hausdorff 공간에서는 역으로 컴팩트 부분집합이 닫혀 있다.

```python
def needs_infinite_cover(intervals, target):
    """target 을 덮는 열린구간 목록에서 유한 부분덮개를 그리디로 찾아본다."""
    lo, hi = target
    cur = lo
    used = 0
    while cur < hi:
        best = None
        for (a, b) in intervals:
            if a < cur + 1e-15 < b or (a <= cur < b):
                if best is None or b > best:
                    best = b
        if best is None or best <= cur:
            return used, cur          # 여기서 막혔다
        cur, used = best, used + 1
    return used, None


cover = [(1 / n, 1.0) for n in range(2, 200)]
print(needs_infinite_cover(cover, (0.0, 1.0)))     # 0 을 덮는 구간이 없다
print(needs_infinite_cover(cover, (0.02, 1.0)))    # 유한 개로 끝난다
```

$(0,1)$ 전체를 목표로 하면 좌단에서 곧바로 막히고, 좌단을 조금만 안쪽으로 옮기면 유한 개로 끝난다. 컴팩트성이 깨지는 지점이 정확히 경계에 몰려 있음을 보여 준다.

## 연속함수와의 관계

컴팩트 집합의 연속상은 컴팩트하다. 상의 덮개를 역상으로 끌어와 유한 부분덮개를 뽑고 다시 밀어내면 된다. 이 한 줄에서 여러 정리가 따라 나온다.

- **최대·최소 정리.** 비어 있지 않은 컴팩트 공간 위의 실수값 연속함수는 최댓값과 최솟값을 갖는다. 상이 $\mathbb R$ 의 컴팩트 집합이므로 닫혀 있고 유계이고, 따라서 상한을 실제로 달성한다.
- **균등연속.** 컴팩트 거리 공간 위의 연속함수는 균등연속이다.
- 컴팩트 공간에서 Hausdorff 공간으로 가는 연속 전단사는 위상동형이다. 역함수의 연속성을 따로 증명하지 않아도 된다는 점에서 실용적이다.

## 곱과 Tychonoff

유한 개 컴팩트 공간의 곱은 컴팩트하다. 임의 개의 곱까지 확장한 것이 Tychonoff 정리이며 [선택공리](axiom-of-choice.md)와 동치다. 무한 곱에서도 컴팩트성이 유지된다는 사실이 함수공간과 논리의 컴팩트성 정리를 떠받친다.

## 수열 조건과의 차이

거리 공간에서는 컴팩트와 점열 컴팩트가 동치이지만 일반 위상공간에서는 아니다. $[0,1]^{[0,1]}$ 은 Tychonoff 정리로 컴팩트하지만 점열 컴팩트가 아니고, 첫 번째 비가산 서수의 구간은 점열 컴팩트이지만 컴팩트가 아니다. 거리 공간의 직관을 일반 위상공간에 그대로 옮기면 안 되는 대표적인 자리다.

# 활용

## 존재정리

최적화에서 "최적해가 존재하는가" 는 대개 허용 영역의 컴팩트성으로 답한다. [볼록성](convexity.md)이 국소해와 전역해를 잇고 컴팩트성이 존재를 보장하는 분업이며, 둘 중 하나만으로는 부족하다. $(0,1)$ 위의 항등함수가 볼록하지만 최솟값을 갖지 않는 것이 그 예다.

변분법에서 "최소화열을 뽑아 부분수열의 극한을 취한다" 는 직접법도 같은 구조다. 무한차원에서는 노름 컴팩트성이 너무 강하므로 약위상을 도입해 컴팩트성을 되살리는 것이 표준 기법이다.

## 국소에서 전역으로

각 점 근방의 정보를 유한 개로 줄여 전체에 대한 결론을 내는 논증에 반복해서 쓰인다. 균등연속, Lebesgue 수 보조정리, 다양체 위의 단위 분할 구성이 모두 여기에 속한다. 미분기하와 대수위상에서 "컴팩트 다양체" 를 가정하는 이유도 국소 좌표계를 유한 개로 줄이기 위해서다.

## 분류 문제의 전제

[곡면의 분류](classification-of-surfaces.md)는 컴팩트하고 경계가 없는 곡면, 즉 닫힌 곡면에 대한 정리다. 컴팩트성이 없으면 무한히 많은 손잡이를 붙인 곡면 같은 대상이 들어와 유한한 불변량으로 분류할 수 없다. Euler 지표가 유한한 값으로 정의되고 삼각분할이 유한 개의 조각으로 끝나는 것이 모두 컴팩트성의 결과이며, "유한 개로 줄인다" 는 이 조건의 성격이 분류 가능성 자체를 만들어 낸다.[^1]

[^1]: Jiří Lebl, *Basic Analysis*, Completeness and compactness. 거리 공간의 컴팩트성, 수열 조건과의 동치, Heine–Borel 정리. https://www.jirka.org/ra/html/sec_metcompact.html
