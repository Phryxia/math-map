# Chaikin 알고리즘

# 개요

**Chaikin 알고리즘(Chaikin's algorithm)** 은 꺾은선의 모서리를 깎아 내는 일을 되풀이해 매끄러운 곡선을 얻는 방법이다. 정사각형의 네 꼭짓점을 이은 꺾은선을 둥근 곡선으로 바꾸고 싶은데, 곡선의 식을 세우지 않고 점의 좌표만 고쳐서 하고 싶다고 하자. 각 변을 $1:2:1$ 로 세 토막 내어 가운데 토막만 남기면 모서리가 하나씩 깎인다. 이것을 되풀이하면 꺾은선이 원래 꺾은선의 2차 [B-스플라인](b-splines.md) 곡선으로 수렴한다.

# 직관

정사각형의 꼭짓점 $(0,0)$, $(1,0)$, $(1,1)$, $(0,1)$ 을 차례로 잇고 마지막 점을 처음 점에 다시 이은 닫힌 꺾은선을 놓는다. 변 $(0,0)\text{–}(1,0)$ 위에 $1/4$ 지점 $(0.25,0)$ 과 $3/4$ 지점 $(0.75,0)$ 을 찍는다. 네 변에 모두 이렇게 하면 다음 여덟 점이 나온다.

$$
\begin{aligned}
&(0.25,0),\quad(0.75,0),\quad(1,0.25),\quad(1,0.75),\cr
&(0.75,1),\quad(0.25,1),\quad(0,0.75),\quad(0,0.25)
\end{aligned}
$$

이 여덟 점을 차례로 이으면 정사각형의 네 모서리가 잘려 나간 팔각형이다. 꼭짓점 $(1,0)$ 근처의 모서리는 선분 $(0.75,0)\text{–}(1,0.25)$ 로 바뀌었다.

같은 일을 팔각형에 하면 점이 $16$ 개가 되고 모서리가 더 무뎌진다. 꼭짓점 $(1,0)$ 쪽에서 곡선이 수렴하는 점은 $(0.875,0.125)$ 다. 이 값은 성질 절에서 변의 가운데 점 $(0.5,0)$ 과 $(1,0.5)$ 를 끝점으로 하고 $(1,0)$ 을 손잡이로 하는 2차 [Bézier 곡선](bezier-curves.md)의 $t=1/2$ 에서의 점으로 나온다.

# 정의

꺾은선 $P_0,P_1,\dots,P_n$ 에 대해 Chaikin 알고리즘의 한 단계는 각 변 $P_iP_{i+1}$ 을 다음 두 점으로 바꾼다.

$$
Q_i=\frac34P_i+\frac14P_{i+1},\qquad R_i=\frac14P_i+\frac34P_{i+1}
$$

새 꺾은선은 $Q_0,R_0,Q_1,R_1,\dots$ 의 순서로 잇는다. 닫힌 꺾은선이면 $P_n$ 과 $P_0$ 을 잇는 변도 바꾸고, 점의 수가 한 단계마다 두 배가 된다. 직관 절의 여덟 점은 정사각형의 네 변에서 나온 $Q_i,R_i$ 다.

```javascript
// closed 가 참이면 마지막 점과 첫 점을 잇는 변도 깎는다
function chaikinStep(points, closed) {
  const out = [];
  const m = closed ? points.length : points.length - 1;
  for (let i = 0; i < m; i++) {
    const p = points[i], q = points[(i + 1) % points.length];
    out.push(p.map((x, k) => 0.75 * x + 0.25 * q[k]));
    out.push(p.map((x, k) => 0.25 * x + 0.75 * q[k]));
  }
  return out;
}
```

# 성질

## 극한은 2차 B-스플라인

닫힌 꺾은선에 Chaikin 알고리즘을 되풀이하면, 꺾은선은 같은 간격의 매듭을 가진 2차 B-스플라인 곡선으로 수렴한다[^1]. 그 곡선은 B-스플라인 문서의 직관 절처럼 이웃한 세 점 $P_0,P_1,P_2$ 마다 다음 2차 Bézier 조각을 이은 것이다.

$$
M_0=\frac{P_0+P_1}2,\qquad P_1,\qquad M_1=\frac{P_1+P_2}2
$$

이 조각을 Bézier 곡선 문서의 분할 성질로 $t=1/2$ 에서 나누면 왼쪽 절반의 제어점은 다음이다.

$$
M_0,\qquad \frac{M_0+P_1}2=\frac14P_0+\frac34P_1,\qquad \frac18P_0+\frac34P_1+\frac18P_2
$$

가운데 점은 $R_0$ 이고, 셋째 점은 $R_0$ 과 $Q_1$ 의 가운데 점이며, 첫 점 $M_0$ 은 $Q_0$ 과 $R_0$ 의 가운데 점이다. 따라서 새 꺾은선 $Q_0,R_0,Q_1,\dots$ 의 2차 B-스플라인 조각은 원래 곡선의 조각을 반으로 나눈 것이고, 두 꺾은선이 정하는 곡선은 같다.

## 수렴 속도

한 단계는 모든 Bézier 조각을 반으로 나누는 것이므로, 꺾은선과 극한 곡선 사이의 거리의 상한은 단계마다 $1/4$ 배가 된다. 직관 절의 정사각형에서 꼭짓점 $(1,0)$ 과 극한 곡선 위의 점 $(0.875,0.125)$ 사이의 거리는 약 $0.177$ 이다.

## 열린 꺾은선의 끝

열린 꺾은선에서는 첫 점 $P_0$ 과 끝 점 $P_n$ 이 첫 단계에서 사라지고, 극한 곡선은 첫 변의 가운데 점에서 시작해 끝 변의 가운데 점에서 끝난다. 끝점을 남기려면 단계마다 $P_0$ 과 $P_n$ 을 새 꺾은선의 양 끝에 다시 붙인다.

## 다른 차수로의 확장

가운데 점을 찍는 단계와 이웃한 점을 평균하는 단계를 번갈아 $p$ 번 되풀이하는 Lane–Riesenfeld 알고리즘(Lane–Riesenfeld algorithm)은 $p$ 차 B-스플라인으로 수렴한다. $p=2$ 이면 Chaikin 알고리즘이다. $p=3$ 이면 새 꼭짓점과 새 변의 점이 다음이다.

$$
\frac18P_{i-1}+\frac34P_i+\frac18P_{i+1},\qquad \frac12(P_i+P_{i+1})
$$

# 활용

- 곡선 그리기. 손으로 찍은 점이나 다각형을 몇 단계만 깎아 화면에 둥근 곡선처럼 보이게 한다. 각 단계는 더하기와 상수배뿐이라 계산이 싸다.
- [세분 곡면](subdivision-surfaces.md). 다각형 그물의 면과 모서리에 같은 꼴의 깎기 규칙을 적용하는 Doo–Sabin 곡면은 Chaikin 알고리즘을 곡면으로 옮긴 것이고, 극한이 2차 B-스플라인 곡면이다. 3차 판본인 Catmull–Clark 곡면은 애니메이션 모델링에서 쓰인다.
- 경로 평활. 로봇이나 지도의 경로를 이루는 꺾은선을 몇 단계 깎으면, 경로가 원래 꺾은선의 볼록 껍질 밖으로 나가지 않은 채 꺾인 곳이 둥글어진다.

[^1]: R. F. Riesenfeld, "On Chaikin's algorithm", Computer Graphics and Image Processing 4 (1975), 304–310.
