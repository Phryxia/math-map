# 비추이적 주사위

# 개요

**비추이적 주사위(nontransitive dice)** 는 A 가 B 를, B 가 C 를, C 가 A 를 각각 절반보다 큰 확률로 이기는 주사위들이다. 면에 $2,2,4,4,9,9$ 와 $1,1,6,6,8,8$ 과 $3,3,5,5,7,7$ 을 적은 세 주사위를 둘씩 맞붙여 큰 눈이 나오는 쪽이 이기게 하면, 셋이 서로 $5/9$ 의 확률로 꼬리를 물고 이긴다. 두 주사위의 승패를 [유한 확률 공간](probability.md)에서 면의 쌍을 세어 계산하면, "더 자주 이긴다" 는 관계가 순서를 이루지 않는다는 것이 드러난다.

# 직관

주사위 A 의 면을 $2,2,4,4,9,9$, B 의 면을 $1,1,6,6,8,8$ 로 하고 둘을 함께 던진다. A 의 눈이 $2$ 이면 B 의 $1$ 만 이기고, $4$ 이면 역시 $1$ 만 이기고, $9$ 이면 모두 이긴다. A 와 B 는 각각 세 값을 확률 $1/3$ 씩 내므로 값의 쌍 9 개가 각각 확률 $1/9$ 이고, A 가 이기는 쌍이 $1+1+3=5$ 개라 A 가 이길 확률은 $5/9$ 다.

B 와 C($3,3,5,5,7,7$)를 맞붙이면 B 의 $1$ 은 하나도 못 이기고, $6$ 은 $3$ 과 $5$ 를 이기고, $8$ 은 모두 이긴다. B 가 이길 확률은 $(0+2+3)/9=5/9$ 다. C 와 A 를 맞붙이면 C 의 $3$ 은 $2$ 를, $5$ 는 $2$ 와 $4$ 를, $7$ 은 $2$ 와 $4$ 를 이기므로 C 가 이길 확률은 $(1+2+2)/9=5/9$ 다.

세 주사위의 평균은 모두 $5$ 다. 그런데 어느 주사위를 골라도 그것을 $5/9$ 로 이기는 주사위가 남아 있다. 상대가 먼저 고르고 내가 나중에 고르면 언제나 내가 유리하다.

# 정의

같은 공간 위의 [확률변수](random-variables.md) $X$ 와 $Y$ 가 독립일 때 $P(X\gt Y)\gt P(Y\gt X)$ 이면 $X$ 가 $Y$ 를 **이긴다** 고 한다. 주사위는 각 면이 같은 확률로 나오는 확률변수다. 확률변수 $X_1,\dots,X_n$ 이 서로 독립이고 $X_1$ 이 $X_2$ 를, $X_2$ 가 $X_3$ 를, $\dots$, $X_n$ 이 $X_1$ 을 이기면 이들을 **비추이적(nontransitive)** 이라 한다.

직관 절의 세 주사위는 $n=3$ 인 비추이적 주사위다. 면 값 $\lbrace 2,4,9\rbrace$, $\lbrace 1,6,8\rbrace$, $\lbrace 3,5,7\rbrace$ 은 가로, 세로, 대각선의 합이 모두 $15$ 인 $3\times 3$ 마방진의 세 행이다.

$$
\begin{pmatrix}4&9&2\cr 3&5&7\cr 8&1&6\end{pmatrix}
$$

# 성질

## 네 주사위

B. Efron 이 만든 네 주사위는 다음과 같다.

| 주사위 | 면                  |
| ------ | ------------------- |
| A      | 4, 4, 4, 4, 0, 0    |
| B      | 3, 3, 3, 3, 3, 3    |
| C      | 6, 6, 2, 2, 2, 2    |
| D      | 5, 5, 5, 1, 1, 1    |

A 는 $4$ 가 나오는 확률 $2/3$ 로 B 를 이긴다. B 는 C 의 $2$ 를 이기므로 $2/3$ 로 이긴다. C 는 $6$ 이 나오면 이기고 $2$ 가 나오면 D 의 $1$ 만 이기므로 $\frac13+\frac23\cdot\frac12=\frac23$ 로 이긴다. D 는 $5$ 가 나오면 이기고 $1$ 이 나오면 A 의 $0$ 만 이기므로 $\frac12+\frac12\cdot\frac13=\frac23$ 로 이긴다.

## 이길 확률의 상한

독립인 확률변수 $n$ 개가 순환하며 이길 때, 순환의 각 대결에서 이길 확률 가운데 가장 작은 것을 최대로 만든 값을 $p_n$ 이라 하자. 다음이 알려져 있다.[^1]

$$
p_3=\frac{\sqrt5-1}{2}\approx 0.618,\qquad p_4=\frac23,\qquad \lim_{n\to\infty}p_n=\frac34
$$

직관 절의 $5/9\approx 0.556$ 은 $p_3$ 보다 작고, Efron 의 주사위는 $p_4$ 에 닿는다. $p_n$ 은 $3/4$ 를 넘지 못하므로 순환에 주사위를 아무리 많이 넣어도 모든 대결을 $3/4$ 이상으로 이기게 할 수는 없다.

## 확률적 순서와의 비교

모든 $t$ 에서 $P(X\gt t)\ge P(Y\gt t)$ 이면 $X$ 가 $Y$ 보다 확률적으로 크다(stochastically larger)고 한다. $X$ 가 $Y$ 보다, $Y$ 가 $Z$ 보다 확률적으로 크면 모든 $t$ 에서 $P(X\gt t)\ge P(Y\gt t)\ge P(Z\gt t)$ 이므로 $X$ 가 $Z$ 보다 확률적으로 크다. 또 $X$ 가 $Y$ 보다 확률적으로 크면 $X$ 는 $Y$ 에게 지지 않는다.

직관 절의 A 와 B 는 이 관계로 비교되지 않는다. $t=1$ 에서는 $P(A\gt 1)=1\gt 2/3=P(B\gt 1)$ 이지만 $t=4$ 에서는 $P(A\gt 4)=1/3\lt 2/3=P(B\gt 4)$ 다. 순환의 모든 대결이 확률적 순서를 따르면 순환을 한 바퀴 돌아 모든 확률변수의 분포가 같아지고 아무도 이기지 못한다. 그래서 비추이적인 순환에는 확률적 순서로 비교되지 않는 쌍이 반드시 있다.

## 평균과의 무관함

평균으로 비교하는 관계는 실수의 순서이므로 추이적이다. 이기는 관계는 두 분포가 겹치는 모양으로 정해지고 평균과는 따로 움직인다. 직관 절의 세 주사위는 평균이 모두 $5$ 인데 서로 순환하며 이긴다.

## 투표의 역설

마방진의 세 행을 세 유권자의 선호로 읽을 수도 있다. 세 유권자가 후보 A, B, C 를 각각 A, B, C 순, B, C, A 순, C, A, B 순으로 좋아하면 A 를 B 보다 좋아하는 유권자가 셋 가운데 둘, B 를 C 보다 좋아하는 유권자가 둘, C 를 A 보다 좋아하는 유권자가 둘이다. 다수결의 승패가 순환하는 이 예를 Condorcet 역설(Condorcet paradox)이라 한다.

[Arrow 불가능성 정리](arrow-impossibility-theorem.md)는 후보가 셋 이상이면 다수결 대신 어떤 집계 규칙을 써도 몇 가지 공정성 조건을 함께 지키는 규칙이 독재뿐임을 보인다. 주사위의 면 쌍을 세는 계산과 유권자의 쌍대 비교를 세는 계산은 같은 꼴이다.

# 활용

- 패턴 경주. [Penney 게임](penney-game.md)에서 길이 $3$ 인 동전 패턴들은 THH, HHT, HTT, TTH 가 차례로 다음 것을 이기는 순환을 이룬다. 나중에 고르는 사람이 언제나 이기는 구조가 비추이적 주사위와 같다.
- 순위 매기기. 쌍대 비교의 승률로 선수나 모형의 순위를 정할 때, 승률이 순환하면 하나의 순서로 정리되지 않는다. [Bradley–Terry 모형](bradley-terry-model.md)처럼 각 대상에 실수 점수 하나를 두는 모형은 승률이 언제나 추이적이라 이런 자료를 맞출 수 없다.
- 다수결 투표. Condorcet 역설은 사회적 선택 이론에서 쌍대 다수결이 선호 순서를 만들지 못하는 예다.
