# Karger 축약 알고리즘

# 개요

**Karger 축약 알고리즘(Karger's contraction algorithm)** 은 무향 그래프에서 간선을 무작위로 하나씩 골라 두 끝점을 한 정점으로 합치기를 정점이 두 개 남을 때까지 되풀이하고, 남은 두 정점 사이의 간선을 절단으로 내놓는 무작위 알고리즘이다. D. R. Karger 가 1993 년에 제안했다[^1]. 한 번 돌려 특정 최소 절단을 얻을 확률이 $1/\binom n2$ 이상이고, 이로부터 무향 그래프의 최소 절단이 $\binom n2$ 개 이하라는 것이 나온다. 최소 절단의 크기는 [Menger 정리](menger-theorem.md)의 간선 연결도이고, 이 알고리즘은 최대 흐름을 쓰지 않고 그 값을 구한다.

# 직관

삼각형 두 개를 간선 하나로 이은 그래프는 정점이 $6$ 개, 간선이 $7$ 개이고, 그래프를 둘로 가르는 가장 작은 간선 집합은 가운데 다리 하나다. 간선을 무작위로 하나 고르면 다리일 확률은 $1/7$ 이고, 나머지 $6/7$ 의 경우에는 같은 삼각형 안의 두 정점을 고른다.

같은 삼각형 안의 두 정점을 한 정점으로 합치면 다리는 그대로 남는다. 다리가 아닌 간선만 계속 고르면 결국 각 삼각형이 정점 하나로 줄고, 두 정점 사이에 다리만 남는다. 최소 절단은 간선이 적으므로 무작위로 고른 간선이 거기에 들 확률이 작고, 끝까지 피할 확률을 곱해도 정점 수의 제곱의 역수 정도는 남는다.

# 정의

여러 겹 간선을 허용하는 무향 그래프 $G=(V,E)$ 에서 간선 $uv$ 를 **축약(contraction)** 한다는 것은 $u$ 와 $v$ 를 새 정점 하나로 바꾸고, $u$ 나 $v$ 에 붙어 있던 간선을 새 정점에 붙이고, $u$ 와 $v$ 사이의 간선은 지우는 것이다. 겹 간선은 그대로 둔다.

$S\subseteq V$ 가 공집합도 $V$ 도 아닐 때 $S$ 와 $V\setminus S$ 를 잇는 간선의 집합 $\delta(S)$ 를 절단이라 하고, 크기가 가장 작은 절단을 **최소 절단(minimum cut)** 이라 한다. 그 크기가 간선 연결도 $\lambda(G)$ 다.

알고리즘은 다음과 같다.

```javascript
// 정점이 두 개 남을 때까지 무작위 간선을 축약한다.
function contract(graph) {
  while (graph.vertexCount() > 2) {
    const e = graph.randomEdge(); // 남은 간선 가운데 균등하게 고른다
    graph.contract(e);            // 끝점을 합치고 그 사이 간선을 지운다
  }
  return graph.edges();           // 남은 두 정점 사이의 간선이 절단이다
}
```

# 성질

## 성공 확률

정리(Karger). 최소 절단 $C$ 하나를 고정하면, 축약 알고리즘이 $C$ 를 내놓을 확률은 $\binom n2^{-1}$ 이상이다[^1].

증명의 요지. $\lvert C\rvert=k$ 이면 정점 하나를 떼는 절단도 $k$ 이상이므로 모든 정점의 차수가 $k$ 이상이고, 간선은 $nk/2$ 개 이상이다. 그래서 첫 축약에서 $C$ 의 간선을 고를 확률은 $k/(nk/2)=2/n$ 이하다. $C$ 의 간선을 고르지 않는 한 축약된 그래프에서도 $C$ 가 최소 절단으로 남으므로, 정점이 $i$ 개 남았을 때 $C$ 의 간선을 고를 확률은 $2/i$ 이하다. 끝까지 피할 확률은

$$
\prod_{i=3}^n\Bigl(1-\frac 2i\Bigr)=\prod_{i=3}^n\frac{i-2}{i}=\frac{2}{n(n-1)}
$$

이상이다.

## 최소 절단의 개수

따름정리. 정점 $n$ 개의 무향 그래프에서 최소 절단은 $\binom n2$ 개 이하다.

서로 다른 최소 절단을 내놓는 사건은 서로 겹치지 않고 각각의 확률이 $\binom n2^{-1}$ 이상이므로 개수가 $\binom n2$ 이하다. 순환 $C_n$ 에서는 간선 두 개를 고르는 방법마다 최소 절단이 하나씩 있어 등호가 성립한다. 같은 논법으로 크기가 $\alpha\lambda(G)$ 이하인 절단은 $O(n^{2\alpha})$ 개다.

## 반복과 Karger–Stein 알고리즘

축약을 $\binom n2\ln n$ 번 독립으로 돌려 가장 작은 절단을 고르면 실패 확률이 $(1-\binom n2^{-1})^{\binom n2\ln n}\le 1/n$ 이다. 한 번의 축약이 $O(n^2)$ 시간이므로 전체는 $O(n^4\log n)$ 이다.

증명에서 실패 확률은 정점이 적게 남은 마지막 단계에 몰려 있다. D. R. Karger 와 C. Stein 은 정점이 $\lceil 1+n/\sqrt 2\rceil$ 개가 될 때까지 축약한 그래프를 두 벌 만들어 각각 재귀로 풀고 작은 쪽을 고르는 알고리즘을 주었다[^2]. 성공 확률이 $\Omega(1/\log n)$, 한 번의 시간이 $O(n^2\log n)$ 이므로 $O(\log^2n)$ 번 반복해 $O(n^2\log^3n)$ 시간에 높은 확률로 최소 절단을 찾는다.

## 결정적 방법과의 비교

[Gomory–Hu 나무](gomory-hu-tree.md)는 최대 흐름 $n-1$ 번으로 모든 정점 쌍의 최소 절단을 구하고, 가장 가벼운 간선이 전역 최소 절단이다. 전역 최소 절단만 필요하면 축약 알고리즘은 흐름 계산 없이 그 값을 얻는다. M. Stoer 와 F. Wagner 의 결정적 알고리즘은 정점을 차례로 합치는 같은 축약을 쓰되, 합칠 쌍을 무작위가 아니라 가장 강하게 연결된 순서로 고른다.

# 활용

- 망 신뢰성. 간선이 각각 확률 $p$ 로 끊길 때 그래프가 끊길 확률을 근사하는 다항시간 무작위 근사 기법에서, 작은 절단의 개수가 $O(n^{2\alpha})$ 라는 따름정리가 끊김을 일으키는 절단을 다항식 개로 줄인다.
- 그래프 희소화. 간선마다 그 간선을 지나는 절단의 크기에 반비례하는 확률로 표본을 뽑아 모든 절단의 크기를 $1\pm\varepsilon$ 배로 보존하는 희소 그래프를 만들 때, 절단 개수의 상한이 모든 절단에 걸친 합집합 상한(union bound) 계산에 쓰인다.
- 무작위 알고리즘의 예. 한 번의 성공 확률이 작아도 독립 반복으로 실패 확률을 줄이는 한쪽 오류 알고리즘으로, [무작위 복잡도 부류](randomized-complexity-classes.md)의 오류 줄이기와 같은 계산이다.

[^2]: D. R. Karger, C. Stein, "A new approach to the minimum cut problem", Journal of the ACM 43 (1996), 601–640.
