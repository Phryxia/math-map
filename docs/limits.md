# 수열의 극한

# 개요

수열의 극한은 "뒤쪽의 모든 항이 한 값에 원하는 정확도만큼 가까워진다" 는 성질을 정확히 적은 것이다. 해석학의 거의 모든 정의가 이 위에 세워진다. 연속성, 미분, 적분, 급수의 합이 전부 어떤 수열의 극한으로 정의되므로, 극한의 $\varepsilon$–$N$ 정의를 다루는 능력이 곧 해석학을 다루는 능력이다.

정의가 까다로워 보이는 이유는 "가까워진다" 는 동적인 표현을 [명제와 증명](proofs.md)에서 다루는 한정기호의 정적인 배열로 바꿔야 하기 때문이다. 그 배열의 순서가 전부다.

# 직관

## 도전과 응답의 게임

극한을 두 사람의 게임으로 읽으면 정의가 자연스러워진다. 상대가 오차 $\varepsilon$ 를 아무리 작게 불러도, 내가 기준 $N$ 을 적절히 내놓아 그 이후 모든 항이 $\varepsilon$ 안에 들어온다고 답할 수 있으면 수렴이다. $N$ 이 $\varepsilon$ 에 의존해도 되지만 $\varepsilon$ 를 본 뒤에 정한다는 순서가 중요하고, 일단 정한 뒤에는 예외 없이 모든 항이 조건을 만족해야 한다.

## 유한 개는 상관없다

앞쪽 항을 아무리 바꿔도 극한은 변하지 않는다. 극한은 수열의 꼬리에만 의존하는 성질이고, 그래서 "충분히 큰 $n$ 에 대해" 라는 표현이 해석학 전반에서 반복된다.

# 정의

## 수렴

실수 수열은 자연수를 정의역으로 하는 [함수](functions.md)이고 $n$ 번째 값을 $a_n$ 으로 쓴다. 실수 $L$ 에 대해 다음이 성립하면 수열이 $L$ 로 수렴한다고 한다.

$$
\forall\varepsilon>0\;\exists N\in\mathbb N\;\forall n\ge N:\ \lvert a_n-L\rvert<\varepsilon
$$

$$
\lim_{n\to\infty}a_n=L
$$

수렴하지 않으면 발산이라 하고, 그중 어떤 $M$ 에 대해서도 결국 $a_n > M$ 이 되는 경우를 $+\infty$ 로 발산한다고 한다.

## 상극한과 하극한

수렴하지 않는 수열에도 꼬리의 크기를 재는 두 값이 항상 정의된다.

$$
\limsup_{n\to\infty}a_n=\lim_{N\to\infty}\ \sup_{n\ge N}a_n,\qquad \liminf_{n\to\infty}a_n=\lim_{N\to\infty}\ \inf_{n\ge N}a_n
$$

유계 수열에서는 둘 다 존재하고, 둘이 같을 때가 정확히 수렴할 때다. 존재 여부를 따지지 않고 논증을 진행할 수 있어 부등식 증명에서 널리 쓰인다.

# 성질

## 기본 정리

- **유일성.** 극한이 둘이면 오차를 두 값 거리의 $1/3$ 로 잡고 삼각부등식을 쓰면 모순이 나온다.

$$
\lvert L-M\rvert\le\lvert L-a_n\rvert+\lvert a_n-M\rvert<\tfrac23\lvert L-M\rvert
$$

- **유계성.** 수렴 수열은 유계다. 극한에서 거리 1 이내인 꼬리와 앞의 유한 개 항을 각각 제한하면 된다.
- **대수.** 수렴하는 두 수열의 합, 차, 곱은 각각의 극한의 합, 차, 곱으로 수렴하고, 분모의 극한이 0 이 아니면 몫도 수렴한다.
- **짜내기.** $a_n \le b_n \le c_n$ 이고 양끝이 같은 값으로 수렴하면 가운데도 그 값으로 수렴한다.
- **순서 보존.** $a_n \le b_n$ 이면 극한도 $\le$ 다. 단, 강한 부등식은 극한에서 약해질 수 있다. $1/n > 0$ 이지만 극한은 0 이다.

## 완비성에 기대는 정리

단조 증가하면서 위로 유계인 실수 수열은 수렴한다. 이 명제는 실수의 완비성(상한 공리)과 동치이며, 유리수 안에서는 거짓이다. $\sqrt2$ 로 다가가는 유리수 단조 수열은 유리수 안에 극한을 갖지 않는다. 같은 근거에서 다음이 따라온다.

- **Bolzano–Weierstrass.** 유계 수열은 수렴하는 부분수열을 갖는다. 구간을 반씩 쪼개며 항이 무한히 많은 쪽을 택하면 된다.
- **Cauchy 판정.** 항들이 서로 가까워지는 것만으로 수렴이 따라온다. 이 동치성이 [완비성](completeness.md)의 내용이며, 극한값을 모르는 채로 수렴을 증명할 수 있게 해 준다.

## 흔한 오해

항 사이의 차가 0 으로 간다고 수렴하지는 않는다. $a_n = \sqrt n$ 은 $a_{n+1} - a_n \to 0$ 이지만 발산하고, 조화급수의 부분합도 마찬가지다. Cauchy 조건은 이웃한 두 항이 아니라 충분히 뒤의 임의의 두 항이 가까워질 것을 요구한다.

## 계산으로 확인

```python
import math

# ε 을 주면 N 을 돌려준다: |1/n - 0| < ε 는 n > 1/ε 과 같다
N = lambda eps: math.floor(1 / eps) + 1
for eps in (1e-1, 1e-3, 1e-6):
    n = N(eps)
    print(eps, n, abs(1 / n) < eps)          # 정의를 만족하는 N 을 실제로 준다

a = lambda n: (-1) ** n * (1 + 1 / n)        # 유계지만 발산
tail = [a(n) for n in range(100, 10000)]
print(round(max(tail), 6), round(min(tail), 6))
# 1.01 -1.009901: limsup = 1, liminf = -1 이라 수렴하지 않는다

s, terms = 0.0, []                            # 조화급수: 항은 0 으로 가지만 부분합은 발산
for n in range(1, 10 ** 6 + 1):
    s += 1 / n
    if n in (10, 10 ** 3, 10 ** 6):
        terms.append((n, round(s, 4)))
print(terms)
# [(10, 2.929), (1000, 7.4855), (1000000, 14.3927)]  로그 속도로 계속 커진다
```

세 번째 실험이 "항이 0 으로 간다" 와 "부분합이 수렴한다" 가 다른 진술임을 보여 준다. 부분합은 $\ln n$ 규모로 자라므로 백만 항을 더해도 15 를 넘지 않지만, 어떤 값에도 정착하지 않는다.

# 활용

## 해석학의 기초 언어

함수의 연속성은 "수렴하는 입력 수열을 수렴하는 출력 수열로 보낸다" 로 특징지어지고, 미분은 차분몫 수열의 극한, 적분은 근사합의 극한이다. 무한급수의 합은 부분합 수열의 극한으로 정의되므로 급수 이론 전체가 극한의 응용이다.

## 알고리즘의 수렴

반복법이 답에 다가가는지, 얼마나 빨리 다가가는지를 재는 언어가 극한이다. Newton 법의 이차 수렴, 경사하강법의 선형 수렴, Monte Carlo 추정의 $1/\sqrt n$ 오차가 모두 수열의 수렴 속도에 대한 진술이다. 확률 쪽에서는 수렴의 의미가 여러 갈래로 갈라져 거의 확실한 수렴, 확률 수렴, 분포 수렴이 구별된다.

## 일반화

거리만 있으면 같은 정의를 쓸 수 있으므로 [거리 공간](metric-spaces.md)에서 그대로 반복되고, 거리 없이 근방만 있는 위상공간에서는 수열 대신 그물을 쓴다. 함수들의 수열에서는 각 점마다 수렴하는 것과 전체에서 고르게 수렴하는 것이 달라지며, 그 차이가 [균등수렴](uniform-convergence.md)의 주제다.[^1]
