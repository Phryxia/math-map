# 논문: How Powerful are Graph Neural Networks?

이 논문은 이웃의 특징을 반복 집계하는 그래프 신경망이 어떤 그래프 구조를 구별할 수 있는지 분석한다.

## 정의

Graph neural network를 GNN이라 줄여 쓴다. 여기서는 각 정점이 이웃 특징의 순서에 무관한 집계값과 자기 특징으로 새 특징을 계산하는 message-passing GNN을 대상으로 한다.

정점 v의 t번째 특징 벡터를 h_t(v), 이웃 집합을 N(v), t번째 집계 함수를 A_t, 자기 특징과 집계를 결합하는 함수를 U_t라 하자.

$$
h_{t+1}(v)=U_t\left(h_t(v),A_t\left(\{\!\{h_t(u):u\in N(v)\}\!\}\right)\right)
$$

그래프 전체의 출력은 정점 특징들의 순열 불변 readout으로 만든다. 여기서 표현력은 두 입력 그래프에 서로 다른 출력을 줄 수 있는 능력을 뜻한다.

## 성질

같은 초기 특징 조건에서 위 형태의 GNN은 1-WL이 구별하지 못하는 그래프를 더 강하게 구별할 수 없다. 1-WL 색이 같은 정점들은 매 단계 같은 특징을 얻는다는 귀납으로 상한을 보인다.

충분한 반복 횟수와 단사적인 이웃 집계·갱신·readout을 갖추면 1-WL이 구별하는 그래프들을 구별할 수 있다는 충분조건도 제시한다. 논문의 구성에서는 가산 입력 특징 공간과 크기가 제한된 multiset이라는 조건을 사용한다.

평균은 서로 다른 multiset을 합칠 수 있다. 예를 들어 실수 특징 1, 3을 모은 경우와 2, 2를 모은 경우는 모두 평균 2다. 최댓값 역시 작은 원소들과 중복 횟수를 잃는다.

그렇다고 원래 특징을 그냥 합하면 항상 단사라는 뜻은 아니다. 바로 위 두 multiset은 합도 4로 같다. 논문에서 합 집계의 충분한 표현력은 적절한 특징 변환과 함수 조건에 의존한다.

## 활용

학습을 더 해도 구조적 구별 한계가 사라지지 않는 사례를 분석한다. 데이터 라벨이 1-WL로 구별되지 않는 두 구조를 나누도록 요구하면 이 모델 범위에서는 그 차이를 표현할 수 없다.

정점 식별자, 추가적인 위치 정보, 고차 구조를 넣으면 입력 조건이나 모델 범위가 달라진다. 또한 표현할 수 있다는 결과가 실제 학습 성공이나 일반화 성능을 자동으로 보장하지는 않는다.
