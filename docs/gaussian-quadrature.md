# Gauss 구적

# 개요

Gauss 구적은 적분을 노드에서의 함숫값의 가중합으로 바꾸는 공식 가운데, 노드와 가중치를 모두 미지수로 두어 정확도를 최대로 올린 것이다. 노드 $n$ 개로 차수 $2n-1$ 이하의 다항식을 정확히 적분한다.

노드는 가중함수에 딸린 [직교다항식](orthogonal-polynomials.md) $p_n$ 의 영점이고 가중치는 그 영점에서 결정된다. 노드를 직접 구하는 대신 삼항 점화식의 Jacobi 행렬을 대각화해 얻는 것이 Golub–Welsch 절차다.

# 직관

$\lbrack -1,1\rbrack$ 에서 적분을 함숫값 두 개의 가중합으로 근사한다. 노드를 $\pm1$ 로 고정하면 가중치 두 개만 미지수이고, 상수와 $x$ 를 정확히 적분하라는 조건에서 $\int_{-1}^1f\approx f(-1)+f(1)$ 이 나온다. $f(x)=x^2$ 를 넣으면 좌변이 $2/3$, 우변이 $2$ 로 어긋난다.

노드도 미지수로 풀면 조건을 더 받을 수 있다. 노드 $\pm t$ 와 가중치 $w$ 를 대칭으로 두고 $1$ 과 $x^2$ 를 정확히 적분하라고 요구한다.

$$
2w=2,\qquad 2wt^2=\frac23
$$

에서 $w=1$ 과 $t=1/\sqrt3$ 이다. 홀수 거듭제곱은 대칭성으로 양변이 모두 $0$ 이므로 $x^3$ 까지 정확하다. 노드를 고정했을 때 $x^2$ 에서 깨졌던 공식이 노드를 풀어 주자 차수 $3$ 까지 정확해졌다.

미지수는 노드 $n$ 개와 가중치 $n$ 개로 $2n$ 개이고, 차수 $2n-1$ 이하의 다항식 공간도 $2n$ 차원이다. 두 수가 같으므로 이 차수가 올릴 수 있는 한계다. $t=1/\sqrt3$ 은 Legendre 다항식 $p_2(x)=x^2-\tfrac13$ 의 영점이다.

# 정의

## 구적 공식

가중함수 $w\ge0$ 과 노드 $x_1,\dots,x_n$, 가중치 $w_1,\dots,w_n$ 에 대해 다음을 구적 공식이라 한다.

$$
\int_a^bf(x)w(x)\thinspace dx\ \approx\ \sum_{i=1}^nw_if(x_i)
$$

차수 $m$ 이하의 모든 다항식에서 등호가 성립하면 이 공식의 **정확도 차수**가 $m$ 이다.

## Gauss 구적

$p_n$ 을 가중 $w$ 의 $n$ 차 직교다항식이라 하고 그 영점을 $x_1,\dots,x_n$ 으로 둔다. 가중치를 Lagrange 기저 $\ell_i$ 의 적분으로 정한다.

$$
w_i=\int_a^b\ell_i(x)w(x)\thinspace dx,\qquad \ell_i(x)=\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}
$$

이 노드와 가중치를 쓴 공식이 **Gauss 구적**이다. 가중함수가 $1$ 이면 Gauss–Legendre, $(1-x^2)^{-1/2}$ 이면 Gauss–Chebyshev, $e^{-x^2}$ 이면 Gauss–Hermite 구적이다.

## Jacobi 행렬

선행계수를 $1$ 로 정규화한 점화식 $p_{n+1}=(x-B_n)p_n-C_np_{n-1}$ 의 계수를 모은 삼중대각 대칭행렬이다.

$$
J_n=\begin{pmatrix}B_0&\sqrt{C_1}&&\cr \sqrt{C_1}&B_1&\ddots&\cr &\ddots&\ddots&\sqrt{C_{n-1}}\cr &&\sqrt{C_{n-1}}&B_{n-1}\end{pmatrix}
$$

# 성질

## 정확도 차수

> **정리.** Gauss 구적의 정확도 차수는 $2n-1$ 이고, 노드 $n$ 개를 쓰는 어떤 공식도 $2n$ 을 넘지 못한다.

차수 $2n-1$ 이하의 $f$ 를 $p_n$ 으로 나눠 $f=qp_n+r$ 로 쓰면 $\deg q\le n-1$ 이다. 직교성에서 $\int qp_nw=0$ 이므로 좌변이 $\int rw$ 와 같고, 노드에서 $p_n$ 이 $0$ 이라 우변도 $r$ 의 값만 본다. 차수 $n-1$ 이하에서 $n$ 점 보간이 정확하므로 양변이 일치한다.

차수 $2n$ 이 불가능한 것은 $f(x)=p_n(x)^2$ 가 반례다. 좌변이 양수인데 모든 노드에서 $f$ 가 $0$ 이라 우변이 $0$ 이다.

## 가중치의 양수성

$f=\ell_i^2$ 는 차수 $2n-2$ 이므로 공식이 정확하고, 좌변이 양수이며 우변이 $w_i$ 다. 따라서 모든 $w_i\gt0$ 이다. 가중치가 양수이므로 함숫값의 오차가 상쇄 없이 더해지고 공식이 수치적으로 안정하다.

## Golub–Welsch 절차

> **정리.** $J_n$ 의 고윳값이 Gauss 노드이고, 고유벡터의 첫 성분 $v_{i,1}$ 에서 $w_i=\mu_0v_{i,1}^2$ 이다. 여기서 $\mu_0=\int_a^bw$ 다[^1].

$p_n$ 의 영점이 $J_n$ 의 고윳값인 것은 점화식을 행렬로 적은 것에서 바로 나온다. 다항식의 근을 직접 구하면 차수가 커질 때 불안정하지만, 대칭 삼중대각 행렬의 고윳값 계산은 안정하고 비용이 $O(n^2)$ 다.

```javascript
// 노드와 가중치를 점화식 계수에서 얻는다
function golubWelsch(B, C, mu0) {
  const J = tridiagonalSymmetric(B, C.map(Math.sqrt))
  const { values, vectors } = symmetricEigen(J)   // 안정한 대칭 고윳값 분해
  return values.map((x, i) => ({
    node: x,
    weight: mu0 * vectors[i][0] ** 2,
  }))
}
```

## 오차

$f$ 가 $C^{2n}$ 이면 오차가 다음 꼴이다.

$$
\int_a^bfw-\sum_iw_if(x_i)=\frac{f^{(2n)}(\xi)}{(2n)!}\int_a^bp_n(x)^2w(x)\thinspace dx
$$

어떤 $\xi\in(a,b)$ 에서 성립한다. 해석함수에서는 $\int p_n^2w$ 가 $n$ 과 함께 빠르게 줄어 수렴이 지수적이다. 미분이 거친 함수에서는 이 추정이 쓸 수 없으므로 구간을 나눠 조각마다 적용한다.

# 활용

- 수치적분. 함수 호출 $n$ 번으로 차수 $2n-1$ 까지 정확하므로, 같은 호출 수의 Newton–Cotes 공식보다 정확도가 높고 노드가 구간 안에 있어 끝점의 특이성을 피한다.
- 유한요소법의 요소 적분. 기저함수의 곱이 다항식이라 차수를 알고 있으므로, 그 차수를 정확히 적분하는 최소 노드 수를 Gauss 구적으로 고른다.
- 가중함수에 특이성이 있는 적분. $(1-x^2)^{-1/2}$ 나 $x^\alpha e^{-x}$ 를 가중함수로 흡수하면 특이점이 노드 선택에 들어가므로 변수변환 없이 적분한다.
- [확률변수](random-variables.md)의 모멘트 계산. 분포의 가중함수에 딸린 직교다항식을 쓰면 적은 노드로 기댓값 적분을 대신하고, 노드와 가중치가 모멘트를 정해진 차수까지 보존한다.

[^1]: G. Golub, J. Welsch, "Calculation of Gauss quadrature rules", Math. Comp. 23 (1969), 221–230.
