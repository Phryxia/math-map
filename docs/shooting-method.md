# 사격법

# 개요

**사격법(shooting method)** 은 양 끝에 조건이 걸린 미분방정식을 처음 기울기를 고쳐 가며 푸는 방법이다. $y''=\tfrac32y^2$ 을 $y(0)=4$, $y(1)=1$ 로 풀려고 하면, 수치해법은 $x=0$ 에서 값과 기울기를 둘 다 받아 앞으로 나아가는데 $x=0$ 의 기울기를 모른다. 사격법은 기울기 $s$ 를 하나 정해 끝까지 풀고 $x=1$ 에서 빗나간 양을 본 뒤, 빗나간 양이 $0$ 이 되도록 $s$ 를 방정식의 근으로 구한다.

# 직관

[Runge–Kutta 방법](runge-kutta-methods.md)은 $y(0)$ 과 $y'(0)$ 을 받아 $x=0$ 에서 $x=1$ 까지 한 걸음씩 나아간다. 위 문제는 $y(0)=4$ 만 주고 $y'(0)$ 대신 $y(1)=1$ 을 주므로 그대로는 돌릴 수 없다.

$y'(0)$ 을 $s$ 로 정하고 돌리면 끝값 $y(1)$ 이 하나 나온다. $s=-7$ 이면 $3.644$, $s=-9$ 이면 $-0.958$ 이다. 첫째는 $1$ 보다 크고 둘째는 작으므로 그 사이에 끝값이 $1$ 이 되는 $s$ 가 있다.

끝값에서 $1$ 을 뺀 값 $F(s)$ 는 $s$ 를 넣으면 나오지만 식으로는 적히지 않는다. 그래서 두 번의 결과를 잇는 직선으로 다음 $s$ 를 정하는 [할선법](secant-method.md)을 쓴다. $s$ 는 $-8.149$, $-7.976$, $-8.0005$, $-8.000002$ 로 가고, 참해 $y=4/(1+x)^2$ 의 기울기 $y'(0)=-8$ 에 닿는다. 처음 기울기를 고쳐 가며 끝점을 맞추는 모양이 과녁을 겨냥해 쏘는 것과 같아 사격법이라 한다.

# 정의

## 단일 사격법

2 계 **경계값 문제(boundary value problem)** 는 다음이다.

$$
y''=f(x,y,y'),\qquad y(a)=\alpha,\quad y(b)=\beta
$$

$s$ 마다 초깃값 문제 $y''=f(x,y,y')$, $y(a)=\alpha$, $y'(a)=s$ 의 해를 $y(x;s)$ 라 하고, 다음 함수를 둔다.

$$
F(s)=y(b;s)-\beta
$$

**사격법** 은 $F(s)=0$ 의 근 $s^\ast$ 를 구하고 $y(x;s^\ast)$ 를 경계값 문제의 해로 삼는 방법이다. $F$ 의 값 하나를 얻는 데 초깃값 문제 하나를 수치적으로 푼다. 직관 절의 예에서 $f(x,y,y')=\tfrac32y^2$, $a=0$, $b=1$, $\alpha=4$, $\beta=1$ 이고 $F(-7)=2.644$, $F(-9)=-1.958$ 이다.

## Newton 사격과 변분 방정식

$F$ 의 도함수는 $z(x)=\partial y(x;s)/\partial s$ 의 끝값이다. $z$ 는 원래 방정식을 $s$ 로 미분한 **변분 방정식(variational equation)** 을 만족한다.

$$
z''=f\_y\thinspace z+f\_{y'}\thinspace z',\qquad z(a)=0,\quad z'(a)=1
$$

$y$ 와 $z$ 를 함께 적분하면 $F(s)$ 와 $F'(s)=z(b)$ 가 한 번에 나오고, 이것으로 [Newton 법](newton-method.md) $s\mapsto s-F(s)/F'(s)$ 를 쓴다.

## 다중 사격법

**다중 사격법(multiple shooting)** 은 구간을 $a=x_0\lt x_1\lt\cdots\lt x_m=b$ 로 나누고, 각 마디 $x_j$ 에서 값과 기울기 $(y_j,s_j)$ 를 미지수로 두어 조각마다 초깃값 문제를 푸는 방법이다. 미지수는 조각의 끝에서 다음 조각의 처음과 값과 기울기가 이어진다는 조건과 두 경계조건으로 정해지고, 이 연립방정식을 Newton 법으로 푼다.

# 성질

## 해와 근의 대응

정리. $f$ 가 연속이고 $y,y'$ 에 대해 Lipschitz 이면, 경계값 문제의 해와 $F$ 의 근은 일대일로 대응한다.

증명의 요지. [상미분방정식](ordinary-differential-equations.md)의 Picard–Lindelöf 정리로 각 $s$ 에서 초깃값 문제의 해가 유일하게 존재한다. 경계값 문제의 해 $y$ 는 $s=y'(a)$ 에서 $y(x;s)$ 와 같은 초깃값을 가지므로 같은 함수이고 $F(s)=0$ 이다. 역으로 $F(s)=0$ 이면 $y(x;s)$ 가 두 경계조건을 만족한다.

경계값 문제는 해가 없을 수도, 여럿일 수도 있다. 직관 절의 문제에서 $F$ 는 $s=-8$ 말고 $s\approx-35.86$ 에서도 $0$ 이 된다. $s=-30$, $-40$ 에서 할선법을 시작하면 $-35.700$, $-35.855$, $-35.8586$ 으로 이 둘째 해에 닿는다. 두 해는 $x=0$ 에서 값이 같고 기울기만 다르다.

## 선형 방정식

$f(x,y,y')=p(x)y'+q(x)y+r(x)$ 이면 $y(x;s)$ 는 $s$ 의 일차식이고 $F$ 도 $s$ 의 일차식이다. 그래서 두 번 쏘면 $F$ 의 직선이 정해지고, 할선법의 첫 걸음이 정확한 근이다. $y''=y$, $y(0)=0$, $y(1)=1$ 에서 $y(x;s)=s\sinh x$ 이고 $F(s)=s\sinh1-1$ 이므로 $s^\ast=1/\sinh1\approx0.8509$ 다.

## 초깃값에 대한 민감성

$y''=\lambda^2y$, $y(0)=0$ 에서 $y(x;s)=s\sinh(\lambda x)/\lambda$ 이고 $F'(s)=\sinh(\lambda(b-a))/\lambda$ 다. $\lambda=20$, $b-a=1$ 이면 $F'(s)\approx1.2\times10^7$ 이므로, $s$ 에 남는 $10^{-12}$ 의 오차가 끝값에서 $10^{-5}$ 의 오차가 된다. 빨리 자라는 해가 섞인 방정식에서는 $s$ 를 아무리 정확히 구해도 끝값을 맞출 수 없다.

다중 사격법은 조각 하나의 길이를 $(b-a)/m$ 으로 줄여, 조각 안의 증폭률을 $e^{\lambda(b-a)}$ 에서 $e^{\lambda(b-a)/m}$ 로 낮춘다. 연립방정식은 커지지만 각 이음 조건이 이웃한 두 조각의 미지수만 쓰므로 계수행렬이 띠 모양이다.

# 활용

- Sturm–Liouville 고윳값 문제. $-(py')'+qy=\lambda wy$, $y(a)=y(b)=0$ 에서 $y'(a)=1$ 로 고정하고 $\lambda$ 를 미지수로 쏘아 $y(b;\lambda)=0$ 을 푼다. [Sturm–Liouville 이론](sturm-liouville.md)의 진동정리로 $n$ 번째 고윳값의 고유함수는 내부에 영점이 $n-1$ 개이므로, 영점 수를 세어 원하는 고윳값을 고른다.
- 최적제어. [Pontryagin 최대 원리](pontryagin-maximum-principle.md)는 상태의 처음 조건과 공상태의 끝 조건을 함께 주는 경계값 문제를 내놓고, 공상태의 처음 값을 미지수로 쏘아 끝 조건을 맞춘다.
- 측지선. [Riemann 계량](riemannian-metrics.md)이 주어진 곡면에서 두 점을 잇는 측지선은 한 점에서 출발 방향을 정해 측지선 방정식을 풀고, 다른 점에 닿도록 방향을 고쳐 구한다.
- 궤도 설계. 정해진 시각에 두 위치를 지나는 궤도는 처음 속도를 미지수로 쏘아 끝 위치를 맞춘다. 행성 사이 이동처럼 끝 조건에 민감한 문제에는 다중 사격법을 쓴다.
