# Neville 알고리즘

# 개요

**Neville 알고리즘(Neville's algorithm)** 은 보간 다항식의 식을 구하지 않고 한 점에서의 값만 직선 보간을 되풀이해 계산하는 방법이다. $2^x$ 의 값을 $x=0,1,2$ 에서만 알 때 $x=3$ 에서 보간 다항식의 값을 알고 싶다고 하자. [다항식 보간](polynomial-interpolation.md)의 Lagrange 꼴로는 기저 다항식 셋을 모두 만들어야 한다. Neville 알고리즘은 이웃한 두 점을 지나는 직선의 값 두 개를 다시 직선으로 섞어 같은 값 $7$ 을 낸다.

# 직관

점 $(0,1)$, $(1,2)$ 를 지나는 직선은 $x=3$ 에서 $4$ 이고, 점 $(1,2)$, $(2,4)$ 를 지나는 직선은 $x=3$ 에서 $6$ 이다. 두 값은 각각 앞의 두 점과 뒤의 두 점만 쓴 어림값이다.

이 두 어림값을 하나로 합친다. 앞의 어림값 $4$ 는 $x=2$ 의 자료를 쓰지 않았고, 뒤의 어림값 $6$ 은 $x=0$ 의 자료를 쓰지 않았다. 두 어림값을 $x=0$ 에서 $4$ 쪽, $x=2$ 에서 $6$ 쪽이 되도록 $x$ 에 대해 직선으로 섞어 $x=3$ 에서의 값을 읽는다.

$$
\frac{(3-0)\cdot 6-(3-2)\cdot 4}{2-0}=\frac{18-4}{2}=7
$$

다항식 보간 문서의 직관 절에서 구한 이차 다항식 $\tfrac12x^2+\tfrac12x+1$ 의 $x=3$ 에서의 값도 $7$ 이다.

# 정의

서로 다른 점 $x_0,\dots,x_n$ 과 값 $y_0,\dots,y_n$, 그리고 값을 구할 점 $x$ 가 주어진다. $P_{i,i}=y_i$ 로 두고 $i\lt j$ 에 대해 다음으로 $P_{i,j}$ 를 정한다.

$$
P_{i,j}=\frac{(x-x_i)P_{i+1,j}-(x-x_j)P_{i,j-1}}{x_j-x_i}
$$

$P_{0,n}$ 이 결과다. 직관 절은 $n=2$, $x=3$ 이고 $P_{0,1}=4$, $P_{1,2}=6$, $P_{0,2}=7$ 이다. 값들을 $j-i$ 가 같은 것끼리 한 열에 놓은 삼각형 표를 **Neville 표(Neville tableau)** 라 한다.

```javascript
// xs, ys: 자료점, x: 값을 구할 점
function neville(xs, ys, x) {
  const p = ys.slice();
  const n = xs.length;
  for (let d = 1; d < n; d++) {
    for (let i = 0; i + d < n; i++) {
      const j = i + d;
      p[i] = ((x - xs[i]) * p[i + 1] - (x - xs[j]) * p[i]) / (xs[j] - xs[i]);
    }
  }
  return p[0];
}
```

# 성질

## 정당성

$P_{i,j}$ 는 점 $x_i,\dots,x_j$ 를 지나는 차수 $j-i$ 이하의 보간 다항식 $p_{i,j}$ 의 $x$ 에서의 값이다. $j-i$ 에 대한 귀납법으로, 다음 다항식을 놓는다.

$$
q(t)=\frac{(t-x_i)\thinspace p_{i+1,j}(t)-(t-x_j)\thinspace p_{i,j-1}(t)}{x_j-x_i}
$$

$t=x_i$ 이면 둘째 항만 남아 $p_{i,j-1}(x_i)=y_i$ 이고, $t=x_j$ 이면 첫째 항만 남아 $y_j$ 다. 그 사이의 점 $x_k$ 에서는 두 다항식이 모두 $y_k$ 이므로 $q(x_k)=y_k$ 다. 차수는 $j-i$ 이하이고 보간 다항식은 유일하므로 $q=p_{i,j}$ 다.

## 계산량

한 점의 값을 구하는 데 표의 칸 $n(n+1)/2$ 개를 채우고 칸마다 곱셈 두 번과 나눗셈 한 번을 쓰므로 계산량은 $O(n^2)$ 이다. 자료점을 하나 더하면 표에 대각선 한 줄만 더 채우면 되고, 앞서 채운 칸은 그대로 쓴다.

## 오차의 어림

$P_{0,n}$ 과 $P_{0,n-1}$ 의 차이는 점을 하나 더 써서 값이 얼마나 바뀌었는지를 보여 주므로, 보간 오차의 어림으로 쓴다. 직관 절에서 $P_{0,2}-P_{0,1}=7-4=3$ 이고, $x=3$ 에서의 실제 오차 $2^3-7=1$ 보다 크다. 이 차이는 분할 차분 $f\lbrack x_0,\dots,x_n\rbrack$ 에 $\prod_{i\lt n}(x-x_i)$ 를 곱한 값이고, Newton 꼴의 마지막 항과 같다.

# 활용

- [Richardson 외삽](richardson-extrapolation.md). 걸음 크기 $h$ 를 줄여 가며 얻은 근삿값들을 $h^2$ 의 함수로 보고 $h=0$ 에서의 값을 Neville 알고리즘으로 구한 것이 Richardson 외삽이고, 사다리꼴 규칙에 쓰면 Romberg 적분(Romberg integration)이다.
- 표의 보간. 수표나 측정값 표에서 원하는 점 하나의 값을 낼 때, 가까운 점부터 하나씩 더하며 Neville 표를 채우고 값의 변화가 충분히 작아지면 멈춘다.
- 유리함수 외삽. 직선 섞기 대신 유리함수 보간의 점화식을 쓰는 같은 꼴의 표가 Bulirsch–Stoer 방법의 외삽 단계에 쓰인다.
